# 映像品質キット（ルール改変ニッポン 冒頭 v2 の仕組みを、どのチャンネルでも使えるようにしたもの）

- 社長の指示（2026-11-14）：「さっき作ったクオリティの動画を他のチャンネルでも使えるようにして」
- 元になった動画：ルール改変ニッポン「全員同じ給料／誰が働く？」冒頭1分版 v2（社長「映像の方向性はこれでOK」2026-11-14）。実物は `pilots/kaihen-001-equal-pay/`
- 追加費用なし（すべて無料のソフト・素材）。顔出し・自分の声なし

## 入っているもの

| 部品 | ファイル | 中身 |
|---|---|---|
| 3D の映像（映画のような仕上げ） | `three/Canvas3D.tsx` | 被写界深度（ミニチュア風のぼかし）・ブルーム（光のにじみ）・ビネット。3D を 1440×810 で描いて 1920×1080 に拡大し、書き出しを約3分の1に短縮。`project()` で3Dの位置に2Dの文字を重ねる |
| 3D の部品 | `three/common.tsx`・`three/World.tsx` | カメラの動き（キーフレーム）、手ぶれ、文字の貼り込み、街（ビル・道路・街灯・木）、空（夜→朝）、人（職業の小物つき）、給料袋、看板、カード、判子（ルール改変ニッポン用の例） |
| BGM（作曲＋実楽器の音） | `audio/bgm.py` | Python で MIDI を作曲し、FluidSynth＋FluidR3_GM（MIT ライセンス、作者 Frank Wen）で鳴らす。場面ごとに曲調を変える5種類（intro＝盛り上げ／groove＝前へ進む／question＝緊張／cards＝軽快／calm＝落ち着き）。リバーブ・コンプで仕上げ |
| ナレーションの仕上げ | `audio/voice_polish.py` | 低音のこもりを切る・声の通りを良くする・耳に痛い高音を抑える・音量をそろえる |
| 準備 | `audio/setup_voicevox.sh` | VOICEVOX の公式エンジン（Docker）と BGM の道具を起動・導入。コンテナが再起動したあとも、そのまま動く |
| 新しい動画の作成 | `new_pilot.sh <話のID>` | 上の部品と、字幕（ヒト図鑑と同じ仕組み）・分割書き出し・音量 −16 LUFS の仕組みを `pilots/<話のID>/` に複製する |

## 使い方
```bash
video/kit/audio/setup_voicevox.sh
```
```bash
video/kit/new_pilot.sh <話のID>
```
そのあとは `pilots/<話のID>/docs/notes.md` の「直すこと」に沿って、色・読み・強調語・声・BGM の区間を、そのチャンネルに合わせる。書き出しの手順は `pilots/kaihen-001-equal-pay/docs/notes.md` と同じ（字幕カード → 分割書き出し → 結合）。

## チャンネルごとの使い方（各チャンネルで社長が決めたルールを優先する）

| チャンネル | そのまま使えるもの | 社長のルールに合わせて変えるもの・決めてもらうこと |
|---|---|---|
| 地球の事情（`channels/chizu/`） | 3D の仕上げ、ナレーションの仕上げ、BGM の作曲の仕組み | 見た目は社長指示（2026-11-12）の「明るい灰白の背景・丸ゴシック・暗い紺は使わない」に合わせる（空は朝、街の色を明るく）。画面の左上・右上の注釈は出さない。声は今の雀松朱司（`VV_SPEAKER=52`） |
| ヒト図鑑（`channels/iq-chinou/`） | 3D の仕上げ（すでに 3D を使っている）、ナレーションの仕上げ | **BGM は社長指示（2026-11-07）の「静かなドラム3曲・キックなし」が決まっているので、この BGM に変えるには社長の判断が要る**。声は今のナースロボ＿タイプＴ（`VV_SPEAKER=47`） |
| ハビ判事（`channels/habi-judge/`） | 3D の仕上げ、BGM、ナレーションの仕上げ | 声は社長承認の Open JTalk（CC BY 3.0 のクレジット必須）。VOICEVOX に変えるなら社長の判断が要る |
| 恋愛・不倫 YouTube（新規） | すべて | チャンネルの色・声はチャンネル設計で決める |

## ライセンス・クレジット
- VOICEVOX：キャラクターごとの規約に従い、概要欄に「VOICEVOX:キャラクター名」を書く（例：「VOICEVOX:玄野武宏」）。規約は `curl 127.0.0.1:50021/speaker_info?speaker_uuid=...` で確認する
- FluidR3_GM：MIT ライセンス（`/usr/share/doc/fluid-soundfont-gm/copyright`）。BGM はこのキットで作曲したもの
- フォント：Noto Sans JP（SIL OFL）
