## D-1 鏡は何のためにあったか

### D-1-1 「国中の人に見せよ」＝見せる権威の道具
- 魏の詔書は銅鏡百枚などを「悉可以示汝國中人、使知國家哀汝」（すべて国中の人に見せ、魏があなたを大切にしていると知らせよ）と結ぶ。→ A-1-2
- 確かさ：確認済み

### D-1-2 卑弥呼の「鬼道」
- 「事鬼道、能惑衆」（鬼道に仕え、よく人々を惑わした）。鬼道はシャーマニズムと推測されている。
- 出典：ウィキペディア「卑弥呼」（典拠：大津透2017）
- 確かさ：確認済み（ウィキペディア）。「卑弥呼が鏡を使って祭祀をした」は倭人伝に書かれていない → **台本で断定しない**（「〜と考える研究者もいる」程度、または使わない）

### D-1-3 鏡に描かれた神々（神仙思想）
- 三角縁神獣鏡の背面は神仙世界。銘文から西王母・東王父が確認でき、王喬・赤松子（代表的な仙人）の可能性も。禅定印を結ぶ仏像とする説の人物もある（新山古墳の三角縁三仏三獣鏡）。聖獣は龍・虎・白虎・天鹿・朱鳥・玄武など。
- 西王母と東王父は後漢後半の鏡で好まれ、陰陽を整える役割とされる。
- 出典：ウィキペディア「三角縁神獣鏡」（典拠：下垣2010）
- 確かさ：確認済み（ウィキペディア）
- 銘文の例：「寿如金石」（金石のように長生き）、「保子宜孫」（子を保ち孫によい）＝ 長寿と子孫繁栄の願い（B-5の紀年銘文）。→ 確認済み（銘文の字はウィキペディア）。意訳は一般的な読み

### D-1-4 「左龍右虎、不祥を辟く」＝魔除け
- 安満宮山古墳の青龍三年鏡の銘：「青龍三年顔氏作竟成文章左龍右虎辟不詳朱爵玄武順陰陽八子九孫治中央寿如金石宜侯王」。「辟不詳（不祥を避ける）」＝ 災いを退ける魔除けの文句が実際に鏡に書かれている。
- 出典：ウィキペディア「三角縁神獣鏡」（紀年銘鏡の節）
- 確かさ：銘文は確認済み（ウィキペディア）。「辟不詳＝辟不祥（不祥を辟く）」の読みは一般的な解釈（原典の釈文は未読）

### D-1-5 死者を守る？ 黒塚古墳の配置
- 棺の中は画文帯神獣鏡1面だけ、頭の近くに文様の面を内側に向けて立てる。三角縁神獣鏡33面は棺の外で、棺の北半分を「コ」の字に取り囲む。→ B-6
- 遺体を鏡で取り囲む「身体包囲型配置」と呼ばれる（論文の検索抜粋）。
- 「鏡が邪悪なものから死者を守った（または死者の霊を封じた）」という解釈は**一次資料で確認できず未確認**。→ 台本では「なぜ取り囲んだのか」を問いとして出し、答えは「守るためと考える人もいる」程度にとどめる。
- 小林行雄の伝世鏡論：鏡は日本古来の信仰と分かちがたく、弥生時代に祭祀に使われ司祭的首長が受け継いだ宝鏡だった（ウィキペディア「同笵鏡論・伝世鏡論」）→ 確認済み（ウィキペディア）。ただし現在は小林説をそのまま支持する研究者はいない

### D-1-6 鏡を磨いて、重ねて、赤く塗る（富雄丸山の新知見）
- 天理参考館の3面は、赤色顔料（ベンガラ）を使って研磨した痕があり、墳頂部の別の鏡にも同じ痕。副葬前に一緒に手入れされたとみられる（奈良新聞 2026/1/31、検索抜粋）。
- 鏡の上に銅板2枚、隣に銅の腕輪（銅釧）を重ねて置いた可能性（朝日 2026/11/22、本文確認）。
- 造出しの木棺では、銅鏡3面が鏡面を上にして重ねて副室に置かれていた（奈良市資料、検索抜粋）。
- 確かさ：C-2・C-3 参照

## D-2 八咫鏡と「鏡を神として祀る」

| 事実 | 出典 | 確かさ |
|---|---|---|
| 八咫鏡は三種の神器の一つ。伊勢神宮内宮の御神体と、皇居（賢所）の形代の2つがある。いずれも一般公開されない | ウィキペディア「八咫鏡」 | 確認済み（ウィキペディア） |
| 天孫降臨の際、天照大御神が邇邇芸命に授け、「この鏡を天照大御神自身だと思って祀るように」という神勅（宝鏡奉斎の神勅）が下されたという（記紀神話） | ウィキペディア「八咫鏡」 | 確認済み（ウィキペディア）。神勅の原文（日本書紀の一書の文言）は**未確認**★ |
| 天岩戸神話で、岩戸を少し開けた天照大御神をこの鏡に映したという | ウィキペディア「八咫鏡」 | 確認済み（ウィキペディア） |
| 古代の記録で八咫鏡を依代とする神社は伊勢神宮と宗像大社辺津宮だけとされる | ウィキペディア「八咫鏡」 | 確認済み（ウィキペディア） |

| 平原1号墓の鏡（40面分、国宝、2006年指定）。大型内行花文鏡5面（または4面）、伊都国歴史博物館に4面、九州国立博物館に1面を展示 | ウィキペディア「平原遺跡」 | 確認済み（ウィキペディア） |
| 『日本書紀』で、伊弉諾尊が左手で白銅鏡を持ったとき大日孁貴（天照大神）が生まれたという記述（第五段一書第一） | ウィキペディア「魔鏡」 | 確認済み（ウィキペディア）。原文未確認 |
| 鏡づくりの集団「鏡作部」。奈良県田原本町に鏡作坐天照御魂神社など | ウィキペディア「銅鏡」 | 確認済み（ウィキペディア） |
| 神原神社古墳（景初三年鏡）は、出雲国風土記に載る神原神社の旧社殿の下にあった。神社を移転した後に発掘され、石室は境内に移築復元 | ウィキペディア「神原神社古墳」 | 確認済み（ウィキペディア）。→「神社の真下に卑弥呼の年号の鏡が眠っていた」は映像向き |

- 神社の御神体として鏡をまつる例が多いことは一般によく知られるが、「御神体が鏡である神社の数」などの数字は**未確認**（使わない）。

## D-3 鏡を割って埋める（破鏡・破砕鏡）

- **破鏡**：鏡の破片に穴をあけたり縁を磨いたりして使ったもの。弥生時代後期〜古墳時代前期。集落・祭祀遺構から出る例が多い（山形県の報告では集落・祭祀遺構99点、墳墓62点）。
- **破砕鏡**：鏡を意図的に細かく割って副葬したもの、と区別されることが多いが、研究者により区別に揺れがある。
- 出典：辻田淳一郎の英文論文（SEAA）、各地の発掘報告（いずれも検索抜粋）
- 確かさ：報道ベース（検索抜粋）。定義は研究者で異なる★
- **平原遺跡**：1号墓の銅鏡は破砕した破片で見つかり、39〜40面分に復元。ただし発掘責任者の原田大六は「人為的に破砕されたモノではない」と報告している（ウィキペディア「平原遺跡」）。→ 確認済み（ウィキペディア）。**「平原の鏡はわざと割った」と断定しない**（説が分かれる）
- 神原神社古墳の近くの土井・砂古墳から破鏡が出ている（ウィキペディア「神原神社古墳」）→ 確認済み
- 破鏡の意味（鏡を分けて持つ、死者の力を封じる等）は諸説あり、**どれも確定していない**

## D-4 都市伝説・よく言われる説

### D-4-1 「卑弥呼の鏡は魔鏡」「光を当てると絵が浮かぶ」
| 事実 | 出典 | 確かさ |
|---|---|---|
| 魔鏡＝鏡面のわずかな凹凸のため、光を反射させると背面の文様などが反射光の中に浮かぶ鏡。磨くとき、薄くなった鏡が背面の凹凸の厚みの差でしなり、鏡面に微細な凹凸ができる | ウィキペディア「魔鏡」 | 確認済み（ウィキペディア） |
| 最も古い魔鏡は紀元前1世紀頃の前漢の「透光鑑」 | ウィキペディア「魔鏡」 | 確認済み（ウィキペディア） |
| 2014年1月29日、京都国立博物館の村上隆・学芸部長が、三角縁神獣鏡の3Dプリンター製レプリカに太陽光を当てると、壁に映した反射光に背面の文様が浮かぶ「魔鏡現象」を確認したと発表。国内の古代鏡で確認されたのは初めて。対象は愛知県犬山市・東之宮古墳出土の鏡2面。三角縁神獣鏡の平均的な組成と同じ比率の銅・スズ・鉛の金属粉を使い、レーザー積層造形で製作 | 日本経済新聞 2014年1月（検索抜粋）https://www.nikkei.com/article/DGXNASHC2902G_Z20C14A1000000/ | 報道ベース（検索抜粋）。発表日・東之宮古墳・2面は検索抜粋のみ★ |
| 村上隆の論文：三次元デジタイザで形状を計測し、成分を調整した金属粉の3Dプリンターで三角縁神獣鏡を精確に復原、その鏡面が太陽光で「魔鏡現象」を起こすことを実証。「すでに500枚を超える出土がある。いつ、どこで、誰がどうやって作ったかもわからない謎の鏡」 | 村上隆「『三角縁神獣鏡』にみる『魔鏡現象』」『化学と教育』64巻5号、日本化学会、2016年5月20日発行 https://www.jstage.jst.go.jp/article/kakyoshi/64/5/64_242/_article/-char/ja/ | 確認済み（J-STAGE抄録） |
| ウィキペディア「魔鏡」も「古墳時代の三角縁神獣鏡で魔鏡の現象が確認されている」 | ウィキペディア「魔鏡」 | 確認済み |
| 判決の材料：確認されたのは**3Dプリンターで復元した複製（磨いた新品の状態）**での現象。出土した実物は錆びていて光を反射しないので、実物で確かめたわけではない。卑弥呼の時代の人が魔鏡として使った、あるいは意図して作った証拠は**ない**（未確認） | 上記を踏まえた整理 | 「意図して作ったかは分からない」は推論。台本では「わざと作ったのかは分かっていない」と言う |
| 隠れキリシタンの魔鏡（キリスト像などが浮かぶ）が西南学院大学博物館などにあるが、魔鏡を信仰に用いた事実はないとされる | ウィキペディア「魔鏡」 | 確認済み（ウィキペディア） |
| 日本の魔鏡は1877〜78年に東京大学のアトキンソン、工部大学校のエアトンとペリーが英国で紹介・原理を解明 | ウィキペディア「魔鏡」 | 確認済み（ウィキペディア） |
| 魔鏡を作る職人は国内で京都の山本合金製作所（山本晃久さん）だけ（2015年時点の報道）。1974年に山本真治（凰龍）が魔鏡を復元、ローマ教皇に1990年と2014年に献上 | Yahoo!ニュース（THE PAGE）2015年7月31日 https://news.yahoo.co.jp/articles/c9b83b525458adeb385f8de2b9ea9331f9534411 ／ウィキペディア「魔鏡」 | 確認済み（2015年時点。現在も唯一かは未確認） |

### D-4-2 「卑弥呼の墓から三角縁神獣鏡が出る」
- 卑弥呼の墓の候補とされる箸墓古墳（約280m）は宮内庁が倭迹迹日百襲姫命の「大市墓」として管理し、墳丘への自由な立ち入りは禁止。埋葬施設は不明で、**鏡が出たという記録はない**。
- 出典：ウィキペディア「箸墓古墳」／共同通信 2026年2月19日（渡り土堤の発見、C-4）
- 確かさ：確認済み（「鏡の出土記録はない」はウィキペディアの記述に鏡がないことによる推定。断定するなら要確認★）
- 判決の材料：三角縁神獣鏡が大量に出る古墳（黒塚・椿井大塚山など）は**卑弥呼の死（247〜248年頃）より後**の3世紀後半〜4世紀の古墳。森浩一は「鏡の多くは4世紀の古墳から出る」として否定論の根拠にした（ウィキペディア「三角縁神獣鏡」）。→ 確認済み
- 卑弥呼の墓の記述は「径百余歩」「徇葬者奴婢百余人」（A-1-5）。倭人伝には墓に鏡を入れたという記述はない → 確認済み（倭人伝の該当部に鏡の語はない）

### D-4-3 「景初四年の鏡は偽物」
- 景初四年は存在しない年号だが、広峯15号墳の鏡は1986年の正式な発掘で出土しており、出土品として重要文化財。偽物（後世の偽造）ではない。
- 解釈：①魏の都から遠い場所で、改元を知らずに作った（近藤喬一1988：製作地が洛陽でなかった、または誤記）、②国産説の根拠（王仲殊）、など。
- 出典：ウィキペディア「三角縁神獣鏡」「広峯15号墳」
- 確かさ：確認済み（ウィキペディア）
