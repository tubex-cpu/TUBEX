# Gemini に依頼するサムネの文章：もしも全人類が1000年眠ったら

社長（2026-11-26）「サムネ1cmと1000年のものはGeminiに依頼する文章を作成して」。
コピーとタイトルの3組は `03_plan.md` ④。企画の全容は `03_plan.md` ①〜⑥。

## 使い方
1. Gemini に「0. 最初に渡す依頼」を貼り、続けて案A・B・Cを1つずつ貼る。
2. 文字（コピー）は Gemini に入れてもらう。日本語が崩れたら「直すときの決まり文句」の最後の文で**文字なし版**を頼み、Claude がチャンネルの書体（M PLUS Rounded 1c Black、白に黒の太フチ、強調語だけ黄色）で入れる。
3. できた画像を `pilots/moshimo-1000nen/outputs/thumb_gemini_A.png` などに置けば、Claude が 320px での見え方・CLAUDE.md のサムネ監査基準（権利・事実性・スマホ視認性ほか）で確かめる。Gemini の利用はいまの契約の範囲内（追加費用0）。

## 0. 最初に渡す依頼（共通）
```
YouTube動画「もしも全人類が1000年眠ったら」のサムネイル画像を作ってください。横長16:9、1280×720以上。

【絵柄】
- ローポリ（面のある多面体）の3DCG。人・木・建物すべて同じローポリの質感。ゲームの1場面のような、映画的な照明。
- 光ははっきりした明暗差。主役に強い光を当て、背景は少し暗く、主役が浮き出るように。主役にピント、奥はぼかす。
- 色は鮮やかに。ただし漫画やアニメのような太い輪郭線、ゆるキャラの顔にはしない。

【文字】
- 指定した2行の日本語だけを入れる。極太の丸ゴシック体、白い文字に黒の太い縁取りと影。指定した語だけ黄色。
- 上の行は小さめ、下の行を大きく。2行とも一瞬で読める大きさ。
- 文字は絵の主役（人の顔・塔など）に重ねない。空や地面など単純な所に置く。
- 文字の一字一字を正確に。指定外の文字・記号・ロゴ・透かしは入れない。

【構図のルール】
- 右下の角（再生時間が出る場所）に大事なものを置かない。
- 線・泡・光の飾りなど、意味のない装飾は入れない。
- 実在の人物・ブランドの看板・キャラクター・他の動画の画像は入れない。

これから3案を1枚ずつ頼みます。まず「案A」を作ってください。
```

## 案A（推奨）コピー「全人類が／1000年眠ったら」
```
案A。文字：上の行「全人類が」、下の行「1000年眠ったら」（「1000年」だけ黄色）。

- 舞台は、渋谷のスクランブル交差点が千年たって森になった場所。夕方、オレンジ色の夕日が低く差し込む。
- 手前に、横向きに眠る一人の男性の顔を大きく。目を閉じ、穏やかな寝顔。服や髪の上に苔と小さな草が生え、肩のそばから細い木の芽が伸びている。
- その奥に、同じように道に横たわって眠る人々が何十人も続き、横断歩道の白い縞が苔と草のすき間から少しだけ見える。
- まわりには大きな木が育ち、崩れて苔むしたビルの柱だけが残る。
- 画面の上部は夕焼けの空で空けておき、そこに文字を入れる。
```

## 案B　コピー「1000年後の／渋谷」

```
案B。文字：上の行「1000年後の」、下の行「渋谷」（「渋谷」だけ黄色）。

- 夜。森になった渋谷のスクランブル交差点を、地面すれすれの低い位置から見上げる。

- 画面の下側は暗い地面で空けておき、そこに文字を入れる（右下の角はさける）。
```

## 直すときの決まり文句
- 「文字が崩れています。『（正しい文字）』と一字ずつ正確に入れ直してください。」
- 「主役（寝顔／塔）がもっと大きく見えるよう、カメラを近づけてください。」
- 「物が多すぎます。背景をぼかして、主役だけが目に入るようにしてください。」
- 「文字が絵の主役に重なっています。空いている所へ移してください。」
- 「漫画っぽく見えます。輪郭線をなくし、ローポリの3DCGの質感にしてください。」
- 「文字を入れない版も、同じ絵で作ってください。」

## 根拠（本編の回収）
- A：SCENE 01（交差点で全員が眠る）・14（千年後、森の中で目を覚ます）。
- B：SCENE 06・10・13（道路から木、森の東京、目を覚ます）・15（渋谷の空に天の川）。
- C：SCENE 12（法隆寺は何百年かごとに解体・組み直し、伊勢神宮は20年ごとに建て替え：F21・F24）。「法隆寺が手入れなしで千年もつ」とは言わない（`03_plan.md` ⑥）。
- 渋谷から天の川が見えるのは物語の出来事（`03_plan.md` ⑥）。
