# 必須カット一覧：もしも人類が、眠れなくなったら？

`03_script.md` の章番号と対応する。★は定点（毎回同じカメラ位置・画角）。3D は猫動画の作り方（`pilots/moshimo-neko-meow/video/`、Blender Workbench・箱と球の簡易人物）で作れる範囲に絞った。人物は止めず、まばたき・首・呼吸を常に動かす（CLAUDE.md ルール⑪）。ただし「眠れない」設定なので、**目を閉じたまま動かない姿（眠っているように見える姿）は第14章まで一切使わない**。横になる場面では、まぶたや指を必ず動かす。

## 定点（全編で同じ構図を使い回す）
| ID | 定点 | 使う章 | 状態の変化 |
|---|---|---|---|
| ★A | 夜の団地の外観（向かいの棟から、森家の窓が中央） | 00・01・09・14・15 | 午後11時に明かりが消える → 午前4時に一つずつ点く → 午前3時に全部点いている → 10日目の夜に一つずつ消える → 11日目の夜、森家の窓が消える |
| ★B | 森家の台所テーブル（冷蔵庫と壁の時計が見える） | 01・03・06・07・09・10・13・14・15 | 冷蔵庫の扉の貼り紙が 0→3→4→5枚 と増える。時計の時刻 |
| ★C | バス営業所の点呼台 | 02・05・15 | 「運転できます」→ 全員が首を振る → 「眠れましたか」にうなずく |
| ★D | 救急外来の待合室（受付から） | 00・08 | 午前3時に満員 → 夜も朝も人数が変わらない |
| ★E | 団地前の交差点（歩道橋から） | 00・02・04・05・09・15 | ブレーキの遅れ → 運休の紙のバス停 → 夜に人が歩く車道 → ガードレールの花 |

## テロップ（語りを補う。研究の数字は出さない）
- 左上：「◯日目 ◯時｜場所」
- 右上：経過バー（1日目の夜〜10日目の夜、眠れなかった日数）
- 要点カード（例）
  - 「眠気はある。眠れない」
  - 「見えているのに、反応が遅れる」
  - 「眠れていない運転者は、乗せない」
  - 「止めることで守る命、待たされる命」
  - 「麻酔は、眠りの代わりにならない」
  - 「支える人も、眠れていない」
- 冒頭：「もしもの世界を描いたフィクションです。人物・団地・病院は架空です」
- 第5章の決まりのテロップには、小さく出典を添える：「国土交通省：睡眠不足の乗務員を乗務させてはならない（2018年）」
