# 企画書：もしも世界から電波が消えたら？

チャンネル「世界をズラす」の3D「もしも」動画（3D映像・VOICEVOX 男性ナレーション・字幕）。テーマは社長の言葉「電波が遮断された世界どうなる？」。
本編 約18分04秒（`03_script.md` 末尾の見積もり。エンドカード込み 約18分09秒）。全20場面。
根拠の番号【F◯】は `01_research.md` の資料表、【P◯】はこの世界の仮定（下の②）、【R◯】は推論。競合は `02_competitors.md`。

## ① 企画戦略と狙い

- **想定視聴者**：「もしもインターネットが消えたら」の短尺（13万〜210万再生）を見ている10〜40代。スマホを手放せない自覚があり、「自分の生活のどこが止まるか」を知りたい人。
- **誰でも予想する展開**（競合の短尺がほぼこの並び）：スマホが圏外 → ネットが止まる → 公衆電話に行列・伝言板・紙の地図 → 昭和に戻る → 不便だけど静かで意外と幸せ。
- **狙い**：この予想を最初の約1分で見せきり、残りの17分を「電波に頼っていると知らなかったもの」が時間とともに止まる連鎖と、「ネットは死んでいなかった」という逆転、そのあと人が線と光で暮らしを組み直す景色にあてる。
- **差別化**：同テーマの長尺（ウラガワ3D 10:39・468再生、ずんだもん解説 12:40・54再生）は「〜かもしれません」の断り・解説・答え合わせの章で勢いが止まる。本作は解説の章を持たず、仕組みは場面の中で一文だけ言い切る。

## ② 前提・ルール（語りでは説明しない）と構成

**前提とルール**
- **P1 消えるもの**：電波法でいう「電波」（3THz以下の電磁波）が、空間を伝わらなくなる【F1】。携帯電話・Wi-Fi・Bluetooth・GPS・テレビとラジオの放送・業務無線（航空・鉄道・消防救急・船）・レーダー・衛星との交信・電波時計の標準電波・防災行政無線・医用テレメータ・車の鍵（スマートキーとイモビライザー）・かざすICカード、そして電子レンジの中のマイクロ波まで、すべて。
- **P2 残るもの**：電線と光ファイバーの中を流れる電気と光（固定電話・公衆電話・有線のネット・発電と送電）。光（赤外線・可視光）は電波ではないので届く【F1・F3】。音。機器の中で電線でつながって動くもの（ペースメーカーの拍動など）。
- **P3 始まり**：晴れた平日の午後に、世界中で同時に消える。夜や雲の中の飛行の場面は描かない。
- **P4 終わり**：電波は戻らない。1か月後まで描き、終わりは描かない。
- **描かないこと**：死者数・事故件数・被害額（資料がない）。飛行機の墜落などの劇的な事故。理由（なぜ電波が消えたか）。

**視聴後の発見**
- 電波が消えても、ネットは消えない。消えるのは「どこでもつながる」ことだけ。ネットの本体は、海の底と地面の下の線の中にあった。
- 電波は、スマホより先に、台所の電子レンジ、車の鍵、救急車、病院の心電図、天気予報、夕方のチャイム、時計を動かしていた。
- 電波のない世界で、人は昔に戻るのではなく、線と光と足で今の町をつなぎ直す。

## ③ 予想を超える因果と具体的な場面

1. **ネットは死んでいない**（SCENE 03 伏線 → 12 → 13・14）：国を越えるデータの99%は海底ケーブル【F28】、基地局までは線【F29】。止まったのは手元までの無線の区間だけ【R7】。→ 壁の差し込み口が町でいちばん大事な場所になり、LANケーブルが売り切れ、差し込み口のない部屋が離れ小島になる。
2. **スマホより先に止まる、見えない電波**：
   - 電子レンジは電波で温めていた【F2】→ 回るのに冷たいご飯、コンビニの「温めますか」が消える（SCENE 03・05）
   - 車の鍵のチップの合図【F6・F7】→ 新しい車ほど止まり、古い軽トラックだけ動く。走っている車はエンジンを切れず、給油で首を振る（SCENE 04）【R2】
   - 消防救急無線【F15】→ 固定電話の119は届くのに、救急車に次の出動が届かない（SCENE 06）【R4】
   - 防災行政無線【F25】→ 夕方のチャイムが鳴らず、子どもが帰る時間が分からない（SCENE 09）
   - 医用テレメータ【F18】→ 心電図の画面が消え、看護師が歩いて回る。ペースメーカーは自分の電池で動き続ける（SCENE 10）【R6】
   - 衛星・レーダー・観測所の回線【F20〜F22】→ 天気予報が出ず、予報官が屋上で空を見る（SCENE 11）
3. **時間がそろわなくなる**（SCENE 18）：電波時計は標準電波で時刻を直していた【F12】。直らなければ時計は1か月で15〜30秒ずれる【F13】→ 学校のチャイムと駅の時計がずれ、117【F14】に列ができる【R11】。
4. **光が戻ってくる**（SCENE 02・03・15・20）：光は電波ではない【F1】。リモコン【F3】、管制塔のライト【F8】、船の信号灯【F24】、灯台の光り方【F23】が、電波の代わりに言葉を運ぶ【R9】。

## ⑤ 推奨案と理由

**推奨はA。**
- 競合では「インターネットが消えたら」が13万〜210万再生、「電波が消えたら」は最大6,847再生（`02_competitors.md`）。視聴者が反応するのは「電波」より「ネット」「スマホ」の言葉なので、タイトルの後半とコピーにそれを置く。
- そのうえで「ネットが消える」と思って開いた人の予想を、事実（海を越えるデータの99%は海底ケーブル【F28】）で裏切れる。同テーマの競合は短尺・長尺とも、この逆転を本編の軸にしていない。
- 本編の早い段階（SCENE 03、開始1分49秒）に伏線があり、中盤（開始10分28秒〜11分19秒）で回収するので、序盤の離脱を伏線で支え、中盤に山を作れる。
- Bは前半の芯、Cは結末の芯として、本編ではどちらも回収している。
