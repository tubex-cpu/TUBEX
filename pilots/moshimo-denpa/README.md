# もしも世界から電波が消えたら？（台本 第1稿）

3D「もしも」動画（チャンネル「世界をズラす」。3D映像・VOICEVOX 男性ナレーション・字幕）。テーマは社長の言葉「電波が遮断された世界どうなる？」。2026-11-24 制作開始。
本編 約18分04秒（エンドカード込み 約18分09秒）。全20場面・202行・4,712字。

## 一行で
電波が消えても、ネットは消えない。消えたのは手元までの最後のひと区間で、電子レンジ・車の鍵・救急車・心電図・天気予報・時計が先に止まり、人は線と光と足で町をつなぎ直す。
