# もしも全人類が、眠らなくてよくなったら？ — 台本 第1稿

- 制作：2026-11-24（Claude Code）。新規作成のため既存台本の上書きなし
- テーマ（社長の言葉）：「睡眠が不要になって24時間全人類が起き続けるなら世界はどうなる？」
- 方針
  - 主語は「あなた」。固有の登場人物は置かない。場所は駅・家・コンビニ・電力会社・線路・家具店・ホテル・海辺・川辺・学校。全22場面。
  - 冒頭は「真夜中の満員電車」から入り、最初の夜へ戻る。理由（眠らなくてよくなった）は SCENE 02 で一度だけ言う。
  - 「時間が増えて得をする」「仕事が増える」は前半の通過点。軸は、夜が消えたことで、夜に任せていたもの（線路の点検・夜の電気・親の時間・怒りが冷める区切り・生き物の暗がり・星空）が回らなくなる連鎖。
  - 結末の発見：眠りは、世界じゅうが一度に止まる時間だった。人類は、眠くないまま、自分たちで夜を作り直す。最後は冒頭の駅に戻る。
  - 保険の言い回し・研究や出典への言及・具体的な日付は入れない。数字は「人生の三分の一」「三人に一人（天の川）」の2つだけ。
