# もしも全人類が、眠らなくてよくなったら？（台本 第1稿）

3D「もしも」動画（チャンネル「世界をズラす」。3D映像・VOICEVOX 男性ナレーション・字幕）。本編 約18分05秒（エンドカード込み 約18分10秒）・全22場面。2026-11-24 制作開始。

## 一行で
眠気も疲れも来なくなった人類から「夜」が消える。終電がなくなって線路を直す時間が消え、夜の電気が余らず、親がひとりに戻る時間も、ホタルの暗がりも、星空も消える。眠りは、世界じゅうが一度に止まる時間だった。眠くないまま、人は夜を作り直す。
