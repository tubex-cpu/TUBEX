# 人も、すべての生き物も、心臓が2つあったら？（台本 第1稿）

## 一行で
心臓が二つになって、命は長くなった。そのかわり一つの命が食べる量が増え、生き物の数は減っていく。数を決めていたのは心臓の数ではなく、食べ物の量だった。
