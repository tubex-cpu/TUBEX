# 猫の鳴き声回：シネマ調（参考画像の雰囲気）の試作

社長（2026-11-22）「猫の動画、この雰囲気で動画を作ることは可能ですか？作れるなら冒頭１分を制作して下さい」（参考：ローポリの面のある猫の群れ、夕焼けの路地、街灯、濡れた路面の画像3枚）、「添付した画像そのままで再現するのは不可能？」。

- `look.py`：本編の部品（kit.py / shots_v5.py）を EEVEE 用の材質・光に置き換える（夕焼けの空、街灯、濡れた路面、面のある猫、猫の顔の細部）
- `render_cine.py`：冒頭1分（SCENE 01 の11カット）をシネマ調で描く。試し描き：640×360・8サンプルで1コマ約9〜14秒
- `test_crowd.py`：参考画像に寄せた1コマの試作（路地を埋める猫の群れ）
- 結論（社長への回答）：Blender（CPU のみ）で添付画像そのままの見た目を動画にするのは不可能。方法の選択（①画像を動かす ②ChatGPT の動画生成 ③3Dの作り込み）を社長に確認中。冒頭1分の本描きは未着手
