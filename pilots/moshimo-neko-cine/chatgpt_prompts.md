## カットごとのプロンプト

### カット1（7秒）窓を開けた瞬間
```
カット1（7秒）。室内から、窓を開けるあなたの目線（主観）。
最初の1秒は閉じたガラス窓。ガラス戸が横に開くと、夕暮れの住宅街が広がる。
窓のすぐ下の塀の上に茶トラ、向かいの家の屋根に三毛、奥の路地に白黒の猫。3匹が同時に口を大きく開けて鳴き始める。
カメラは窓に少し近づき、外の景色が画面いっぱいになる。最後は足元に目を落とすと、部屋の中にも茶トラが1匹、こちらを見上げて鳴いている。
```

### カット2（5秒）隣の家から、道路の向こうから、奥の路地から
```
カット2（5秒）。夕暮れの路地を、猫の目線の低さから。
手前の塀の陰で鳴く猫 → 道路の向こう側で鳴く猫 → さらに奥の路地で鳴く猫、と奥へ向かって猫が次々に鳴く。
カメラはゆっくり奥へ進む。濡れた路面に街灯と猫が映る。
```

### カット3（4秒）世界中の猫が、一斉に鳴き始めました
```
カット3（4秒）。夕暮れの住宅街を高い空から見下ろす。
屋根の上、塀の上、路地、ベランダに、何十匹もの猫が散らばっていて、全員が同時に顔を上げて鳴いている。
カメラはゆっくり引いて、街全体が見える。窓の明かりと街灯が灯り始めている。
```

### カット4（5秒）ごはんをもらっても
```
カット4（5秒）。夕方の台所。床に赤と青のフードボウル。
茶トラがボウルの前で、ごはんを入れてもらっても食べずに、こちら（人）を見上げて口を大きく開けて鳴き続ける。
窓から橙の夕日が差し込み、床に長い影。カメラはゆっくり猫に寄る。
```

### カット5（3.5秒）そして、この声は、やみません
```
カット5（3.5秒）。薄暗い寝室。ベッドの足元（枕から離れた位置）で、丸くなって眠っている茶トラ。
目を閉じたまま、口だけ開いて鳴いている。しっぽの先がゆっくり動く。
窓の外は夕暮れの最後の明かり。枕元の小さなランプが暖かく灯る。猫が枕やふとんにめり込まないように。
```

### カット6（3.5秒）公園の鳩が、いっせいに顔を上げます
```
カット6（3.5秒）。夕方の公園の地面の高さ。ローポリの灰色の鳩が10羽ほど、地面の餌をつついている。
奥の植え込みから猫の鳴き声。その瞬間、鳩が全員いっせいに顔を上げ、つつくのをやめて固まる。
濡れた地面に夕焼けが映る。カメラは止めたまま、少しだけ寄る。
```

### カット7（3.5秒）電線のカラスが、首をかしげます
```
カット7（3.5秒）。電柱と電線を下から見上げる。夕焼けの空を背に、電線にローポリの黒いカラスが4羽。
下の塀の上で黒猫が鳴く。カラスが順に首をかしげて、声のする下の方をのぞき込む。
カメラはゆっくり横に流れる。
```

### カット8（3.5秒）犬が、窓に向かって吠え始めます
```
カット8（3.5秒）。夕方のリビング。ソファの背にのった白い犬（ローポリ、たれ耳）が、窓の外に向かって吠え始める。
窓の外は夕暮れの住宅街。犬は前足をソファの背にかけ、口を開けて何度も吠える。
カメラは犬の横顔が見える斜め前から。
```

### カット9（11秒）道を歩く人が足を止める。猫の姿は見えない
```
カット9（11秒）。夕暮れの細い住宅街の道。仕事帰りの人が3〜5人、こちらへ歩いてくる（ローポリの人、顔は簡単に）。
途中で全員が足を止め、首を左右に動かして、あたりを見回す。
道には猫の姿は一匹も見えない（塀の陰や家の中から声だけが聞こえる設定）。電線、街灯、濡れた路面。
カメラは人の少し前から、ゆっくり後ろへ下がる。
```

### カット10（4.5秒）猫を飼っていない人の部屋
```
カット10（4.5秒）。猫のいない一人暮らしの小さな部屋。ベッド、机、ノートパソコン。
部屋の人が手を止めて、窓の方へ顔を向ける。窓の外は夕暮れの住宅街で、向かいの屋根に鳴いている猫の小さな姿。
部屋の中に猫はいない。カメラは止めたまま、少しだけ窓へ寄る。
```

### カット11（8.5秒）この日から、世界は静けさを失います
```
カット11（8.5秒）。夕暮れの住宅街の路地を、地面すれすれの高さからゆっくり上昇していく。
路地を埋める何百匹もの猫が全員こちらを向いて鳴いている（添付画像1枚目・3枚目の構図に近い）。手前に大きく茶トラ。
カメラは上昇しながら引いていき、最後は街全体と夕焼けの空、灯った街灯が見える高さで止まる。
```
