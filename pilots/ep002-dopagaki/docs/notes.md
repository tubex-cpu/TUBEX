## フル尺 v1（2026-11-05）
- 社長指示（2026-11-05）：「ドパガキの動画制作に進んでください」。
- 台本：Googleドキュメント（https://docs.google.com/document/d/1vTH6tWNgcP7u68tvBEri8etqwS6M5eORaVLonZi0okw/edit）の台本 v2。社長がドキュメント上で直接直した文（冒頭「ドパガキ。人ごとだと思って笑ってはいられません。」「ですがそれに気づかないかぎり、あなたの時間だけでなく、これからも小さな画面の中で溶けていきます。」など）はそのまま使った。ナレーションの元データは `data/script_full.py`。
- 作り方・仕様は ep001 v4 と同じ：
  - 声：VOICEVOX:ナースロボ＿タイプＴ（ノーマル）。1行ずつ合成し、行ごとに音量をそろえる。数字・専門用語の読みは `scripts/make_audio_full.py` の READ（18人中12人・約28万人・前と後 などはカタカナで指定）。
  - BGM：自作合成の4曲（冒頭〜第2章＝不穏、第3〜5章＝謎、第6〜8章＝解説、第9〜10章＝温かい）。95Hz以下を削る。
  - 字幕：1行ずつ・句読点なし（「？」「！」「」は残す）・黒フチなし・少し太く。白い背景の場面（第1章の白い部屋・第2章の最後・第6章のメモと手帳）だけ薄い影。強調語は赤・黄（最大3か所）。
  - 画面に「再現」「CG」「説明図」などの注記は出さない。図解は字幕の帯（下から約150px）に入れない。
  - 演出・効果音：章タイトルのカード（ライザー＋ヒット）、赤の強調語でズーム、強調語にヒット音・キラッ（4秒以上あける）、スワイプ音、電気ショックの音、タイマー音、最後の電源オフ。
- 映像：64場面（`src/full/ScenesA.tsx`・`ScenesB.tsx`・`ScenesC.tsx`、部品は `src/full/kit.tsx`）。寝室・机・リビング・MRI室は3Dの背景CGを静止画で書き出して使用（`src/Stills.tsx` → `public/bg/`）。あなた目線のスマホ、脳の3Dモデル（線条体・島皮質・側頭葉の下側・海馬のそば・前帯状皮質・眼窩前頭皮質の位置を光らせる）、実験の手順カード、グラフ。キャラは傍観者として要所だけ（語らない）。
- 数字の出し方：画面の数字は資料表にあるものだけ（18人中12人・24人中6人・44の国と地域・約28万人・7％→11％・22人と26人・125,198人・2.17倍／1.46倍／2.72倍・寝室にあるだけで1.79倍／1.53倍・467人）。第6章（ショート動画のあとの展望記憶）は成績の数値を出さず「下がった／下がらない」だけを示す。
- 書き出し：1分ごとの分割レンダリング（`scripts/render_segments.mjs`、3本並行）→ `scripts/assemble_full.sh`（字幕は1フレームごとに割り当て、音声は −16 LUFS）。粒子ノイズは書き出しが重く、ffmpeg で足すとファイルが大きくなりすぎるため外した。
