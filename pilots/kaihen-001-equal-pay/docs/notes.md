## 冒頭 v2（2026-11-13）
- 社長「動画の質はかなり上げてほしい」「BGMは大きく変えてほしい」（v1 を見て）
- 映像：3D のミニチュアの日本の街（`src/three/World.tsx`、`src/full/Opening3D.tsx`）。夜明けの空撮 → 巨大な「改」の判子が道路に落ちる（衝撃波・土ぼこり・カメラの揺れ）→ 横断歩道に5人（医者・店員・作業員・部長・あなた）→ 同じ額の給料袋 → 朝日と分かれ道（いつもの職場／別の職場）→ 4人が透け「？」→ 予想カード A・B・C が街の上で回転して出る → ラベルの見方（ガラス風パネル）。被写界深度・ブルーム・ビネット（@react-three/postprocessing）。3D は 1440×810 で描いて 1920×1080 に拡大（書き出し時間を約3分の1に）
- BGM：`scripts/bgm.py`。MIDI を Python で作曲し、FluidSynth＋FluidR3_GM（Frank Wen、MIT ライセンス。/usr/share/doc/fluid-soundfont-gm/copyright）で鳴らす。場面ごとに5つの曲：判子までの低い弦とティンパニのロール → 判子でオーケストラヒット＋シンバル → ピアノの8分・ピチカート・ベース・ドラムの前へ進む曲（朝で長調に）→ 「誰が働く？」でドラムが抜けトレモロの弦 → 予想カードはマリンバの軽い曲（カードごとにチェレスタ）→ ラベルは落ち着いたピアノ。リバーブ・コンプ（pedalboard）。声の間は 0.32 倍に下げる
- ナレーション：EQ（低域カット・3.2kHz を少し上げる）とコンプ
- 効果音：判子の落下（ライザー）と着地の低い衝撃音を 3.55 秒に合わせた
