## ① 企画戦略と狙い
- 想定視聴者：東京に隕石・南海トラフ・首都直下・首都壊滅のシミュレーション動画を見る人（関連動画からの流入）。
- 訴求：競合の当たり軸（「東京駅に隕石が落ちたら」「1mから10kmまで」「直径100kmの隕石が東京に」）をそのまま使い、時間（落ちた瞬間から1日後）・23区・「史上最大（記録に残る最大の落下）」で少しずらす。
- 誰でも予想する展開：巨大なクレーターができ、東京が消える。

## ② 前提と構成・視聴後の発見
- 決めごと（語らない）：記録に残る史上最大の落下（シベリアの空中爆発）と同じものが、平日の朝、東京駅の上空5〜10kmで起きる。
- 構成：二つ目の太陽 → 東京駅の真上で爆発 → シャツが燃えるような熱 → 音のない数十秒 → 真下の木は立ったまま → 外向きに倒れる木 → 新宿に届く音 → 30km先で窓に集まる人 → 割れる窓 → 60km先の熱い風 → 200km先の窓 → 世界の地震計・気圧計 → 1時間後、23区の3倍以上・東京都とほぼ同じ広さ → 穴がない → 窓をふさぐ → 遠くの国の明るい夜 → 1日後 → 本当に起きたこと（シベリア）→ 人のいない森だった → 穴を探した学者 → 近年の窓に集まった町 → 何時間前に見つかるか → ぶつけてそらす → 1日後の東京駅。
- 視聴後の発見：史上最大の隕石は、東京に穴を開けない。空の上で爆発し、地面に一度も触れずに、東京都とほぼ同じ広さの木を倒す。光と音の間の「静かな数十秒〜数分」に窓へ近づくのが一番危ない。

## ③ 予想を超える因果と場面
1. 空中爆発なので穴がない。真下の木は立ったまま、まわりは外向きに倒れる（F5・F16・F17・F31）→ SCENE 05・06・14
2. 光と音の時間差：30km先では1分半、60km先では3分（C2・C5）。その間に人は窓に集まる（F42・F43）→ SCENE 04・08〜10
3. 範囲：木が倒れる範囲は23区の3倍以上、東京都とほぼ同じ（F14・F15・C1）。窓は半径200km近く（F20）→ SCENE 11・13
4. これは本当に起きた。人のいない森の上だった（F3・F22・F24）→ SCENE 18〜20
