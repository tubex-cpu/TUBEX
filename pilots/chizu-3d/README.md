# 地球の事情 3D版（カナダ chizu-003・バミューダ chizu-005）

社長 2026-11-14「if動画ジャンル参入の動画制作のクオリティを真似して１、２の動画を制作し直して欲しい」（対象は社長の選択で「カナダ・バミューダ」）、「今の尺のままで進めて」。
手本はルール改変ニッポン冒頭 v2（`pilots/kaihen-001-equal-pay/`：3Dのミニチュア、被写界深度、光と影、作曲したBGM）。

- **変えないもの**：承認済みの台本・ナレーション・字幕・カットの時刻（カナダ commit ae6a615、バミューダ v4 commit 5012a92）。事実・数字・言い回しは同じ
- **変えたもの**：映像とBGM・効果音。承認済みの版は原本として残し、3D版は別名で書き出す

## 作り方
1. `scripts/plates.py <ca|bm>`：承認済みの描画プログラム（カナダ `render/render.py`、バミューダ `render/render_v4.py`）で、各カットを字幕・ズーム・フェードなしの「プレート」として書き出す（`episodes/<id>/render/out/plates/`、git 外）。地点の点の位置も記録し（`pins_###.json`）、`--json` で `timeline3d.json` にまとめる
2. `scripts/comp3d.py <ca|bm>`：3D合成（numpy / OpenCV。平面の射影変換と解析的な奥行き）
   - 地図：プレートを「地層の断面が見える模型の台」に貼り、リネンの机の上で動くカメラで撮る。日の光の影、落ちてきて刺さる3Dの地図ピン、奥行きに応じたピントのぼけ
   - 図解・章の扉：プレートを厚みのある白いカードにして、ぼかした模型の上に浮かせる
   - 大きな数字：立体の数字ブロックと説明のプレートを模型の上に立てる
   - 地球儀：光と大気のある地球儀（Natural Earth の陰影図）、カナダの輪郭・目的地のピン
   - 字幕：v4 と同じ（丸ゴシック・白・柔らかい影）。仕上げにビネットと粒子
3. `src/heroes/*.tsx`（Remotion + three.js、本物の3D）：見せ場の場面
   - バミューダ `BM-H1`（2.82〜10.81秒、カット1〜3の図解の代わり）：白い階段状の屋根の家並みに雨、最後は家の断面で屋根→雨どい→地下のタンクに水がたまる
   - カナダ `CA-H1`（20.22〜27.87秒、問いの扉の代わり）：森と湖ばかりの広い模型の上を飛び、南の端の家とクレーンが密集した町へ降りる。問いの文言は同じ
   - 書き出し：`node scripts/render_part.mjs <ID> 0 1`（WebGL はソフトウェア描画で約5秒/コマのため、見せ場だけに使う）
4. `scripts/bgm_chizu.py <ca|bm>`：BGM を作曲（MIDI → FluidSynth + FluidR3_GM〈Frank Wen、MIT ライセンス〉。ルール改変ニッポン v2 と同じ方法）。冒頭の盛り上がり、章の扉ごとの短い盛り上がり、章の間は旅・歴史・緊張・探索の曲を約75秒ごとに切り替える。効果音（ピンが刺さる音・数字が立つ低い音）は numpy で合成。ナレーションの下で BGM を下げる
5. `scripts/pipeline.sh`：プレートと見せ場の書き出しを待ち → JSON → BGM・ミックス → 10秒ごとの合成（4並列、途中から再開できる）→ 結合（−15 LUFS）

素材の権利：地図・地球儀は Natural Earth（パブリックドメイン）、フォントは M PLUS Rounded 1c（SIL OFL 1.1）、音源は FluidR3_GM（MIT）。第三者の映像・音源・有料素材は使っていない（追加費用0）。
