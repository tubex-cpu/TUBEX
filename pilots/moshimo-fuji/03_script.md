# もしも富士山が噴火したら — 台本 第1稿

- テーマ：社長（2026-11-27）「B→D→Aの順で制作したい」「A3は被害が最も大きくなる時間と、その後の状態について必ず触れたい」「A3もこの案でOK」「Aの台本制作に進んで」
- 形式：3D「もしも」動画（3D映像・VOICEVOX 男性ナレーション〈玄野武宏〉・1行字幕・状況テロップ）。手本は `pilots/moshimo-nankai/03_script.md`。尺 11〜15分（社長 2026-11-27、B と同じ）
- 承認済みの3組（`03_plan.md` ④）をすべて回収する：A1「東京はどうなる」／A2「首都が止まる」／A3「15日後の東京」（被害が最も大きくなる時間と、その後の状態）
- この「もしも」の決めごと（語りで説明しない）：平日の朝、富士山が江戸時代と同じ規模で噴火し、15日間続く。風は西南西（灰が東京へ向かう）。途中で雨の日がある。
- 方針
  - 冒頭は一番強い場面（東京のオフィスの窓から見える、富士山の噴煙）から入る。
  - 誰でも予想する一次結果（噴煙・溶岩）ではなく、東京に届く灰の連鎖で見せる：3時間後に灰 → 電車と空が止まる → 店の棚 → 雨で停電・断水 → 家にとどまる東京 → 15日目に灰が最も積もる → 噴火が止まっても、灰は止まらない。
  - 結末：噴火は15日で止まる。けれど、東京の灰の暮らしは、そこから始まる。富士山のふもとでは、江戸時代の灰が今も動いている。
  - 配慮：確率・予言・具体的な日付は言わない。けが人・犠牲者・燃える建物は描かない。数字は国の報告書で確認したものを使い、検索結果でしか確認できていない数字（3時間後・2日後5cm・15日目10cm・灰の総量）は、録音前に原文で確かめる（制作メモ参照）。
  - 量は身近なものに例える。研究・出典には語りで触れない。
