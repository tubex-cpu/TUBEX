## ① 企画戦略と狙い
- 想定視聴者：富士山噴火・南海トラフ・首都直下・首都壊滅のシミュレーション動画を見る人（関連動画からの流入）。
- 訴求：競合の当たり軸（「富士山噴火」「首都圏に迫る火山灰」「首都崩壊」）をそのまま使い、東京の視点と時間（3時間後／15日後／その後）で少しずらす。
- 誰でも予想する展開：溶岩と噴石、山の近くの被害。

## ② 前提と構成・視聴後の発見
- 決めごと（語らない）：平日の朝、宝永噴火と同じ規模、15日間、西南西の風、途中で雨の日。
- 構成：窓の向こうの噴煙 → 1時間後に横浜 → 3時間後に新宿が暗くなる → 電車・空港が止まる → 帰れない人 → 棚が空く → 江戸も昼に暗くなった → ガラスの粉 → 滑る道路 → 除いても積もる（2日後）→ 雨で泥・停電・地下鉄・断水 → 動けない車 → 発電所 → 逃げない東京／避難するふもと（1週間後）→ 15日目、噴火が止まり灰が最も多い → 灰の山 → 舞い上がる灰 → 山を下りる泥 → 江戸の灰のその後 → 今も動く灰 → 1か月後の東京。
- 視聴後の発見：東京を止めるのは溶岩ではなく、紙一枚より薄い灰と雨。噴火が止まった日が、東京の灰が一番多い日。噴火は15日で止まるが、灰は三百年たっても止まらない。

## ③ 予想を超える因果と場面
1. 微量の灰で地上の電車が止まる（F13・F14）→ SCENE 04
2. 雨が降ると、0.3cmの灰でも停電し、地下鉄・水・トイレまで止まる（F20・F22・F24〜F26・F32）→ SCENE 12〜15
3. 東京は「逃げない」：30cm未満は自宅で生活継続（F48〜F52）→ SCENE 18・19
4. 噴火が止まった15日目に灰が最も多く、そこから片付けが始まる（F4・F7・F8・F60）→ SCENE 20・21
5. その後：乾いた灰が舞い、ふもとでは少しの雨で泥が流れ、江戸時代の灰は今も動く（F37・F62・F63・F76〜F81）→ SCENE 22〜26
