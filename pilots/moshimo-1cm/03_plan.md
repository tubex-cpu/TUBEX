# 企画書：もしも全人類が1cmになったら

3D映像・ナレーション（VOICEVOX:玄野武宏）・1行字幕・状況テロップの「もしも」動画。チャンネル「世界をズラす」。本編 約8分45秒（エンドカード込み 約8分50秒、15場面）。台本 `03_script.md`、出典 `01_research.md`（F◯＝事実、R◯＝推論）。
社長（2026-11-26）「候補１動画制作まで進めて、他が出さないうちに配信できるように急ぎましょう」。リサーチ `channels/moshimo-3d/research_2026-11-26.md`。

## ① 企画戦略と狙い
- 想定視聴者：もしも系・小人もの・猫の動画を見る10〜40代。
- 誰でも予想する展開：何でも巨大に見える、虫や動物に食べられる。
- 狙い：一次結果（巨大な世界、落ちてもけがをしない、階段は上れない）を前半で見せる。後半は「食べ物がほとんど要らなくなる → 余った食べ物でネズミが増える → 一番こわかった猫が、一番頼れる隣人になる」に着地する。
- 競合との違い：英語圏で伸びた1本（Imagine If Every Human Woke Up 1 cm Tall／Just Imagine if／10:36／45.4万回／2026-10-31 公開／2026-11-26 取得 https://www.youtube.com/watch?v=p7Gc28Jzrfk）と同じ題材。日本語の同じ題材は、ウェブ検索では見つからなかった（YouTube 内の検索は vidIQ のクレジット切れで未実施）。こちらは日本の家（布団・階段・台所の米粒・茶トラ猫）を舞台にし、結末を「猫との関係の逆転」にする。

## ② 前提と構成・視聴後の発見
前提（語りで説明しない）：ある朝、世界中の人が身長1cmになる。身につけていた物も一緒に小さくなる。ほかの生き物・物の大きさは変わらない。

| 段 | 場面 | 何が起きるか |
|---|---|---|
| 入口 | 01 巨大な目 | 目を開けると家の猫の目。前足が持ち上がる |
| 巨大な世界 | 02 布団の山／03 高いビルから飛び降りる／04 下りられるのに上れない | 落ちてもけがをしない。階段は下りられても上れない |
| 世界中で | 05 アリの行列のような人の列 | 車も電車も止まる。人の列とアリの列が同じ大きさ |
| 体の変化 | 06 米一粒の朝ごはん／07 すぐに冷える体 | 米一粒で何日も。でも体はすぐ冷え、少しずつ何度も食べる |
| 外の危険 | 08 雨粒／09 アリとクモ／10 スズメとカラス | 雨粒一つが自分と同じ重さ。クモ・鳥が上から |
| 連鎖 | 11 減らないおにぎり／12 ネズミの夜 | 日本中の食事が村ひとつ分。余った食べ物にネズミが増える |
| 逆転 | 13 金色の目が光る／14 猫のいる家／15 同じ朝 | 猫がネズミを追い払う。人々は猫のいる家の棚で暮らす。冒頭と同じ構図で、猫が目を閉じる |

視聴後の発見：小さくなると、食べ物はほとんど要らない。困るのは、食べ物が余ること。一番こわかった猫が、一番頼れる隣人になる。

## ③ 予想を超える因果と場面
1. 落下でけがをしない（F4・F8）／階段は二十倍以上の壁で上れない（F26）→ 家の二階に戻れない（SCENE 03・04）
2. 米一粒で何日も（R3〜R5、クライバーの法則）。一方、小さな体ほど熱が逃げ、体重あたり多く食べる（F1・F2・F4）（SCENE 06・07）
3. 日本中の一日の食事が、ふつうの人千人あまりの分（R6）→ 食べ物が余る → ネズミが増える（創作）（SCENE 11・12）
4. 猫は小さな動物を狩る（F18）→ ネズミを追い払う → 一番頼れる隣人（創作）（SCENE 13・14）

## ⑥ 根拠と未検証
- 事実（確認済み）：F1〜F4・F8・F9・F13〜F19・F21〜F26 ほか（`01_research.md`）。
- 推論：R1〜R9（体重13mg、1日約0.014kcal、米1粒で約5日、日本中で約1,200人分、雨粒3mm≒体重）。体重比例で計算すると米1粒で約250日になるため、語りは「何日も」にとどめる。
- 創作：ネズミが増える、猫がネズミを追い払って人を守る、棚の上の暮らし。
- 使わない（未確認）：水の膜（F6）、日本の飼い猫の数（F20）、声の高さ（R10）。
