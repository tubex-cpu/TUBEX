# ChatGPT に依頼するサムネのプロンプト：もしも全人類が1cmになったら

社長（2026-11-26）「感情を大きく動かしてCTRが爆上がりするChatGPTに依頼するサムネのプロンプトを制作して」。
コピーとタイトルの3組は `03_plan.md` ④。ChatGPT には**文字なしの絵**だけを作ってもらい、コピーは Claude が猫の回と同じ書体（M PLUS Rounded 1c Black、白に黒の太フチ、強調語だけ黄色）で入れる。理由：生成画像の日本語は崩れやすく、チャンネルの書体をそろえるため。

## 感情を動かす狙い（3案共通）
- **一瞬で分かる大きさの差**：ふつうの物（猫の目・米粒・雨粒）が画面の大半を占め、人はその横で親指ほどの大きさ。比べる物が同じ画面にあるので、320px でも「小さくなった」と分かる。
- **見る人が「自分だったら」と感じる**：舞台は日本の家（布団・台所・玄関先）。小さな人の顔と表情（驚き・おびえ）がはっきり見える大きさにする。
- **次の一瞬が気になる**：猫の前足が持ち上がる、雨粒が落ちてくる直前など、「このあとどうなる？」の瞬間で止める。
- **チャンネルの絵柄**：本編と同じローポリの3D（社長 2026-11-22「動画の切り抜きシーンの一部のような絵風」）。字幕・テロップは入れない。

## 0. 最初に渡す依頼（共通）
```
YouTube動画「もしも全人類が1cmになったら」のサムネイル用の画像を作ってください。文字は一切入れないでください（あとで別に入れます）。

【絵柄】
- ローポリ（面のある多面体）の3DCG。人・猫・家具・植物すべて同じローポリの質感。ゲームの1場面のような、映画的な照明。
- 舞台は日本の家。光ははっきりした明暗差（主役に強い光、背景は少し暗く）で、主役が背景から浮き出るように。
- 被写界深度：主役にピント、奥はぼかす。
- 色は鮮やかに、ただし漫画やアニメのような太い輪郭線・ゆるキャラの顔にはしない。

【大きさ】
- 人間は身長1cm。ふつうの大きさの物の横で、親指ほどの大きさに見えること。
- 小さな人の顔と表情（目を見開いた驚き・おびえ）は、縮小しても分かるように、カメラを人の近くに置く。

【構図のルール】
- 横長 16:9（1280×720 以上）。
- 画面の上部 3分の1（または指定の位置）は文字を入れるので、空や壁など単純な背景で空けておく。主役をそこに重ねない。
- 右下の角（再生時間が表示される場所）に大事なものを置かない。
- 線・泡・飾りなど、意味のない装飾は入れない。

【入れないもの】
- 文字・ロゴ・透かし・字幕。
- 実在の人物・ブランド・キャラクター・他の動画の画像。

これから3案を1枚ずつ頼みます。まず「案A」を作ってください。
```

## 案A（推奨）コピー「全人類が／1cmになったら」
```
案A。布団の上の、身長1cmの人と、家の茶トラ猫。

- 画面の右半分を、茶トラ猫の顔が大きくのぞき込む。金色の大きな目と細くなった黒い瞳が、画面の中でいちばん目立つ。白いひげが電線のように太く見える。
- 猫の前足が、画面の中央上あたりで持ち上がり、肉球が小さな人の真上に影を落としている（振り下ろす直前の一瞬）。
- 画面の左下寄りの布団の上に、パジャマ姿の小さな人が一人、しりもちをついて猫を見上げている。顔は驚きとおびえ。猫の目の横に並ぶと、人は目の大きさより小さい。
- 布団のしわが丘のように、枕が山のように背景にそびえる。朝の窓の光が猫の顔と小さな人を照らす。
- 画面の左上は、白い壁や窓の光で単純に空けておく（文字を入れる場所）。
```

## 案B　コピー「米一粒で／何日も生きる」
```
案B。台所の床の、身長1cmの人と、一粒のご飯。

- 画面の中央に、白く光るご飯粒が一つ。表面のつやまで見える大きさで、小さな人の頭より大きい。
- 小さな人が、そのご飯粒を両腕で抱えて、うれしそうに、少し信じられないという顔でかじっている。
- 背景に、巨大な茶わんと箸の先がぼやけて見え、さらに奥で茶トラ猫の足先が見える（気配だけ）。
- 床のフローリングの木目が、道路のように太く見える。台所の窓からの光で、ご飯粒が輝く。
- 画面の上部は、ぼけた台所の壁で単純に空けておく（文字を入れる場所）。
```

## 案C　コピー「雨粒が／自分と同じ重さ」
```
案C。玄関先の地面の、身長1cmの人と、落ちてくる雨粒。

- 画面の上から、小さな人の胴ほどもある大きな雨粒が、すぐ頭上まで落ちてきている。すでに地面に落ちた雨粒は、王冠のように大きくはじけて水しぶきが人の背より高く上がっている。
- 小さな人は、大きな葉っぱの下へ駆け込む途中で、雨粒を見上げて叫んでいる。
- 背景に、ぼけた玄関のドアと植木鉢が、ビルのように大きくそびえる。
- 灰色の雨空。雨粒だけに光が当たり、透明なしずくの中に景色が映っている。
- 画面の上部の左右どちらかは、雨空で単純に空けておく（文字を入れる場所）。
```

## 直してもらうときの決まり文句
- 「小さな人が分かりにくいので、カメラをもっと人に近づけて、顔の表情を大きくしてください。大きさの差は保ってください。」
- 「主役以外の物が多すぎます。背景をぼかして、主役と小さな人だけが目に入るようにしてください。」
- 「上部の文字を入れる場所に物が入っています。そこを空けてください。」
- 「漫画っぽく見えます。輪郭線をなくし、ローポリの3DCGの質感にしてください。」

## 受け取ったあと（Claude が行う）
- `outputs/thumb_chatgpt_A.png` などに保存し、`thumbs/compose.py` と同じ型でコピーを入れる（絵と文字を重ねない）。

- `CLAUDE.md` のサムネ監査基準（権利・事実性・スマホ視認性ほか）で監査する。生成画像の利用は ChatGPT のサブスク枠内（追加費用0）。
