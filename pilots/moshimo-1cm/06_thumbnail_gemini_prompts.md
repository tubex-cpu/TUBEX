# Gemini に依頼するサムネの文章：もしも全人類が1cmになったら

社長（2026-11-26）「サムネ1cmと1000年のものはGeminiに依頼する文章を作成して」。
コピーとタイトルの3組は `03_plan.md` ④。企画の全容は `03_plan.md` ①〜⑥。ChatGPT 用の文章は `06_thumbnail_chatgpt_prompts.md`（絵の指定は同じ。こちらは文字も Gemini に入れてもらう）。

## 使い方
1. Gemini に「0. 最初に渡す依頼」を貼り、続けて案A・B・Cを1つずつ貼る。
2. 文字（コピー）は Gemini に入れてもらう。日本語が崩れたら「直すときの決まり文句」の最後の文で**文字なし版**を頼み、Claude がチャンネルの書体（M PLUS Rounded 1c Black、白に黒の太フチ、強調語だけ黄色）で入れる。
3. できた画像を `pilots/moshimo-1cm/outputs/thumb_gemini_A.png` などに置けば、Claude が 320px での見え方・CLAUDE.md のサムネ監査基準で確かめる。Gemini の利用はいまの契約の範囲内（追加費用0）。

## 0. 最初に渡す依頼（共通）
```
YouTube動画「もしも全人類が1cmになったら」のサムネイル画像を作ってください。横長16:9、1280×720以上。

【絵柄】
- ローポリ（面のある多面体）の3DCG。人・猫・家具・植物すべて同じローポリの質感。ゲームの1場面のような、映画的な照明。
- 舞台は日本の家。光ははっきりした明暗差。主役に強い光を当て、背景は少し暗く、主役が浮き出るように。主役にピント、奥はぼかす。
- 色は鮮やかに。ただし漫画やアニメのような太い輪郭線、ゆるキャラの顔にはしない。

【大きさ】
- 人間は身長1cm。ふつうの大きさの物の横で、親指ほどの大きさに見えること。
- 小さな人の顔と表情（目を見開いた驚き・おびえ）が、縮小しても分かるように、カメラを人の近くに置く。

【文字】
- 指定した2行の日本語だけを入れる。極太の丸ゴシック体、白い文字に黒の太い縁取りと影。指定した語だけ黄色。
- 上の行は小さめ、下の行を大きく。2行とも一瞬で読める大きさ。
- 文字は小さな人や主役（猫の目・米粒・雨粒）に重ねない。壁や空など単純な所に置く。
- 文字の一字一字を正確に。指定外の文字・記号・ロゴ・透かしは入れない。

【構図のルール】
- 右下の角（再生時間が出る場所）に大事なものを置かない。
- 線・泡・光の飾りなど、意味のない装飾は入れない。
- 実在の人物・ブランド・キャラクター・他の動画の画像は入れない。

これから3案を1枚ずつ頼みます。まず「案A」を作ってください。
```

## 案A（推奨）コピー「全人類が／1cmになったら」
```
案A。文字：上の行「全人類が」、下の行「1cmになったら」（「1cm」だけ黄色）。

- 布団の上の、身長1cmの人と、家の茶トラ猫。
- 画面の右半分を、茶トラ猫の顔が大きくのぞき込む。金色の大きな目と細い黒い瞳が、画面の中でいちばん目立つ。白いひげが電線のように太く見える。
- 猫の前足が画面の中央上あたりで持ち上がり、肉球の影が小さな人の真上に落ちている（振り下ろす直前の一瞬）。
- 画面の左下寄りの布団の上に、パジャマ姿の小さな人が一人、しりもちをついて猫を見上げている。顔は驚きとおびえ。人は猫の目より小さい。
- 布団のしわが丘のように、枕が山のように背景にそびえる。朝の窓の光が猫の顔と小さな人を照らす。
- 画面の左上は白い壁や窓の光で空けておき、そこに文字を入れる。
```

## 案B　コピー「米一粒で／何日も生きる」
```
案B。文字：上の行「米一粒で」、下の行「何日も生きる」（「何日も」だけ黄色）。

- 台所の床の、身長1cmの人と、一粒のご飯。
- 画面の中央に、白く光るご飯粒が一つ。表面のつやまで見える大きさで、小さな人の頭より大きい。
- 小さな人が、そのご飯粒を両腕で抱えて、うれしそうに、少し信じられないという顔でかじっている。
- 背景に、巨大な茶わんと箸の先がぼやけて見え、さらに奥で茶トラ猫の足先が見える（気配だけ）。
- 床のフローリングの木目が道路のように太く見える。台所の窓からの光で、ご飯粒が輝く。
- 画面の上部はぼけた台所の壁で空けておき、そこに文字を入れる。
```

## 案C　コピー「雨粒が／自分と同じ重さ」
```
案C。文字：上の行「雨粒が」、下の行「自分と同じ重さ」（「同じ重さ」だけ黄色）。

- 玄関先の地面の、身長1cmの人と、落ちてくる雨粒。

- 画面の上部の左右どちらかは雨空で空けておき、そこに文字を入れる。
```
