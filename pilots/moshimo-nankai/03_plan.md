## ① 企画戦略と狙い
- 想定視聴者：南海トラフ・首都直下・首都壊滅・隕石などのシミュレーション動画を見る人（関連動画からの流入を狙う）。
- 訴求：伸びた競合と同じ軸（「もしも南海トラフ巨大地震が起きたら」）を使い、切り口だけを少しずらす（発生から1か月の時間の流れ／東京の視点／2回続けて来たら）。
- 誰でも予想する展開：大きな揺れと巨大な津波。

## ② 前提と構成・視聴後の発見
- 決めごと（語りで説明しない）：平日の昼。震源域の東の半分が先に動き、約1日半後に西の半分が動く（安政東海・安政南海の約32時間差の前例に合わせた設定。予言ではない）。
- 構成：長い揺れ → 高い所へ → 2分後の海 → 東京の高い階だけが揺れる → エレベーター → 新幹線 → 飛行機 → 地下街に水 → 帰れない人 → 揺れたのは半分だけ（巨大地震警戒）→ 歩いて帰る東京 → 揺れていない町が逃げる → 2回目 → 誰もいない海岸に来る波 → 2回目で崩れる家 → 届かない知らせ → 川をせき止める山 → 避難所は3日目から混む → 一本の道がふさがる → 役場も被災 → 貨物列車 → 港 → 揺れなかった東京の棚 → 前にもあった空っぽの棚 → 道を直す人 → 昔、高い所へ導いた火 → 1か月後の東京。
- 視聴後の発見：東京は壊れなかったのに止まった。止めていたのは揺れではなく、西とつながる一本の道。2回目の巨大地震では、1回目の知らせで逃げた町の海岸に誰もいなかった。

## ③ 予想を超える因果と場面
1. 震源から遠い東京は、地面より高いビルの上の階が長く揺れる（F2・F22・F23・F33・F34）→ SCENE 04・05
2. 2回目は「揺れていない町が先に逃げる」ことで、海岸に誰もいない（F45〜F47・F57、R5）→ SCENE 10・12〜14
