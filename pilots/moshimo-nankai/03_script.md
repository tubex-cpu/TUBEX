# もしも南海トラフ巨大地震が起きたら — 台本 第1稿

- テーマ：社長（2026-11-27）「B→D→Aの順で制作したい」「訴求は競合の当たっている物を少しずらすだけ」「Bはサムネ・タイトル３パターン全て承認、台本制作まで進めて。動画尺は１１〜１５分」
- 形式：3D「もしも」動画（3D映像・VOICEVOX 男性ナレーション〈玄野武宏〉・1行字幕・状況テロップ）。手本は `pilots/moshimo-1000nen/03_script.md`
- 承認済みの3組（`03_plan.md` ④）をすべて本編で回収する：B1「巨大地震が来たら（発生から1か月）」／B2「東京はどうなる」／B3「2回来たら」
- 方針
  - 冒頭は一番強い場面（平日の昼、海沿いの町で長い揺れ、2分後の海）から入る。
  - この「もしも」の決めごと（語りで説明しない）：平日の昼に、震源域の東の半分が先に動き、約1日半後に西の半分が動く（江戸時代の終わりに、約32時間の差で2回起きた前例に合わせた設定。実際にどちらの形で起きるかは分からない）。
  - 誰でも予想する一次結果（大きな揺れと津波）は見せたうえで、時間ごとの連鎖に広げる：東京の高層ビルだけが長く揺れる → 止まった新幹線と空の飛行機 → 帰れない人 → 2回目 → 避難所は翌日より3日後に混む → 東西をつなぐ道が切れる → 揺れの小さい東京の棚が空く → 1か月後、直す人が道をつなぐ。
  - 結末：東京は壊れなかった。それでも東京は止まった。止めていたのは揺れではなく、西とつながる一本の道だった。
  - 配慮（`01_research.md` 3節）：死者数・確率・予言・具体的な日付は語らない／テロップにも出さない。犠牲者・遺体・火災は映さない。特定の町が「消える」とは描かない。買いだめをすすめない。数字は国の想定（国交省計画 第4版）で確認できたものだけ。
  - 量は身近なものに例える。研究・出典には語りで触れない。根拠は末尾の「制作メモ（読み上げない）」と `01_research.md`。

## SCENE 01　長い揺れ　【平日の昼】
**【映像】**
- 平日の昼の、海沿いの港町。漁港、堤防、商店街。昼休みの人が歩いている。
- 地面が揺れ始める。電線が大きく波打つ。揺れが、止まらない。
- 人が立っていられず、しゃがみ込む。
- テロップ：「平日の昼　海沿いの港町」「揺れが止まらない」。

**【読み上げ】**
> 平日の昼。
> 海沿いの町が、揺れ始めます。
> 立っていられないほどの揺れです。
> 揺れは、なかなか止まりません。
> 一分たっても、まだ揺れています。
> 棚の物が落ち、窓ガラスが鳴り続けます。
> 南海トラフで、巨大地震が起きました。

**【音・間】** 町の音（カモメ・車）が地鳴りに変わる。最後の1行の後、映像の間3秒。
