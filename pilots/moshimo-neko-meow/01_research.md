## B. 仮定（もしもの設定。台本冒頭で示す）

| ID | 仮定 |
|---|---|
| P1 | 対象はイエネコ（飼い猫・野良猫）だけ。ライオンやトラなど野生のネコ科は含まない |
| P2 | 開始は11月下旬のある日、日本時間の午後3時ちょうど。世界中の猫が同じ瞬間に鳴き始める |
| P3 | 猫は数秒おきに鳴き続ける。食べる・飲む・眠る・歩くは普段どおりにでき、体は傷まない。眠っている間も鳴く |
| P4 | 30日後の午後3時、全ての猫が同時に鳴きやむ |
| P5 | 鳴き声の大きさ・高さは、その猫のふだんのニャーのまま。拡声はしない |
| P6 | **ニャー1回の大きさを、1m先で60dB（普通の会話と同程度）と仮定する**。実測の出典がないため（F18）。画面にも仮定と明示する |

## B2. 計算（P6 と F21 から）

| ID | 計算 | 結果 |
|---|---|---|
| C1 | 6億匹が1か所で同時に鳴いた場合：60 + 10×log10(6×10^8) | 約147.8dB → 「約148デシベル」。実際には猫は散らばっているので、この音はどこでも鳴らない |
| C2 | 1匹の声の距離による減衰：60 − 20×log10(r) | 2m＝54.0dB、4m＝48.0dB、10m＝40.0dB、20m＝34.0dB |
| C3 | 中国都市部 ÷ 日本：7,153万 ÷ 915万 | 約7.8倍 → 「8倍近く」。日本の猫と犬の差：915万 − 680万 ＝ 235万 → 「200万匹以上多い」 |

参考：競合ショート（もしもスイッチ）は「1か所に集めたら約170dB」としている。差は1匹あたりの仮定値の違い（170 − 87.8 ≒ 82dB を仮定した計算になる）。本作は数字の大きさではなく「散らばっているので、聞こえるのはそばの1匹」という結論で差別化する

## D. 使わないと決めたもの

- （第2稿で方針変更）鳴き声の音量は、社長の依頼を受けて第4章・第7章で扱う。実測値がないため仮定 P6 を置き、計算 C1・C2 として示す
- 米国・ロシアの飼い猫の頭数：資料ごとに数字が大きく違うため使わない（米国は世帯数 F25、ロシアは順位 F24 だけを使う）
- 地域別の猫の数（アジア4億など）：資料間の内訳が合わないため
- 日本の野良猫の数、獣医師の数：今回は出典を確認していない
- 犬・鳥の「反応」の具体描写：出典がないため、映像の演出にとどめ、ナレーションで断定しない
