# もしも世界中の猫が一斉に鳴き始めたら？（試作・台本段階）

3D「もしも」ドキュメンタリー型の長尺（15〜20分）。「もしも人類が滅亡したら」を参考に作った第4版冒頭（ユーザーのMac上の別フォルダー）と同じ演出の系統で作る想定。

## ファイル
- `03_script.md`：台本 第1稿（14章、約18分の目安。ショット指示・ナレーション・根拠記号つき）
- `01_research.md`：資料表（事実F・仮定P・推論R・使わないもの）

## 企画の狙い
- **視聴者が予想する展開**：うるさくて大パニックになる／鳴き声を全部足すと何dBになるか
- **本編の発見（予想を超える因果）**
  1. 大人の猫は、猫どうしではほとんど鳴かない。6億匹が呼んでいる相手は人間（F1）
  2. 鳴きすぎは病気のサインなので、全部の猫が鳴くと、病気の猫を声で見分けられなくなる（F15→R2）
  3. ふだん鳴かない外の猫が鳴くので、人類が初めて猫を「耳で数える」（F2・F11→R4）
  4. 待ち伏せができなくなって鳥は助かる。一方、ネズミはもともと猫に減らされておらず、隠れる必要がなくなって、かえって表に出る（F12〜F14→R5・R6）
  5. 結末：ニャーは、猫が人間と話すために使う声だった（F7・F8）
- **競合との差別化**：同じテーマの縦型ショート「世界中の猫が"同時に"叫んだら…？」（もしもスイッチ、2026-10-29公開、1分1秒、再生20,586回、vidIQで2026-11-18に取得）は、音の伝わり方と合計の音量（約170dB）が切り口。本作は音量の計算を扱わず、「声の宛先」と「生態系・社会の二次的な変化」を主軸にする
