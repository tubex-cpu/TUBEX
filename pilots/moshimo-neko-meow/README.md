## 企画の狙い
- **視聴者が予想する展開**：うるさくて大パニックになる／鳴き声を全部足すと何dBになるか
- **本編の発見（予想を超える因果）**
  1. 大人の猫は、猫どうしではほとんど鳴かない。6億匹が呼んでいる相手は人間（F1）
  2. 鳴きすぎは病気のサインなので、全部の猫が鳴くと、病気の猫を声で見分けられなくなる（F15→R2）
  3. ふだん鳴かない外の猫が鳴くので、人類が初めて猫を「耳で数える」（F2・F11→R4）
  4. 待ち伏せができなくなって鳥は助かる。一方、ネズミはもともと猫に減らされておらず、隠れる必要がなくなって、かえって表に出る（F12〜F14→R5・R6）
  5. 結末：ニャーは、猫が人間と話すために使う声だった（F7・F8）
- **競合との差別化**：同じテーマの縦型ショート「世界中の猫が"同時に"叫んだら…？」（もしもスイッチ、2026-10-29公開、1分1秒、再生20,586回、vidIQで2026-11-18に取得）は、音の伝わり方と合計の音量（約170dB）が切り口。本作は音量も扱うが（第2稿）、結論は「散らばっているので、聞こえるのはそばの1匹＝家の中の騒音」とし、主軸は「声の宛先」と「生態系・社会の二次的な変化」に置く

## 第3稿の方針（2026-11-19 社長コメント）
- ルール説明・研究や実験の話・断定を避ける言い回し・猫を数える話を削除。うるささは「すぐ横で誰かがしゃべり続けるのと同じ」と例える。ネズミは「出てこない→街から消える」。全体を短く言い切る
- 足した展開：壁の向こうの猫（猫を飼っていない人）、耳栓が消える、眠らない街イスタンブール、猫カフェが閉まる、静かすぎて眠れない夜、鳴きやんだあと人が猫に話しかける

## 第2稿で足したもの（2026-11-18 社長依頼）
- 日本と猫の多い国：中国（都市部の飼い猫 約7,150万匹）・イスタンブールの路上猫・ロシア・アメリカ（第3章）
- 何デシベルか：ニャーの実測データはないため「1m で60dB」と仮定。6億匹を1か所で足すと約148dB、実際は散らばっているので聞こえるのはそばの1匹（2m で54dB）。夜は国の基準 45dB を超える（第4章・第7章）
- 被害と良くなること：被害＝睡眠・病気の見落とし・電話・ネズミ・外猫の空腹、良くなること＝鳥と島の生き物・エンジンルームの猫・迷子の猫・外猫の地図（第8〜12章）
