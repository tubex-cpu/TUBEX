# ②③ 新規2チャンネル（未設計・未開設）

**この2チャンネルが社長の目標の対象**（`docs/社長の前提.md`）：
- 2026-11 までに **2チャンネルとも** それぞれ登録者1,000人・総再生4,000時間を達成して収益化（収益化の条件はチャンネルごとに判定される）
- 2026-12 までに2チャンネル合計で月の収益30万円

社長方針（2026-10-11）：**チャンネル設計・コンセプト・「市場が大きく、かつ穴場」のジャンル選びが一番大事。** ここで手を抜かない。
差別化できていない案は、ゲート0に出さない（`docs/社長の前提.md`「絶対にやらないこと」）。
社長方針（2026-10-11）：**ショート動画は主力にしない**（長尺で総再生4,000時間を狙う）。**避けるジャンルはない**。金融系・健康系は大きな再生数が見込めるので候補に含める（事実は出典つきのルールは同じ）。
ジャンルが決まるまでは動画を作らない。まず「工程0：チャンネル設計」を行う。

## 工程0：チャンネル設計（Claude 実施 → Codex 監査 → ゲート0：社長が2つ選ぶ）
成果物：`channels/new-channels/00_genre_research.md`

1. **候補出し**：日本語 YouTube で、追加費用0・顔出しなし・機械音声（Open JTalk）・Remotion で作れるジャンルを15個以上挙げる。① ハビ判事（都市伝説・歴史ミステリー）と視聴者を食い合うジャンルは除く
2. **実数値の取得**（`pipeline/scripts/yt_research.py`。再生数・登録者数・チャンネル開設日・再生数/登録者を1回で出力する。取得日を記録。キーの値は書かない）。ジャンルごとに：
   - **上限（需要）**：直近2年の上位動画の再生数（最大・10位・30位）
   - **混み具合（供給）**：上位30本を占めるチャンネル数、登録者に対して再生数が大きい動画（小さいチャンネルでも伸びている＝穴場のサイン）の数
   - **新規参入の実績**：開設1年以内のチャンネルが上位に入っているか、そのチャンネルが登録者1,000人に何本・何か月で届いたか（確認できる範囲で。推測しない）
   - **視聴時間の稼ぎやすさ**：上位動画の尺（4,000時間に届くには長尺で見続けられるジャンルが有利）
3. **評価**：①上限が大きい ②供給が薄い（穴場）③差別化できる ④自分たちで作れる ⑤2026-11 の収益化期限に間に合う見込み、の5軸で採点し、根拠の数字を表にする
4. **5案に絞る**：各案にチャンネル名案・コンセプト1文・**競合と比べて何が違うか（差別化2点以上、競合チャンネル名と数字つき）**・初回ネタ3本・本数と尺・期限までに1,000人／4,000時間に届く見込み（計算の根拠つき）・リスクを書く
5. **2つの組み合わせ案**：5案から「2チャンネルとして同時に回す」おすすめの組み合わせを1〜2組示す（制作負荷・視聴者の食い合い・どちらも期限に間に合うか）
6. PR に `@codex review` → 合格後、社長にゲート0の確認を依頼（5案から2つ選ぶ）

確認できない数字は使わない。推測で「伸びている」「穴場」と書かない。期限に間に合わない見込みなら、そう書く（隠さない）。

## 決定後
選ばれた2つをそれぞれ `channels/<名前>/CHANNEL.md` に分け、URL／チャンネル名／本数・尺／キャラ・口調／構成／サムネ方針を書く。
