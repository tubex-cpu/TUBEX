## 4. リメイク案（再生数で元動画を超えるための差別化）
元動画の勝ちパターン（残す）：①「少ない本数で伸びている」という具体的な希望 ②ジャンル別に大量に見せる網羅感 ③「note で売られている情報を無料で」という得した感。

差別化（足す）：
1. **10か月後の答え合わせ**：「2025年12月に"今伸びてる"と紹介された79チャンネルは、今どうなったか」を API の実数値で全件追跡。伸び続けた／止まった／消えたを分類し、**伸び続けたチャンネルの共通点**を出す。常識（「伸びてると紹介されたら勝ち組」）とぶつかり、本編を見ないと答えが分からない。
2. **全数字に取得日つき**：元動画は開設年のずれ等があり、こちらは API 実測＋取得日を画面に出す（社長の前提「事実は出典付き」と一致）。
3. **新顔の追加**：元動画以後に開設して伸びたチャンネル（例：年金・給付金完全攻略 2026-03開設・16本・16.4万人）を「次の79ch」として加える。

タイトル案（仮・工程4で再検討）：
- 「"今伸びてる"と紹介された79チャンネル、10か月後に全部調べたら半分が…」※「半分」等の割合は実測後に確定。確認できない数字はタイトルに入れない
- 【実数値で検証】少ない投稿数で伸びたチャンネル、その後も伸び続けたのはどれか
- 2026年に本当に伸び続けた顔出しなしチャンネル（取得日つき全データ）

## 5. 制約・リスク
- **ゲート0未通過**：このジャンルを新チャンネルにするかは社長判断。① ハビ判事とは視聴者が重ならない。
- **API 無料枠**：79件を名前検索すると search.list 100単位×79＝約7,900単位（1日上限10,000の大半）。チャンネル ID／ハンドルを元動画の概要欄・画面から拾い channels.list（1単位/50件）で引けば数十単位で済む。
- **サムネ監査のブロッカー**：この環境から i.ytimg.com が 403 で遮断され、競合サムネの実画像を取得できない（2026-10-15 確認）。CLAUDE.md の基準によりサムネ比較監査は「判定保留」になる。環境のネットワーク設定で i.ytimg.com の許可が必要。
- ジャンル特有のリスク：同ジャンル上位は「収益公開」系（例：ふつうのくま 686,777回、サモン 457,208回）で、実績のない新チャンネルは出せない。追跡・データ検証型なら実績なしで作れる。
