- 制作済み・制作中の題材：
  - もしも世界中の猫が一斉に鳴き始めたら？（完成。`pilots/moshimo-neko-meow/03_script_v5.md`、`outputs/neko_v4_preview_720p.mp4` は git 外のため台本で確認）

  - もしも人類が、眠れなくなったら？（台本）
  - もし日本でパリやスペインのようなストライキが起こったら？（台本）
- サムネの方向（社長指示）：本編の1場面に見える3Dの絵、直接的な問いかけのコピー（例「6億匹の猫が／同時に鳴いたら？」）。`pilots/moshimo-neko-meow/06_thumbnail.md`
- 参考・競合（社長の登録チャンネル）：ifと（地球規模の物理を数字で）、ほんとにやったら（キャラが計算どおりに体験）、もしもの館、MoshiAnime。ほかに「もしもの世界」（@moshimo_sekai_jp）がある。

## 出してほしいもの
1. チャンネル名の案 5つ以上。それぞれ：読み、伝わること、想定する @ハンドル、既存チャンネルとの重複の確認結果（確認した方法と日付。確認できなければ「未確認」）
2. 推奨1つと理由
3. アイコンの案（3方向以上）と、推奨の画像1枚（800×800 PNG）
4. バナーの案と画像1枚（2560×1440 PNG、スマホでも切れない中央 1546×423 に主要素）
5. チャンネルの説明文（概要）の案 1つ

## 条件
- 他者の名前・キャラ・ロゴ・画像は使わない。似せない。
- フォントは SIL OFL のみ。追加費用0（画像生成を使う場合は費用0の根拠を書く）。
- 本編の絵柄（ローポリ3D・ミニチュア風、橙の夕空、黄色の札）とそろえる。
- 置き場所：`channels/moshimo-3d/codex/`（説明は `codex/00_channel_name_codex.md`、画像は同じフォルダ、素材の記録は `codex/assets.md`）。Claude の案のファイルは書き換えない。
- 書き終えたら、Claude の案（`00_channel_name.md`）と並べて、違い・それぞれの強みを短く比べる（社長が選びやすいように）。
