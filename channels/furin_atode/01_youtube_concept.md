## 1. コンセプト（推奨案）
**一文**：彼の言葉を「確かめられること」と「確かめられないこと」に仕分けて、自分で次の一手を決める、大人の女性のための恋愛チャンネル。

| 項目 | 内容 |
|---|---|
| 視聴者 | 25〜40代の女性。彼の言動に振り回されている人（片思い・交際中・都合のいい関係・既婚男性との恋愛） |
| 約束 | 「彼は本気？」を当てるのではなく、彼の言葉ごとに、確かめられる事実と確かめられない点を分け、**日付つきの自分の条件**を決められるようにする |
| 1本の型 | 彼のよくあるセリフ1つ（例：「忙しい」「落ち着いたら会おう」「妻とはもう終わってる」）→ そのセリフの裏で起きていることを研究・統計・法律の出典で示す → 確かめられる事実／確かめられない点に仕分け → 次の1週間にやること・やらないこと |
| 柱 | ①男性心理・脈あり／本命（入口。市場が最も大きい） ②都合のいい関係・連絡の不安 ③複雑恋愛（既婚男性との恋愛。週3本のうち1本程度） |

| note との関係 | ~~動画で扱ったセリフの「台帳（3列）」を note の無料記事で配り~~ → **2026-11-14 の設計決定**：動画の概要欄・固定コメントから、その週の無料 note（8欄の台帳のうち4欄を1行書く記入例1件）へ案内し、既婚男性との恋愛の深い悩みは ¥500 の有料 note で扱う（`03_marketing_funnel.md` が正） |
| 言い方 | 道徳論を入れない。出典で確かめた事実は言い切り、言い切れない話は入れない（`docs/社長の前提.md` 4） |

## 5. 本数・尺と、2026年内の収益化の見込み
- 本数：長尺を週3本（`docs/社長の前提.md` 2）。ショート動画は作らない（社長 2026-11-14）。尺は10〜15分（案）。制作能力は未検証。
- 収益化の条件（登録者1,000人・総再生4,000時間）を、2026-12-31 までに満たす見込みは**低い**。理由：
  - 今日（2026-11-14）は名前も決まっておらず、早くても初投稿は11月下旬。年末までは約6週で、長尺は最大18本程度。
  - 4,000時間は24万分。平均の視聴時間を仮に4分とすると（**仮定**。実績はない）、長尺で約6万回の再生が要り、1本あたり平均3,300回程度になる。
  - 似た新しいチャンネルの例：「れん愛サプリ」は2025-07-28 開設で、115本・総再生401,241回・登録者1,230人（取得日 2026-11-13）。開設から約15か月で、1,000人台。
  - ショートは作らないので、4,000時間は長尺だけで積む（ショートの再生が4,000時間に入らないという扱いも、公式ヘルプでは未確認（この環境から `support.google.com` に接続できない）。
- 期限内に届かない見込みを隠さず、2026年内の途中の目安を社長と決める（例：初月の登録者数・長尺1本あたりの平均視聴時間）。目安の数字は今は置かない。
