## 4. 無料と有料の中身
### 4.1 無料 note（別の記事）
1. 共感：当事者の具体的な場面
2. 問題提起：やりがちな行動（いつでも会えるスタンス、長文の LINE など）
3. 原因解明：事実と推測が混ざる理由
4. **記入例1件**と、基本の手順（8欄のうち「彼の発言・日時・自分が直接確認した出来事・まだ分からない点」の4つを1行だけ書く）
5. 有料への案内（3.1）

- 記入例は、相手が既婚でも独身でも使える形にする。無料だけで1つ整理できる。

### 4.2 有料 note（¥500）の中身
**共通**：台帳の8欄（彼の発言／日時／自分が直接確認した出来事／本人から聞いただけの情報／まだ分からない点／自分の条件／次の行動／見直す日）
- 最初は1つの出来事・1行から書く。過去の全部や、全部の欄を一度に書かせない。分からない欄は「不明」のままでよい。それでも「自分の条件・次の行動・見直す日」には進める。
- 無断の調査（スマホ・位置情報・家族や職場への接触）、離婚が本当かどうかの認定、本心の確定は求めない。

**週ごとに足すもの**（同じ空欄テンプレートの売り直しにしない）
| 週 | 記入見本3件（同じセリフで事実が違う） | 返事の分かれ道 | 持ち帰る判断 |
|---|---|---|---|
| 1 曖昧な約束 | ①彼が自分から日付を出した ②「落ち着いたら」のまま3週間 ③1回会えたが、次は未定 | 日付が出る／あいまい／返事なし | 「〇月〇日までに彼から日付が出なければ、□する」と、見直す日 |
| 2 連絡の不安 | ①翌日に理由つきで返信 ②既読のまま2日 ③休日だけ連絡が途絶える | 返事あり／短い返事だけ／なし | 待つ時間の上限、その間にやること・送らないこと、見直す日 |
| 3 会う条件 | ①彼から候補日が出る ②直前の変更が月に2回 ③自分だけが予定を空けている | 候補日あり／保留／なし | 自分が会える日・会わない条件、見直す日 |
| 4 距離を置いた後 | ①期間を言われた ②期間なし・既読はつく ③既読がつかない | 連絡あり／あいまい／なし | 終わりとみなす自分の条件、こちらから連絡しない線、見直す日 |

- **初めて買う人に**：その週の場面で、記入と判断を最後まで終えられる。
- **前の週を買った人に**：台帳は同じ形式で続けて使え、新しい場面の見本3件・分かれ道・判断の決め方が増える。

### 4.3 有料 note の無料プレビュー（無料 note とは別のもの）
検索や note の中から有料記事へ直接来た読者にも、単独で分かるようにする。`CHANNEL.md` 5 の4ステップは廃止しない。有料記事の中で、購入の境界の前に次を置く。
1. **短い導入**（共感と代弁）
2. **問題提起**（やりがちな行動）
3. **原因解明**（なぜそうなるか）
4. 次の4つ
- 対象：既婚男性との恋愛で、{その週の場面}に悩んでいる人
- 含むもの：4.2 の共通の8欄と、その週の見本3件・分かれ道・持ち帰る判断
- 対象外：彼の本心の判定、法律の個別の判断、復縁の保証、無断の調査の方法
- 価格：¥500 → ここで購入の境界

この後の**解決策**（4.2 の実行セット）が有料。

- `CHANNEL.md` 5 の4ステップとの関係：有料記事は、4ステップ（導入 → 問題提起 → 原因解明までを無料、解決策を有料）のまま。別の無料 note（4.1）は、記入例だけで独立して役に立つ入口で、有料記事の無料部分を置き換えるものではない。

## 7. 計測と改善のルール
**記録する項目**（毎週月曜）
- note（記事ごと）：取得日時／記事 ID／期間（開始日〜終了日）／ページビュー／購入件数／購入率／売上（別の列）／流入元／変更履歴
- YouTube（動画ごと。合流後）：取得日時／動画 ID／期間／再生数／平均視聴時間
- **対応表**：動画 ID → 無料記事 ID → 有料記事 ID。どの動画からどの記事へ案内したかの**運用の台帳**で、因果の計測ではない

| 指標 | 決め方 |
|---|---|
| 購入率（販売の評価） | 同じ記事・公開から28日間の購入件数 ÷ 同じ期間のページビュー。ページビュー・件数・率を並べる。**ページビューが0、または件数が分からないときは率を出さない（算出不可）**。売上を価格で割った値で代わりにしない。**件数とページビューが同じ期間にそろっていると確認できない、集計の遅れが区別できない、起点が分からないときも率を出さない**（PR #14 の N0 案 7 と同じ） |
| YouTube からの流入 | note の流入元はドメイン単位で、参考にとどめる。特定の動画から購入までは追えない。note 内の流入は note.com にまとめられ、ページビューの合計とも一致しないことがある（https://www.help-note.com/hc/ja/articles/61983634535449 、Codex が 2026-11-14 に原文を再確認。2026-11-07 にも確認） |
| 記入できたか（使いやすさの評価） | 任意の読者の反応。購入率と混ぜない。**反応がないことを、使えなかった証拠にしない** |

**改善のルール**
- 毎週は記録だけ。直してよいのは明らかな不備（リンク切れ、案内の4つの欠け、誤字）だけ。
- **比較は、4本の有料記事がそれぞれ公開から28日たってから**（開始から約8週目の終わり）。5〜8週目は同じ順で2周目を出す。
- 少ないページビューで購入0件でも、失敗とは断定しない。原因も断定せず、改善は仮説として扱う。
- **判断のしかた**（比較の時期に。どれも1要素ずつ、次の観測期間で見る）
  1. **露出・流入が少ない**：リンク（切れていないか、案内の4つがあるか）、タイトルと対象読者が合っているかを点検し、次の期間に1要素だけ変える。
  2. **ページビューはあるが購入が少ない**：価格や商品が原因とは断定しない。対象の書き方／無料プレビュー／追加で得られるもの、のどれか1要素を変える。
  3. **購入件数が取れない**：購入率の比較は保留する。ページビューと売上は、それぞれ別に観測して記録する。
  4. **「使いにくい」という任意の反応**：手順や記入見本を直す。売上の評価とは別に扱う。
- 変えるときは**1項目ずつ**、次の観測期間（同じ記事・28日）で見る。
- 収益の見込みや基準の数字は作らない。
- スキ数で読者やテーマの順番を変えない。値下げしない。
