# 不倫の答え合わせ（note `furin_atode`）

社長方針（2026-10-25）：大人恋愛・深層心理コンテンツの運用・執筆戦略。note の工程・ゲートは `pipeline/README.md`「note」、方針の根拠は `pipeline/note_plan.md` が正。
**このファイルはコンセプト・読者・テーマ・口調・構成の正。** 執筆（note 記事）と監査の前に必ず読む。
ゲートN0 はまだ通っていない。このファイルは N0 の `notes/00_strategy.md` を作る前提であり、N0 承認の代わりにはならない（価格帯・競合の実数値・規約確認は N0 で出す）。

## 1. 概要と目的
- **コンセプト**：「誰にも相談できない恋愛（不倫・婚外恋愛・複雑な恋愛）」に悩む女性に向けた、恋愛・男性心理コンテンツの発信と、有料 note への誘導。
- **運用は note のみ**（社長方針 2026-10-25）：X・YouTube・公式 LINE など他の SNS・サービスはこのテーマでは扱わない。集客も note 内（無料 note → 有料 note）で行う。
- **マネタイズ**：伸びたテーマを深掘りした特化型の有料 note の販売。

## 2. 読者（ターゲット）とインサイト
- **メイン**：既婚男性との恋愛（不倫・W不倫）に悩む 20代後半〜40代の女性。
- **深い悩み（ペイン）**：
  - 友人に相談できず孤独。休日の夜やイベントの日に連絡が取れず、気持ちが沈みやすい。
  - 「遊びなのか本気なのか」「なぜ奥さんと別れないのか」と常に疑心暗鬼になっている。
  - 彼を優先しすぎて自己肯定感が下がり、「都合のいい女」になっている自覚と焦りがある。
- **購買行動**：深夜に一人で検索・SNS を巡回し、自分の痛みを正確に代弁してくれた発信者の有料記事を衝動買い・リピート買いする傾向が強い（社長の見立て。N0 で競合の実数値と照合する）。

## 3. 4大黄金テーマ（企画・執筆の軸）
1. **不倫 × 男性心理（本気度の見極め）**：既婚男性の言動の裏にある本音、罪悪感やキャパシティの構造を言語化し、遊びか本気かを見極める基準を渡す。
2. **不倫 × 依存（自分軸の回復）**：連絡が来ない不安や自爆行動（追撃 LINE など）を抑え、「彼軸」から「自分軸」へ戻すマインドセット。
3. **不倫 × 沼らせ方（立場の逆転）**：「都合のいい女」から脱却し、家庭にはない居心地の良さと「手に入りそうで入らない距離感」を作って彼に追わせる具体的テクニック。
4. **不倫 × 復縁（冷却期間と再アプローチ）**：リスクや罪悪感を理由に距離を置かれた・音信不通になった状態から、既婚男性特有の心理を踏まえて連絡を引き寄せる方法。

## 4. 執筆ルール・トーン＆マナー
- **道徳論・一般論を入れない**：「不倫は良くない」「やめた方がいい」「奥さんがかわいそう」といった道徳的ジャッジは一切書かない。100% 読者の味方・理解者のスタンス。
- **痛みの代弁と解像度**：「休日の夜の孤独」「既読スルーへの恐怖」「スマホの向こうにある家庭への嫉妬」など、当事者にしか分からない具体的な場面を描く。
- **感情（共感）＋論理（男性心理）**：導入は徹底的に感情に寄り添い、解決策のパートは男性心理をもとに論理的・冷静に解説する。
  - 社長の指示は「男性の狩猟本能や脳の構造」をベースにすること。ただし全チャンネル共通の「事実は出典付きでしか言わない」（`docs/社長の前提.md`・確定済み）が優先する：研究で確認できる内容は出典を `01_plan.md` に残して書き、確認できない内容は書かない。「〜と言われる」「〜かもしれません」などの保険をかける言い回しで残さない（全チャンネル・note 共通の「言い切りで語る」。社長指示 2026-10-28、`docs/社長の前提.md` 4）。
- 不倫ジャンルで守ること（実在人物を扱わない・創作の明記・法律情報は出典付き・違法な調査方法を勧めない・note の規約内）は `pipeline/README.md`「note」のとおり。道徳論の排除と両立する（読者を守るための情報として書き、説教にしない）。

## 5. 有料 note の構成テンプレート
原則として次の4ステップで構成する。
1. **導入（共感と代弁）**：読者の孤独や痛みを正確に言語化し、「これは私のための記事だ」と思わせる。
2. **問題提起（NG 行動の指摘）**：彼をつなぎ止めようとしてやりがちな行動（いつでも会えるスタンス、感情的な長文 LINE など）が、実は既婚男性を最も冷めさせる原因だと指摘する。
3. **原因解明（男性心理のロジック）**：なぜ既婚男性がそういう態度をとるのか、心理の構造を解説する。**無料エリアはここまで**で引きを作る。
4. **解決策（具体的なアクションプラン）**：明日から実践できる LINE の返信頻度、会っているときの振る舞い、沈黙の使い方など、具体的な「沼らせ・逆転テクニック」を示す（**有料エリア**）。

## 6. 高反応タイトル・フックの型（例）
- 『既婚男性が「絶対に手放したくない女性」にだけ見せる5つの異常なサイン』
- 『「奥さんとはうまくいってない」と言う彼の言葉を信じてはいけない本当の理由』
- 『都合のいい女を卒業。既婚の彼を「あなたなしでは生きられない状態」に沼らせる逆転の法則』
- 『休日の夜に泣くのは今日で終わり。彼の方から「会いたい」と追わせるLINEと距離感の作り方』
- 『【取扱注意】家庭に戻った既婚の彼から、もう一度連絡を引き寄せる「沈黙」と「1通のLINE」』

## 監査で特に見る点
- 道徳的ジャッジ・説教が混ざっていないか（混ざっていれば差し戻し）。
- 導入の痛みの描写が一般論になっていないか（当事者の具体的な場面があるか）。
- 有料 note が上の4ステップになっているか。無料エリアが「原因解明」までで止まり、解決策が有料側にあるか。
- 男性心理・脳・本能の説明が、出典のない断定になっていないか。
- 「不倫ジャンルで守ること」に反していないか（重大指摘）。
