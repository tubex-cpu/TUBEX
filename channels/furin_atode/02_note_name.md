# note の名前（表示名）の候補：「不倫」を含まないもの

- 状態：**候補（社長の選択前）**。新名称の確定、実アカウントの表示名の変更、ID・URL・リポジトリの管理パス（`furin_atode`）の変更はしていない。
- 依頼：社長「noteのチャンネル名に不倫は使用しないようにする」（2026-11-14、逐語。`docs/チャンネル方針.md`）。旧名「不倫の答え合わせ」は取り下げ。**読者・4テーマの変更ではない**（既婚男性との恋愛に悩む女性、①本気度 ②依存 ③沼らせ方 ④復縁はそのまま。`CHANNEL.md`）。
- 作成：Claude Code、2026-11-14。

## 1. 名前を選ぶ条件（案）
| 条件 | 理由 |
|---|---|
| 「不倫」を含まない | 社長指示（2026-11-14） |
| 「婚外恋愛」「W不倫」「既婚者」など、同じ意味の語も表示名には入れない（**提案**。社長の確認が要る） | 指示の理由は聞いていない。2026-10-25 のブリーフにあった「表向きは不倫特化を前面に出しすぎない（凍結の防止・フォローが周囲に知られる懸念）」が理由なら、言い換え語でも同じ問題が残るため |
| 読者が「私のための場所」と分かる | 表示名から「不倫」を外すと何の場所か伝わりにくくなるので、説明文（プロフィール）と記事タイトルで補う |
| 4テーマと3.2.1 の型（彼の言葉を仕分けて自分の条件を決める）に合う | N0 案（PR #14）の差別化の柱と名前をそろえる |
| YouTube 第1枠とつながる | 導線 YouTube → note（社長決定 2026-11-13）。YouTube 名の案A は「彼の言葉、仕分けます。」（`01_youtube_concept.md` 3、社長の選択前） |

## 2. 候補
| 案 | 名前 | プロフィールの1行目（案） | 良い点 | 気になる点 |
|---|---|---|---|---|
| **1（推奨）** | **彼の言葉、仕分けます。** | 言えない恋をしているあなたへ。彼のその言葉を、確かめられること・確かめられないことに仕分けます。 | YouTube 名の案A と同じにすれば、動画から来た人が迷わない。N0 の型（3.2.1）がそのまま名前になる | YouTube 名が A 以外に決まると、つながりが弱くなる。何の恋かは名前から分からない |
| 2 | 言えない恋の仕分け帳 | 誰にも相談できない恋の、彼の言葉と自分の気持ちを仕分けるノート。 | 「言えない恋」で、読者（周りに話せない恋）に届く。「不倫」の語を使わない | 「言えない恋」は片思いなど広い意味にも取れる |
| 3 | 大人の恋の答え合わせ | 彼の言葉を、確かめられることと確かめられないことに分けて答え合わせ。 | 旧名「答え合わせ」の考え方を残せる | YouTube では「恋の答え合わせ」系の名前が少なくとも5つあり埋もれる（`01_youtube_concept.md` 3）。note 上の重複は未確認 |
| 4 | 複雑恋愛の仕分け帳 | 既婚の彼との恋など、複雑な恋の言葉を仕分けます。 | 読者の範囲が一番はっきりする | 「複雑恋愛」は占い系で多く使われている語（YouTube の競合「ふーりん🔮不倫・複雑恋愛タロット占い」など）で、占いと並ぶ。プロフィールに「既婚」が入るので、1 の条件案とぶつかる |

- **推奨は1**。YouTube と note を同じ名前にすると、動画の概要欄から note へ来た人が同じ場所だと分かる。YouTube 名を A 以外にする場合は、2 を推奨する。
- note 上で同じ・似た名前のクリエイターがいるかは**未確認**（この環境から note.com に接続できない）。決定前に Codex に note の検索で確かめてもらう。
