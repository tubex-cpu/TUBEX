## 2. 重複の確認方法と限界
- **YouTube**：YouTube Data API の search（type=channel、regionCode=JP、上位6件）で、同名・ほぼ同名のチャンネルを探した（2026-11-14）。検索語は各名前そのもの。途中で API が「429 Too Many Requests」を返したため、そこで止めた。表の2案は YouTube 上も**未確認**。
- **URL・ID は未取得**：記録したのは、検索結果に出たチャンネルの表示名・登録者数・開設日だけで、チャンネルの URL・ID は記録していない（使ったスクリプトの出力に含めていなかった）。429 を繰り返さないため、再取得はしていない。そのため、3 の除外と 4 の「同名なし／近い名前」は **URL 未取得の暫定判断**で、採否の根拠としては未監査。名前を決める前に、Codex が実画面で、または API の上限が戻った後に1回だけ、候補ごとの検索結果の URL・ID・表示名・登録者数を取得日つきで記録する。YouTube は同名を禁止しないので、「見つからない」は使えることの保証ではない。
- **note**：この環境から note.com に接続できない。上位案の一部（「恋の深呼吸」「彼のことば、ほどきます」「彼の言葉と、わたしの気持ち」）を検索エンジンで `site:note.com` に絞って探したが、該当は出なかった。検索エンジンが note を網羅している保証はないので、**note 上の重複はすべて未確認**として扱う。決定前に Codex に note の検索で確かめてもらう。

### 推奨の上位3案と理由
1. **彼のことば、ほどきます**：「仕分けます」と同じく彼の言葉を扱う中身が名前で分かり、YouTube の型（セリフ1つを扱う）と note の型（3.2.1 の台帳）の両方につながる。「仕分け」より柔らかい。気になる点（本音を読み解く印象）は説明文で打ち消せる。
2. **恋の深呼吸**：短く覚えやすく、いちばん温かい。読者の不安に寄り添う印象で、本心を断定する印象がない。中身は説明文とサムネで補う必要がある。
3. **彼の言葉と、わたしの気持ち**：「彼」と「わたし」を並べ、読者が主語になる。彼の本心を当てるのではなく自分の気持ちも大事にする、という型（日付つきの自分の条件）に合う。長さが弱点。

- 4・7・6 は、相談窓口に見える・不倫を連想させる語感・ホテルを連想させる語感があるので、上位から外した。
- 4・8 は YouTube 上の重複が未確認。
