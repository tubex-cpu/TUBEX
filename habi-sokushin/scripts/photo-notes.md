# 即身仏判決 写真リスト（photo-picks.json の内訳）

- 選定基準：Wikimedia Commons の PD／CC0／CC BY／CC BY-SA のみ（NC・ND・フェアユース・ライセンス不明は不採用）。2026-11-13 に Commons API の extmetadata で作者・ライセンス・出典を1枚ずつ確認。作者も出典も書かれていない「PD表示」は不採用。
- 研究メモ9章で確認済みの20枚（★印）はそのまま引き継いだ。
- 全点を縮小版（幅330px）で目視確認済み。
- 前提：収益化したYouTube動画の本編・サムネで使い、トリミング・色調整・テロップ重ねをする。
  - PD／CC0／No known restrictions：本編・サムネとも可、加工可。
  - CC BY：本編・サムネとも可、加工可。概要欄に「作者・ライセンス・出典・改変あり」を記載。
  - **BY-SA**：これまでの動画と同じく、概要欄にクレジットを載せる前提で採用。加工可だが、加工した画像そのものはBY-SA扱いになる点に注意（表の「ライセンス」欄に BY-SA と明記）。
- 「顔（上半分）」が「あり」の写真は、人物（像・絵・肖像を含む）の顔が画面の上半分にあるので、テロップは下（labelBottom）に置く。
- 保存名の末尾が `-w` のものは横に長い画像（photo-desc.json のキーは `-w` なし）。
- 即身仏そのものの写真は、権利者の条件が確かめられるものが見つからず不採用（研究メモ9章どおり）。湯殿山の御神体は撮影禁止のため探していない。
- 合計 128 枚（引き継ぎ20枚＋新規108枚）。2026-11-13 に30枚を追加し、合計 158 枚（「追加分」の表）。
