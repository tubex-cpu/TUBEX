## 2. 1本につなぐ

### Windows
ダウンロードしたフォルダを開き、アドレス欄に `cmd` と入力してEnter。出てきた黒い画面に次の1行を貼り付けてEnter：
```
copy /b habi-izumo-1080p.mp4.part01+habi-izumo-1080p.mp4.part02+habi-izumo-1080p.mp4.part03+habi-izumo-1080p.mp4.part04+habi-izumo-1080p.mp4.part05+habi-izumo-1080p.mp4.part06+habi-izumo-1080p.mp4.part07+habi-izumo-1080p.mp4.part08+habi-izumo-1080p.mp4.part09+habi-izumo-1080p.mp4.part10+habi-izumo-1080p.mp4.part11 habi-izumo-1080p.mp4
```

### Mac
ターミナルを開いて、次の2行を貼り付けてEnter：
```
cd ~/Downloads
cat habi-izumo-1080p.mp4.part?? > habi-izumo-1080p.mp4
```

できた `habi-izumo-1080p.mp4`（984,480,221バイト）が投稿用の動画です。
