## 見つからなかった題材

- **宇豆柱そのものの写真**（2000年出土・古代出雲歴史博物館の展示）：見つからない。代わりに心御柱の実物大レプリカ（shin-no-mihashira）を入れた。出土状況の写真が1枚あったが、説明板（案内板）を撮ったものだったので外した。
- **金輪御造営差図**：見つからない。
- **江戸時代以前の出雲大社の境内絵図**：見つからない（歌川広重の浮世絵、1922年の古写真、鎌倉時代本殿の模型で代用）。

- **神在祭・神迎祭の様子、かがり火**：祭りそのものの写真は見つからない（稲佐の浜・十九社・万九千神社・佐太神社などの場所の写真で構成）。
- **出雲大社上宮（かみのみや）**：見つからない。
- **出雲大社の夜景・朝の景色**：夜景は見つからない。
- **菅谷たたら山内の高殿**：見つからない（和鋼博物館、大板山たたら製鉄遺跡〔山口県萩市〕、砂鉄、鉄滓、奥出雲の風景で代用）。

## 気になる点

- **説明札が写り込む写真**：kanbara-iron（番号札）、tatetsuki-finds、kanbara-sword、sword-mold-saga、yoshitake-bronze、sueki-okadayama、agate-stones、tatara-site、kamakura-honden-model、shin-no-mihashira（柱の札）、okuninushi-kyoto（背景の社名看板）は小さな札・看板が写る。ズームの位置を札から外すとよい。
- **old-calendar** は周囲に色見本とものさしが写る（国立国会図書館の撮影）。中央を切り出して使う。
- **地元以外の写真**：autumn-mikoshi（松山市）、harvest-field（香取市）、harvest-hazakake（山形県）、momiji-torii（京都）、okuninushi-kyoto（京都・地主神社）、korea-bronze-swords・yoshinogari-sword-w・glass-beads（佐賀・吉野ヶ里）、yoshitake-bronze（福岡）、sword-mold-saga（佐賀）、dotaku-mold（奈良）、tatara-site（萩市）、gaya-slag（韓国）、japan-sea（浜田市）、taisha-kagura（出雲神楽だが撮影地不明）。ナレーションで出雲の話として言い切らないこと。
- **hiroshige-izumo** はアムステルダム国立美術館の画像で、Commons の題名の「provincie Izumi」は Izumo の誤記（中身は広重「六十余州名所図会 出雲 大社ほと〳〵之図」）。
- **seasnake-1** は南アフリカの水族館、**seasnake-beach** は撮影地不明の浜辺。セグロウミヘビの種としては同じ。
- **dotaku-kagawa**（伝香川県出土銅鐸）は絵画のある銅鐸として有名だが、この写真の面に絵がはっきり見えるかは縮小版では判別できない。
- **musubi-statue** と **okuninushi-kyoto** はどちらも像が小さめ・または看板入り。大国主の像のアップとして使うならズームで寄せる。
- **sonnonagahama** は三瓶山頂からの遠景で霞んでいる。薗の長浜の主役は **izumo-coast**（キララ多伎から）にした。
- 加茂岩倉の銅鐸は似た構図（ケースに横たわる銅鐸）が kamo-dotaku-8 の1枚だけになるよう絞った。荒神谷の銅剣の展示は「壁一面（kojindani-swords-wall）」と「ケースを斜めから（kojindani-swords-case）」の2枚で、角度が違う。
- 稲佐の浜・弁天島は場面ごとに違う時間帯・角度のものを選んだが、計10枚と多め（冒頭・国譲り・神在月・まとめ）。使い過ぎに注意。
- 横長の画像（-w）：inasa-pano-w（比3.3）、taisha-pano-w（比5.0）、yoshinogari-sword-w（比3.5）、matsuho-dotaku-w（比3.2）、matsue-pano-w（比3.6）。
- Commons API は混んでいて、429 が頻発した（API は Retry-After の秒数どおりに待つと進んだ。縮小版の取得は upload.wikimedia.org でも1分に1〜2枚程度）。
