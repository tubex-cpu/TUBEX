# 全編絵コンテ v1：なぜオーストラリアの大都市は、海の近くに集まるのか？

- 台本：`05_script_v2.md`（S01〜S18）。時刻は1分300字＋場面ごとの間0.8秒の概算で、**全体は約7分13秒**。音声を作ってから時刻を合わせ直す
- 映像の基準：最新の冒頭45秒版 v3（`australia-opening-v3.mp4`）。v3 は「地図 → 実写 → 地図 → AI内陸 → 地図 → AI港 → キャンベラ実写 → 地図」という順番で、写真はゆっくりズームしている（社長のドライブ「素材クレジットと生成プロンプト.txt」に書かれた時間割による）
- 全編の流れ：**地図で位置を示す → 現地の様子（実写・生成） → 仕組みの図解 → 地図に戻る**。1カットは3〜8秒を目安にする。同じ種類の画面が10秒以上続かないようにするが、機械的には当てはめない
- 種類の記号：🌏地図（NASA Blue Marble の球体投影、または Natural Earth の平面地図） / 📷実写（場所を特定して説明する場面は必ず実写か正確な地理資料） / 🎨AI生成（画面に「AI生成イメージ」と出す。特定の地名は付けない） / 📊図解（自作）
- 素材の状態：**既存**＝v3 にある素材 / **要確保**＝実写を探して作者・ライセンスを確認する / **要生成**＝画像生成 / **要作図**＝自作の図

## 確認できたこと・できていないこと
- 確認できた：v3 の時間割（クレジットファイル）、旧全編の場面画像18枚のうち13枚の画面の文字（Drive の文字読み取り）、素材の作者・ライセンス・生成プロンプト
- **確認できていない**：v3 の静止画23枚（JPG）は、Drive の読み取りで文字も画像ラベルも返ってこず、見た目を確かめられなかった。旧全編の場面画像のうち 01・05・10・17 も同じ。生成画像2枚も見た目は未確認
- **未確認（静止画では分からない）**：動画の動き（ズームの速さ・切り替え方）、音声（ナレーションの読み間違い・BGM・音切れ）
- 旧全編の画面の特徴（文字読み取りより）：左上に「地図の向こうの理由」、見出し・小見出し、右下に「AUSTRALIA / 番号」、下に「資料: ○○ | 出典URL 注記は制作資料へ」、「映像・音声 試作」の表示。v2 では、出典は概要欄と資料表に回し、画面には実写のクレジット（CC BY の表示義務）と「AI生成イメージ」の表示だけを残す

## 素材の確保ルール（HANDOFF より）
- 場所を特定して説明する画面は、その場所の実写か正確な地理資料を使う。架空の港をシドニー港と表示しない
- AI生成の画面には「AI生成イメージ」と出す。写真をズームしたものを「現地で撮った映像」と呼ばない
- Blue Marble は2004年1月の合成画像で、今の地表ではない
- 実写はすべて、作者・ライセンス（商用利用と加工が可能か）・URL を `06c_assets.md`（これから作る）に記録してから使う
