# 概要欄（案）：chizu-001-australia-coast

**タイトル**：オーストラリアの大都市は全部海沿い。なのに、なぜ首都だけ内陸なのか？

---

シドニー、メルボルン、ブリスベン、アデレード、パース。オーストラリアの5つの大都市は、すべて海のそばにあります。ところが首都キャンベラだけは内陸。水と気候、港の歴史、人と仕事の集まり方、そして首都を決めた政治から、地図の偏りの理由を読み解きます。
