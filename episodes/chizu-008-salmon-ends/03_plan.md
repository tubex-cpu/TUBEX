## ① 企画の全容と狙い（ひと目で分かる版）
| 項目 | 内容 |
|---|---|
| 主題（ひとことで） | 回転寿司でサーモンが食べられるのは、日本がチリにサケを持ち込み、ノルウェーからサケを生で食べることを教わったから |
| 動画の問い | 日本の回転寿司のサーモンは、なぜ地球の裏側のチリと、北の果てのノルウェーから来るのか？ |
| 見る人の予想 | 「冷たい海の魚だから、寒い国から来るだけ」 |
| 結論（答え） | 寒い海だから、だけではない。チリには、もともとサケが1匹もいなかった。日本とJICAが卵を運び、養殖を始めた。一方、日本人はもともとサケを生で食べなかった。生で食べる習慣は、ノルウェーが日本に持ち込んだ。チリへは日本が「魚」を、日本へはノルウェーが「食べ方」を運んだ結果、いまの回転寿司のサーモンがある |
| いちばんの驚き | サケのいなかった国から、日本のサケ・マスの7割が来ている |
| 見終わって言いたくなる一言 | 「サーモンって、日本がチリに持っていった魚なんだって」 |
| 想定視聴者 | 回転寿司・食の雑学が好きな人、地図・地理が好きな人 |

## ③ 予想を超える因果と具体的な場面
- 「寒い国の魚だから」→ チリにはもともとサケがいなかった。日本とJICAが始めた（3章）
- 「日本人は昔からサケを生で食べてきた」→ 生では食べなかった。ノルウェーが変えた（4章）
- 「チリは南極に近い寒い所」→ 養殖の町プエルトモンは函館と同じくらいの緯度（3章）
- 「サーモンはどれも同じ」→ 1kgあたりの輸入値段は、ノルウェー産がチリ産の約1.8倍（5章）

## ⑤ 推奨案と理由
- **推奨：A**。「サケのいない国から、なぜ7割も来るのか」という矛盾が強く、答え（日本が卵を運んだ）はサムネからもタイトルからも想像できない。出典（nippon.com、JICA の研究者の記事）で言い切れる
- 次点：B。日本人の常識を逆にする強さはあるが、ノルウェー側は競合（60万回）が近い話をすでに扱っている

## ⑥ 根拠と未検証の箇所

- **未検証（台本の前に一次資料で確認する）**：JICA事業の年号（1972年の試験、1974年のシロサケ放流と回帰しなかったこと、1987年に養殖へ転換。F11〜F13 は検索の抜粋のみ）、ノルウェー「プロジェクト・ジャパン」の開始年（1985/1986で出典が食い違う）、魚種別・生鮮/冷凍別の国別内訳、トルコ産の魚種、プエルトモンが同緯度でも冷たい理由（寒流）。**「日本が持ち込んだサケを日本が輸入している」は、いまの養殖の品種が日本の協力で入った系統か確かめるまで言わない**
