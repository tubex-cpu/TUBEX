## 共通の条件
- 寸法：1920×1080（16:9）、JPEG 品質90前後。下から200px と右上（幅500×高さ120px）は字幕・クレジットが乗るので主役を置かない
- **実写**：PD・CC0・CC BY のみ（CC BY-SA・NC・ND 不可）。作者・ライセンス・元ページ URL・撮影地を記録。撮影地が台本の地名と一致するものだけ
- **生成**：追加費用0（今の契約の範囲）。実在の特定の街・建物・人物・ロゴに見せない。画面に Claude が「AI生成イメージ」と表示する。プロンプト全文・ツール・日付を記録
- 画風（生成）：落ち着いた自然色、やや俯瞰の立体イラスト（ドキュメンタリーの説明図）。漫画・アニメ調・原色は不可。全点でそろえる
- 置き場所：`episodes/chizu-003-canada-housing/gen/`（生成）と、実写は git に入れず `06c_assets.md` に記録（実写のファイルは `assets/`、`.gitignore` 対象）。台帳 `06d_generated_assets.md`
