## 判断
- **日本語ですでに同じ題材の長尺がある**：地球の記憶「世界で2番目に大きな国に、なぜもう場所がないのか」（2026-11-05、6日で352,191回）。元動画（Geoff、10-27）と同じ題・同じ流れで、概要欄の章立ては「寒さと凍った大地 → カナダ楯状地 → 大草原とロッキー → 使える土地は5% → 先住民とヌーベル・フランス → ハドソン湾会社…」。最後に2023年の人口増とバンクーバー・トロント（グリーンベルト・一戸建て住宅地）に触れる。**中心は「地理と歴史で、住める帯が細い」**
- 日本語のほかの動画は「住むのは不可能」「70%がこの線より南」型（ゆっくり解説・ショート）。**「なぜ人がいる場所で家が建たないのか」を CMHC のデータで解いた日本語の動画は見つからなかった**
- 需要は大きい：英語では住宅危機の解説が100万〜680万回、日本語でも地球の記憶が6日で35万回
- 差別化（社長方針：重なりは差別化できていればよい）
  1. **問いを変える**：「住める土地が狭いから満員」で終わらせない。地理は「どこに住めるか」まで、住宅不足は「人がいる場所でどれだけ建てられるか」。国全体 → 都市 → 「建ててよい土地」へ3段でズームする
  2. **原因を分けて見せる**：地理（山・水辺・農地保全）／規制（用途地域・承認の遅さ）／インフラ（上下水道）／費用。CMHC の研究（規制・承認・アメリカとの比較）を根拠にする。地球の記憶・Geoff の長尺の中心は地理と歴史
  3. **短い**：4〜6分。競合の長尺（地球の記憶は章立てから見て30分前後）に対し、1つの問いに1本の筋で答える
  4. **サムネで「満員の地図（赤と緑）」を使わない**：競合2本（Geoff 系・地球の記憶）が同じ型。こちらは都市を拡大した地図・住宅地の区画で見せる

### 共通の勝ちパターン（上位で重なるもの）
1. **カナダの形の地図を正面に大きく置く**（#1・#2・#6・#7・#8・#9・#11）。国の形だけで「何の話か」が一瞬で伝わる
2. **色で「住める／住めない」「豊か／貧しい」を二分する**（#1 赤と白、#6 赤と緑、#2 線の南北）。地図の上に対比を1つだけ置く
3. **常識とぶつかる短い言葉**（「カナダは満員」「POOR」「70%」「BIG U-TURN」）。6字前後、1行で、極太＋フチ
4. **数字1つ**（70%・$5.5M・200万人）が、数字なしの説明より強い

### 差別化の余地（本作で取る）
1. **国全体ではなく「都市を拡大した地図」**：競合はほぼ全員カナダ全体の地図。本作は国の形を小さく残しつつ、都市（トロントなど）の住宅地を大きく見せる「ズーム」の絵にする → 本編の「国 → 都市 → 建ててよい土地」と一致
2. **赤と緑の「住める帯」を使わない**：#6 と元動画が同じ型。本作は「広い国土」と「建てられない住宅地」の対比（例：一戸建てだけの区画に×印ではなく、家の形の区画が埋まって入れない絵）にする
3. **コピーは「満員」「不可能」ではなく、矛盾の問い**：『こんなに広いのに 家が足りない？』（2行。ただし**14字＋「？」で、サムネ監査基準の「合計12字以内」を超える**。サムネ工程で「広いのに 家が足りない？」（10字＋？）などに縮める案を社長に出す）。答え（規制・承認・インフラ）は本編で回収する。危機の煽り（崩壊・飢える）はしない
4. 神秘的・学術的なトーン（地図の質感、局所照明）で、#5 のような原色の煽りと並べたときに落ち着いた信頼感で差をつける
