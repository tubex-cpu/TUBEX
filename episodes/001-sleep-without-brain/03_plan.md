# 03 企画書

- **テーマ**：脳がない生き物も眠る。じゃあ私たちは何のために寝ているのか
- **ターゲット**：寝る前にスマホを見る20〜40代。「へぇ」と言いたい人
- **尺**：約1分40秒（横型 1920×1080）。ショート版は冒頭〜事実①を縦に切り出して流用予定
- **約束（サムネで提示）**：脳がないのに寝る生き物がいる
- **回収**：ヒドラ → クラゲ → 飛びながら寝る鳥 → 「睡眠は脳より先に生まれた」→ 人間の脳の掃除 → 日本人は睡眠最短 → 今夜は早く寝よう
- **構成の狙い**：常識（睡眠＝脳を休める）をフックで否定 → 証拠を3つ積む → 最後に視聴者自身の話に戻す
- **想定コメント誘発**：「今日から早く寝る」「ヒドラかわいい」→ 次回「〇〇も実は寝ている」シリーズ化
