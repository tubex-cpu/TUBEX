# 03 企画書：子どもにスマホ・タブレットを渡す親と、渡さない親

## 1文で
**同じ年に生まれた2人の子――早くからタブレットやスマホを渡された「みなと」と、なるべく渡されなかった「ひなた」――を2歳・5歳・10歳・15歳の章で追い、「スマホで脳が育たない」は研究で本当に言えるのかを、関連が見られた研究と「効果は小さい」とした大規模研究の両方で確かめる。** ── 研究と日本の統計で。

- **2人は「研究ごとの傾向を見せるための例」**（hito-001 の Codex 差し戻しを最初から反映）。各研究は国・年齢・人数・測り方が別々で、この2人の差をスマホが生んだとは証明できない。各章は「**考えられる要因の1つ**」として出し、最終章でも「2人の差はスマホで決まった」とは言わない。
- **研究の範囲を超えて言い換えない**（同上）：例）#1 は「36か月で、画面の音が流れる時間が1分多いと会話のやりとりが約1回少なかった」まで。「スマホを渡すと言葉が遅れる」とは言わない。#5 は「ネットを使う頻度」で「時間」ではない。
- **チャンネル**：ヒト図鑑（`channels/hito-zukan/CHANNEL.md`）。各章を「子どもの脳の発達」の切り口で語る。脳の説明は `01_research.md` に出典がある範囲だけ（会話のやりとりとブローカ野〔#10〕、白質の指標〔#3〕、灰白質の体積の増え方〔#5〕）。
- **元にした形式**：ヒト科研究所の「2人を年齢の章で追う」形式（社長指定）。ヒト科研究所にスマホのテーマはない（`02_competitors.md` A）。
- **ターゲット**：0〜15歳の子をもつ親（20〜40代）。PIVOT・NewsPicks の「スマホで脳が…」動画を見て不安になった人、「本当のところ、どのくらい気にすればいい？」を知りたい人。
- **尺**：約12〜13分（横型 1920×1080）。
- **視聴後に残るもの**：「時間の長さだけでなく、**画面が何を押しのけているか（会話・睡眠）と、一緒に見ているか**を1つ見直してみよう」。不安より、見る場所が1つ分かる。

## 登場人物（研究と統計をもとにした架空の2人）
- **みなと（家庭A）**：共働き。夕食の支度の間や移動中にタブレット・スマホで動画を見せることが多い。親は「助かっている。でも、脳に悪いと聞いて不安」。
- **ひなた（家庭B）**：なるべく画面を見せない方針。代わりに絵本・外遊び。親は「周りの子がみんな持っていて、うちだけで大丈夫？」と別の不安もある。
- どちらの親も子どものことを考えて選んでいる、と冒頭で置く（**どちらの家庭も責めない**）。
- 冒頭で「2歳の6割以上（63.5%）がすでにネットを使っている（テレビ・ゲーム機も含む）」（#11）を示し、みなとは珍しい存在ではないと置く。

- 画面の工夫（差別化）：左右に2人、上に**年齢の目盛り**（2→5→10→15歳）。各章で「研究の数字」を1つだけ大きく出し、その横に必ず**「何人・どこ・相関か」**の小さなラベル（例：「220家族・オーストラリア・観察研究」）。
- 「効果あり」の研究と「効果は小さい」の研究を**天秤の図**で毎章の最後に置く（自作SVG）。
- 回収：冒頭の問い「スマホで脳が育たないは本当？」→ 最終章で「関連はいくつかの研究で見られた。ただ多くは観察研究で効果は小さく、差が出たのは画面が会話や睡眠を押しのけたとき（かもしれない）」と答える（2人の差の原因を断定しない）。

## 差別化（`02_competitors.md` より）
1. 対談・解説・vlog ばかりの需要上位に対し、**2家庭の子を年齢の章で追う物語の形式**（スマホのテーマでは検索の範囲に見当たらず、ヒト科研究所も未扱い）
2. **警告の研究と「効果は小さい」の大規模研究を同じ動画で数字で並べる**（需要上位は警告一色）
3. 軸を「渡す／渡さない」から「**何を押しのけたか・一緒に見たか**」に移す
4. 「脳が育たない」と論文が測ったものの違いを見せる（ヒト図鑑の脳の切り口）
5. 日本の最新統計（こども家庭庁 令和7年度）で2家庭を作る
- ヒト科研究所の親テーマ（年収・習い事・教育熱心・専業主婦）で使われた研究は主役にしない（年収回の「言葉の数」の研究に近い #10 は補足1文のみ）。

## タイトルの方向（工程4で3案に）
- 例：「スマホを渡した家と、渡さなかった家。子どもの脳に差はついたのか｜2歳から15歳までを研究で追ってみた」
- 「壊れる」「末路」「台無し」は使わない。参考チャンネルの型は踏襲しつつ【統計×心理学】の表記は使わない。

## 注記・概要欄の方針
- 概要欄に：研究の一覧（著者・年・雑誌・人数・研究の種類）／「みなと・ひなたは研究と統計をもとにした架空の人物」／「研究の結果は平均・傾向で、すべての子に当てはまらない。多くは観察研究で、スマホが原因とは言えない」／「医学的な診断・育児指導ではない。発達の心配は小児科や自治体の健診で相談を」／ナレーションは AI 音声（Open JTalk、CC BY 3.0 クレジット）。
- **虐待・不適切な養育にはこの回では触れない**。もし工程5で触れることになった場合は、概要欄に児童相談所 虐待対応ダイヤル「189」を入れる。**番号は工程5の前にこども家庭庁の公式ページで確認し、出典 URL を `01_research.md` に残す**（今回は cfa.go.jp に接続できず未確認。確認できなければ番号は書かない）。

## リスクと対策
- **親を責める・不安をあおる**：表現ルール（`01_research.md`）。どちらの家庭も理由があって選んだと描き、渡さない家庭も理想化しない。
- **「スマホは無害」と受け取られる**：「小さい」は「ゼロ」ではないと毎回言う。2歳・5歳の章は関連が見られた研究を主役にする。
- **特定の研究者・動画への批判に見える**：人名・チャンネル名は出さず、「よく聞く言い方」と「論文が測ったもの」の比較にとどめる。
- **出典**：#13 WHO・#14 仙台市・#15 ダニーデンは二次確認のみ → 工程5の前に原著確認、できなければ使わない（WHO の推奨が確認できない場合、5歳の章は #12 の日本小児科医会2004年の提言だけにする）。#2 の訂正内容、#3 の訂正の有無は工程5の前に確認。#16 の講演録の数字・断定は使わない。
- **網羅性**：スマホが普及してからの子どもを大人まで追った研究は、今回の調査では確認できなかった（テレビの研究〔#15〕のみ）→ 「30歳の章」は作らず15歳で終える案にした（下で確認）。

## ゲートAで社長に確認したいこと
1. **この企画（渡す家／渡さない家の2人を2歳→15歳で追い、「脳が育たない」は本当かを研究で確かめる）で進めてよいか。**
2. **結論の向き**：「関連はあるが多くは観察研究で効果は小さい。差が出たのは画面が会話・睡眠を押しのけたとき（かもしれない）」という、需要上位の警告動画と逆寄りの結論でよいか（社長の前提「視聴者に新しい驚き・気づき」には合うが、「スマホは安全」と誤解されないよう注記を厚くする）。
3. **年齢の章**：参考形式は30歳まで追うことが多いが、スマホ世代を大人まで追った研究が確認できなかったため、**15歳で終える**案でよいか（大人の章を入れる場合はテレビの研究〔ダニーデン〕を原著確認して使う）。
4. **2人の家庭設定**：家庭A＝共働きで家事の間に見せる、家庭B＝なるべく見せない方針、でよいか（どちらも責めない描き方）。
