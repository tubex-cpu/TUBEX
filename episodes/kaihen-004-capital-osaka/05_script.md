# 台本 v0.4（世界線を変更）：東京が壊滅し首都が大阪に、日本の「上京」は大阪行きになる？

- v0.4（2026-11-15）：社長の指示（逐語）「・もっとフィクションっぽくていい ・地震で東京は壊滅→首都が大阪に移った日本の世界線 ・母と子のような具体的な個人の物語の描写ではなく大衆全般がどのように生活をしているのかを描きたい」を受けて全面改稿。旧版は `05_script_v0.3.2.md`（大阪へ移転後に南海トラフ、の世界線）ほか
- 共有用 Google ドキュメント（v0.4）：https://docs.google.com/document/d/1qOjlUb-tL_77eAs8XQG2ofe14Cz3C7IW9sRPTQwe0OU/edit（v0.3.2 以前のドキュメントは題名に「旧版」）
- 世界線：**架空の巨大地震で東京が壊滅 → 首都が大阪に移った日本**。地震は名前のない架空の地震として描く（実在の地震の想定・被害・時期とは結びつけない）。南海トラフの名前は使わない（v0.3.2 までの世界線とは別）
- 描くのは個人の物語ではなく、**大衆全般の暮らし**（通勤、住まい、買い物、仕事、言葉、テレビ、学校、旅行）。個人は群衆の一人として映すだけで、名前や家族の筋書きは持たせない
- 語りの型（`channels/if-okane/02_channel_profile.md`「本編の語りの型」）：具体物の変化 → 短い因果 → 小さな逆転 → 次の出来事。画面の左上に「震災から ◯日／◯年」と「次：〇〇」
- 数値：統計の実数は使わない（すべて架空の世界の話）。画面に出す数字は、この世界の架空の値として「架空」と明示する
- 画面のきまり：全編の隅に小さく「フィクション」。人がけがをする場面・遺体・血・苦痛の顔の大写しは使わない。群衆は後ろ姿・遠景・シルエット。壊滅した東京は、明かりの消えた街並み・止まった交通・立ち入りの規制線など「機能が失われた街」として見せる
- この台本は台本初稿の執筆許可によるもの（社長「一旦それで全編書くようClaude Codeに伝えて」）。音声・画像・動画の制作、公開の許可ではない
- 見出しの【】は制作用の区分。語りにも画面にも出さない：【設定】この世界線の条件／【架空】架空の場所・値・言葉／【推論】設定から考えた筋道
- 保険の言い回しは使わない。尺は内容に必要な長さで完稿（説明で延ばさない）。想定は末尾「想定尺」

  - 3〜7秒 地鳴り。ビルの窓の明かりが一斉に揺れ、首都高の照明が波打つ
  - 7〜12秒 東京タワーのような電波塔のシルエット（架空のデザイン）の明かりが消える。遠くから順に、街の明かりがブロックごとに落ちていく
  - 12〜17秒 国会議事堂を思わせる架空の議事堂のドームが、暗闇に沈む。非常灯だけが赤く残る
  - 17〜22秒 止まった山手線のような環状線の車両。止まった首都高。信号の消えた交差点に、立ち尽くす群衆のシルエット

東京が、止まった。
