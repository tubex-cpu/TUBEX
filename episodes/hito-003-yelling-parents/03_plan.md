# 03 企画書：怒鳴る親と、怒鳴らずに伝える親

## 1文で
**同じ保育園に通う2人の子ども──叱るときに怒鳴ってしまう家の「れん」と、怒鳴らずに理由を伝える家の「そら」──を1歳から20歳まで追い、「怒らない＝放任」「あとで優しくすれば帳消し」「怒鳴ると脳が縮む」という3つの思い込みを、子どもの脳と心の研究で1つずつほどく。**

- **2人は「研究ごとの傾向を見せるための例」**。各研究は国・年齢・人数・方法が別々で、れんとそらの差をこれらの要因が生んだとは証明できない。動画では各章を「**考えられる要因の1つ**」として出し、「2人の差は怒鳴ったせいで決まった」とは言わない。最終章も「研究が示すのは平均の傾向で、どの家にも当てはまるわけではない」で締める。
- **両方の家が「叱っている」**。そらの家は叱らない家ではなく、**叱るときに怒鳴らず、なぜいけないかを言葉で伝える家**。ここが「怒らない＝放任」の常識とぶつかる軸（#3）。
- **れんの親も悪者にしない**：子どもを大事に思っていて、仕事と家事で疲れている親。13歳の章で「子どもの行動が親の怒鳴りを増やす」逆向きの流れ（#1）を見せ、**親子の悪循環**として描く。
- **チャンネル**：ヒト図鑑（脳科学ジャンル。`channels/hito-zukan/CHANNEL.md`）。各章を「子どもの脳と心の発達」の切り口で語る。ただし脳の説明は `01_research.md` に出典がある範囲だけ（出典のない「脳が〜する」は足さない）。

- **元にした形式**：ヒト科研究所「親の年収300万と1500万…統計で追ってみた」（`hito-001` の `02_competitors.md` A）。架空の2人 → 年齢の章ごとに研究1つ → 最終章「2人を分けたもの（かもしれないもの）」。
- **ターゲット**：未就学〜中学生の子を持ち、「また怒鳴ってしまった」と気にしている親（20〜40代）。あわせて「怒鳴られて育った」と感じている若い大人。
- **尺**：約12分（横型 1920×1080）。参考チャンネルの上位動画（11〜14分）にそろえる。
- **視聴後に残るもの**：「怒鳴らない＝甘やかす」ではなく、「**叱るときに理由を一言そえる**」ことが研究で良い結果と結びついていた、と知る。自分を責めるより、次に1回だけ試したくなる。

## 登場人物（研究と統計をもとにした架空の2人）
- **れん**：怒鳴る家の子。親は「言っても聞かないから、つい大声になる」。
- **そら**：怒鳴らずに伝える家の子。親は叱るとき「なぜダメか」を短く言う。ルールはある。
- 2人は同じ保育園 → 同じ中学。性別・家の収入は同じくらいに設定（収入の話にしない）。
- 名前は参考チャンネルの子役（ゆうと・はると・さやか・ゆい・あかり・みお）と重ならないものにした。
- 冒頭で「日本でも、3歳半の子の親の約7割が『悪いことをしたとき、たたくことがある』と答えていた（21世紀出生児縦断調査・2000〜2010年代）」（#6）を示し、**怒る・たたくは珍しい家の話ではない**と置く（体罰の数字であって怒鳴る割合ではない、と画面に明記）。

## 構成（年齢ごとの章。各章＝研究1つ）
| 年齢 | 章 | 使う事実 | 常識とぶつかる点・脳と心の切り口 |
|---|---|---|---|
| 0:00 | はじめに：叱られた夜の2人 | #6 | 「怒らないと、ちゃんと育たない？」という問いを立てる。冒頭7秒で「怒らない家の子は、わがままに育つのか」 |
| 1歳 | 眠っている赤ちゃんと、怒った声 | #8（入れる場合） | 眠っていても、赤ちゃんの脳は「とても怒った声」に反応していた。**大人同士の言い争いの研究・20人・意味はまだ分からない**と明示。尺が足りなければこの章を削る |
| 4歳 | ジュースをこぼした日：怒鳴る vs 理由を言う | #3（補足 #7） | **「怒らない＝何も言わない」ではない**。60か国・16万人のデータで、良い結果と結びついていたのは「なぜいけないか説明する」だけ。怒鳴った親は66%、説明した親は80%＝**多くの親は両方している**。（補足：たたいても「その場で言うことを聞く」とは結びつかなかった #7） |
| 13歳 | 反抗期：怒鳴る → 荒れる → また怒鳴る | #1、#5 | ①厳しい言葉のしつけは翌年の問題行動・落ち込みの増加と結びついた ②**逆向き（子の問題行動 → 親の怒鳴り）も同じくらい**＝悪循環 ③**「あとで優しくすれば帳消し」とは言えなかった**（温かさで弱まらず）。ただし言葉の愛情は「健やかさ」のほうと結びついていた（#5）＝ほめるのは無意味ではない |
| 14歳 | 脳のMRI：「よくある厳しさ」が長く続いた子の脳 | #2 | 虐待のない子でも、2.5〜9歳に厳しい育て方（怒る・怒鳴る・たたく等）が高い状態が続いた群は、前頭前野の一部と扁桃体の体積が平均で小さかった。**88人・相関・もともとの違いの可能性**（著者）を画面に出す。「脳が壊れる」とは言わない |
| 20歳 | 「怒鳴ると脳が縮む」は本当？ | #4 | **有名な研究で見つかったのは、聴覚に関わる部分が“大きい”違い（14.1%）**。21人と19人、相関、意味はまだ分からない、と著者自身が書いている。対象は「強い暴言」で、れんの家の「つい大声」と同じではない |
| 最終章 | 2人を分けたかもしれないもの | #1、#3 | 分かれ目は「怒るか怒らないか」ではなく「**叱るときに何を伝えたか**」だったのかもしれない。怒鳴りは親だけのせいではなく親子の悪循環（#1）。研究の範囲で言える次の一歩は「理由を一言そえる」（#3）。責めるより、1回だけ試す |

- **画面の工夫（差別化）**：2人の画面を左右に並べ、章ごとに**年齢のカード**と「その研究の数字1つ＋対象・人数・研究の種類（相関／縦断）」を出す。脳の図は自作SVGで、研究が示した部位だけを示す（色で「小さい／大きい」を誇張しない）。
- **回収**：冒頭の問い「怒らない家の子は、わがままに育つのか」→ 最終章で「研究で良い結果と結びついていたのは、怒らないことそのものより、理由を伝えること。2人の差は1つの原因では決まらない」と答える（2人の差の原因を断定しない）。
- **怒鳴るシーンの描き方**：イラストと吹き出し文字で表す。たたく場面は描かない。怒鳴り声の効果音は使わない（視聴者の負担と、#8 の内容に配慮）。

## 差別化（`02_competitors.md` より）
1. 対談（PIVOT 49万回）・リスト（ショート140万回、「末路10選」）ではなく、**2人の子を1歳→20歳まで年齢の章で追う**
2. 「虐待」ではなく「**ふつうの家庭のつい怒鳴る**」を扱い、**親を責めず悪循環として描く**（#1 の逆向き・#3 の66%）
3. 常識とぶつかる3点（怒らない≠放任／優しさで帳消しにならない／「脳が縮む」ではなく“大きい”）を**研究の範囲で正確に**。強い言葉のタイトルが多い中で、正確さを売りにする
4. ヒト科研究所 11/27 回（教育熱心／自由）の研究（Lamborn 1991 など）は使わず、軸も「厳しい／自由」ではなく「叱り方」

## リスクと対策
- **親を責める・不安をあおる**：表現ルール（`01_research.md`）を守る。れんの親を悪者にしない。最終章は「責めるより1回試す」。
- **研究の言い過ぎ**：子どもの脳の研究（#2・#4・#8）は小さく相関。各章で人数と「相関」を画面に出す。研究の「怒鳴る」の定義（侮辱・たたくを含む等）を添え、れんの「つい大声」に重い研究をそのまま当てはめない。
- **PIVOT 回の後追いに見える**：同じ研究者の研究（#4）を使う。差別化 1〜3 がタイトル・サムネ・冒頭で見えなければ出さない。#4 は「誤解をほどく」章としてだけ使う。
- **出典**：#9（体罰禁止の公式資料）・#10（189）・#11（AAP）は未確認。工程5の前に確認し、できなければ使わない（#9 は論文 #6 の記述の範囲だけにする）。#8 は尺次第で削る。
