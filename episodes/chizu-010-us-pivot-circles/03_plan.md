## ① 企画の全容と狙い
| 項目 | 内容 |
|---|---|
| 主題（ひとことで） | アメリカの真ん中の丸い畑は、雨の少ない土地で、地下の水をくみ上げて回しながらまく機械の形。その水は70年で大きく減った |
| 動画の問い | アメリカの真ん中は、なぜ丸い畑だらけなのか？ |
| 見る人の予想 | 「機械で耕しやすいから」「何かの模様」「水をまく機械の形だろう」 |
| 結論（答え） | 雨が少なすぎて、雨だけでは畑が育たない。だから井戸を真ん中に掘り、長い散水管を円く回して水をまく。四角い区画に円を入れるので四隅が残る。くみ上げているのは、日本の国土より広い地下の水の層で、その水は1950年ごろから琵琶湖約13杯分減った |
| いちばんの驚き | 丸一つ一つの真ん中に井戸がある。その井戸の水位は、場所によって80m以上下がった |
| 見終わって言いたくなる一言 | 「アメリカの丸い畑って、全部真ん中に井戸があるんだって」 |
| 想定視聴者 | 地図・地理が好きな人、Google マップや飛行機の窓で丸い畑を見たことがある人、「アメリカ中部に人が住まない理由」（372万回）を見た人 |

## ③ 予想を超える因果と場面
- 「丸は模様」→ 一つ一つの真ん中に井戸（2章）
- 「雨が多い畑の国」→ 雨は日本の約3分の1。雨だけでは育たない（3章）
- 「地下の湖」→ 砂と小石のすき間の水。日本の国土より広い（4章）
- 「水はなくならない」→ 琵琶湖約13杯分減り、井戸は最大81m下がった（5章）
