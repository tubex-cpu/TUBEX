# 06 サムネ指示書（実施：Codex ／ 監査：Claude）

チャンネル：ヒト図鑑。**`channels/hito-zukan/CHANNEL.md` の「サムネ方針」（二面対比・イラスト調可）が全チャンネル共通の基準より優先**。それ以外の基準（`CLAUDE.md`「サムネ監査基準」、`AGENTS.md`「サムネ実施ルール」）はそのまま適用する。

## 狙い
「同じように暮らしている2人なのに、太り方が違うのはなぜ？」という常識とのズレで止めさせる。答え（座っている時間・食べ過ぎたときの体の反応・盛りの大きさ など）はサムネで言わず、本編の時刻の章に任せる。

## サムネで約束すること（本編で回収済み）
| 約束（どの案で使うか） | 回収するシーン（`script.json` の id） |
|---|---|
| 同じだけ食べ過ぎても、太り方は人によって違う（案A） | `desk-neat`（約10倍）、`final-will` |
| 「朝ごはんを抜くと太る」は研究で言えるのか（案B） | `morning-fact`、`morning-caveat`、`morning-back` |
| 太るのは意志の弱さだけのせいか（案C） | `final-will`、`desk-same`、`final-genes`、`final-answer` |
| 2人の差がどこにあったか（全案共通の大きな問い） | `intro-hook` → `sleep-back` → `final-answer` |

## 素材・前提
- **推奨タイトル（`04_titles.md` A案）**：痩せている人と太っている人、同じ1日のどこで差がつくのか｜朝7時から夜24時まで研究で追ってみた【脳科学】
  → **主コピーで繰り返さない語：「同じ1日」「どこで」「差がつく」（「差」1字も避ける）「研究で追う」「痩せている／太っている」**（後者は左右ラベルでだけ使う）
- **左右の人物とラベル**（`script.json` の `characters` と一致させる）
  - 左：りょう（35歳・会社員・身長170cm・`build: slim`）／ラベル案「痩せている人」
  - 右：たくみ（35歳・同じ会社の同期・身長170cm・`build: round`）／ラベル案「太っている人」
  - どちらも同じスーツ・同じ表情の強さで、**生活の質を変えて描かない**（太っている側を汚い部屋・お菓子まみれ・だらしない姿勢にしない）。ラベルの語は `characters` のまま。「デブ」「ガリ」「肥満体」などは不可
  - ラベルは `script.json` の `characters.left.label` / `characters.right.label` から読む（`types.ts` を変えずに済む）。主コピーは `thumbnail.line1` / `line2`
- **使ってよい数字**（`01_research.md` の出典あり・本編で言っているもの）
  - 約10倍：同じだけ食べ過ぎても太り方は約10倍違った（#9 Levine 1999 *Science*、16人、`desk-neat`）。**「約」を落とさない**。「10倍太る」（体重が10倍）と読める言い方は不可
  - 約2時間：肥満の人は1日約2時間長く座っていた（#8 Levine 2005 *Science*、20人、`desk-sit`）。kcal（350kcal）は出さない
  - 32.4%／約3人に1人：20歳以上の男性の肥満の割合（#4 令和6年 国民健康・栄養調査、`intro-stat`）
  - 30%：盛りが大きいと30%多く食べた（#11a Rolls 2002、`lunch-portion`）
- **使ってはいけない数字**
  - 約508kcal（#1 Hall 2019）をサムネに出すのは不可（1日あたりの差で、1食・弁当1つの差と読まれやすい。`evening-caveat` 参照）
  - 350kcal、Lichtman の 47%／51%、「1年で○kg」の換算、体脂肪の実数、「75%は遺伝」（`final-genes` は「75%は遺伝で決まる、ではない」と言っている）、盛りに気づいた 45%
  - そのほか `01_research.md` にない数字すべて

## 主コピー案（ラベルを除き 2行・合計12字以内。「／」は改行位置）
ラフ3案は**コピー・構図・主役表現をそれぞれ変える**。

| 案 | 主コピー | 字数 | 常識とのぶつかり／本編を見ないと解けない点 | 構図・主役表現の方向 |
|---|---|---|---|---|
| A | **太り方が／約10倍違う？**（11字） | 4＋7 | 「食べた分だけ同じように太る」とぶつかる。なぜ違うのか（運動ではない動き）は本編を見ないと分からない | 「同じだけ食べ過ぎた」前提は図で見せる：2人の前に**同じ大盛りの皿**、体の輪郭の変化だけが違う。中央の仕切りは同じ皿をまたぐ |
| B | **朝ごはん抜くと／太る？**（10字） | 7＋3 | 「朝食を抜くと太る」という常識に疑問を投げる。答え（言えなかった）は本編 | **時計で時間軸を見せる**：左右とも「7:00」の時計と朝の光。左（りょう）は朝ごはん、右（たくみ）はコーヒーだけ（`03_plan.md`「朝ごはんを抜くたくみ、食べるりょう」と同じ向きにする） |
| C | **意志の弱さ／のせい？**（9字） | 5＋4 | 「太るのは意志が弱いから」という思い込みとぶつかる。違うなら何か、は本編 | 2人のデスクワーク姿（左は立ったり歩いたり、右は座りっぱなし）。**体の仕組みの図を1つだけ**：2人の足元に「座っている時間」の短い帯（約2時間の差）を図で |

- 案A は「違う」で「差」を避けている。「約」は落とさない（12字に収めるため「同じ食べ過ぎで」を文言に入れず、皿の図で見せる）。数字の位置は左右の仕切りの上か下中央。右下には置かない
- 案C の文言は、太っている側を責める文脈に見せないため**画面下中央に置き、右の人物に矢印などで結び付けない**
- 研究の範囲を超えない：「太らない体質」「痩せる方法」「食べても太らない」は不可（16人の実験で、太り方に幅があったことまで）

## チャンネルのサムネ方針（二面対比）の要件
- 画面を左右に2分割、左にりょう・右にたくみ。中央の仕切りで明暗・暖色/寒色・状況の違いがひと目で分かる
- 左右それぞれに短いラベル（色の違う箱）。**参考サムネの「暗い赤×紺の箱」と同じ配色＋同じ構図の組み合わせにしない**
- 下に大きな問いのコピー（極太ゴシック＋太フチ。要の語だけ赤か黄）。フォントは OFL（Noto Sans JP 900 など）。Dela Gothic One 不可
- 主役はイラスト調可（半写実の生成イラスト or 表情の分かるシンプルなキャラ）。実在の人物に見せない
- 320px 幅で主コピーが一瞬で読める・何の話か分かる。右下（再生時間の位置）に重要要素を置かない。意味のない飾りを入れない
- 本編の1コマに見えない（本編の紺背景・同じ構図・同じ装飾を流用しない）

## 差別化の方向（2点以上を完成サムネで見えるようにする）
1. **時計・時刻で「1日」を見せる**（参考チャンネル 11/26 回は「20年」の時間軸。こちらは朝7時〜夜24時）
2. **体の仕組みを示す要素を図版で1つだけ**（座っている時間の帯、または食べ過ぎたときに増える「運動ではない動き」）。企画にない脳・DNA・数式・カロリー計算式は雰囲気づけで足さない
3. 文言は参考チャンネルの 11/26 回「なぜ『全然食べてない』という人ほど太っているのか」と**同じ切り口（食べてないのに）を使わない**。（候補から外した理由：ほぼ同じ文言になるため）

## NG
- 断罪・脅しの語：「末路」「壊れる」「毒」「ヤバい」「デブ」「ガリ」「怠け者」
- 根拠のない数字（「9割が知らない」など）、上の「使ってはいけない数字」
- 体型をからかう描写（太っている側を笑い者・不潔・怠け者・汗だく・だらしなく描く、体を誇張する）。**暗い側（寒色・暗い側）を悪者に描かない**：明暗は状況の違いとして使い、人物の善悪にしない
- 「痩せる方法」「太らない体質」など本編で言っていない約束
- 右下（YouTube の再生時間表示の位置）に重要要素（数字・顔・ラベル）を置く
- 他者のサムネ・キャラ・画像・ロゴの使用やトレース、画面上の「概念図」などの説明ラベル

## 進め方
1. **ラフ3案 → 社長が方向を選ぶ → 完成版**。社長の選択前に最終化しない
2. ラフは `episodes/hito-001-thin-fat-day/thumbnail_drafts/` に別ファイル（例：`draft-a.png`／`draft-b.png`／`draft-c.png`）。**既存の `episodes/hito-001-thin-fat-day/thumbnail.png` と本編（`Episode.tsx`・`HitoEpisode.tsx`・`script.json` の scenes）は上書きしない**
   - 注意：`npm run render -- <id> --thumb-only` は `episodes/<id>/thumbnail.png` に書き出す。ラフ段階で使った場合は、書き出された PNG を `thumbnail_drafts/` に移し、`thumbnail.png` は `git checkout -- episodes/hito-001-thin-fat-day/thumbnail.png` で元に戻す
   - `video/src/Thumbnail.tsx` は全エピソード共通。ヒト図鑑用のレイアウトは `series === 'ヒト図鑑'` などで分岐させ、`001-sleep-without-brain` の見た目を変えない
3. 完成時（社長が選んだ後）：`cd video && npx tsc --noEmit && npm run render -- hito-001-thin-fat-day --thumb-only` で 1280×720 の PNG を出し、`thumbnail.png` を commit
