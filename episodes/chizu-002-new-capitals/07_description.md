# 概要欄（案）：chizu-002-new-capitals

**チャンネル**：地球の事情（@chikyu-no-jijo）
**タイトル（仮）**：首都をゼロから造った国々。なぜ大都市を首都にしなかったのか？

---

アメリカのワシントン、ブラジルのブラジリア、オーストラリアのキャンベラ、ナイジェリアのアブジャ。どれも、首都にするために計画して造った街です。そして今、インドネシアも新しい首都ヌサンタラを造っています。なぜ国は、わざわざ首都をゼロから造るのか。地図で4つの型に分けて読み解きます。

0:00 首都と大都市
0:35 型1 大都市どうしの争いを避ける（ワシントン・キャンベラ）
1:30 型2 国の内陸を開く（ブラジリア）
2:08 型3 どの集団にも偏らない場所（アブジャ）
2:44 型4 今の首都の限界（ジャカルタ・ヌサンタラ）
3:20 4つの型を重ねる
