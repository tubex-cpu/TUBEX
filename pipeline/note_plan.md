# note 工程案（たたき台・社長の承認待ち）

社長の前提（2026-10-25）：2027-01 までに note 販売も含めた合計で月50万円。note は**ほぼ自動化**で進め、**有料 note** を販売する。
この案が承認されたら、`pipeline/README.md` に工程として組み込む。

## 基本の考え方
- **YouTube のリサーチを使い回す**：動画用に集めた出典付きの事実（`01_research.md`）と競合調査を、note の素材にする。新しく調べ直すコストを減らす。
- **無料 note は「スキ集め」ではなく「有料の入口」**：評価は スキ数 ではなく、無料 → 有料の購入率で見る（根拠は下の「調べたこと」）。
- **実用ノウハウ系を主力にする**：note 公式の分析では、実用ノウハウ系は読み物系より平均単価が約1.9倍。
- **事実は出典付きのみ**：動画と同じルール。有料部分でも確認できない数字は書かない。

## 何を売るか（ゲートN0 で社長が決める）
新規2チャンネルのジャンル（ゲート0）が決まってから決める。候補の型：
1. **チャンネルのジャンルの深掘り版**：動画で扱ったテーマの詳しい解説・出典一覧・まとめ表（動画の概要欄から誘導）
2. **ノウハウ系**：「AI で顔出しなし YouTube を追加費用0で回す方法」など、このリポジトリの運用そのもの（note 公式分析で「テクノロジー・AI活用」が急上昇1位）
※ どちらにするか・両方やるかは、ゲート0の結果と合わせてゲートN0で社長が選ぶ。

- 回し方は YouTube と同じ（Routine → PR → `@codex review` → 差し戻しは直して再提出、3回続いたら社長に相談）。
- 売上・PV は note の管理画面にしかないため、月1回、社長がスクショか数字を `notes/` か PR に貼る。

## 費用
- 追加費用0（note の登録・投稿は無料）。売上からは note の手数料が引かれる：
  事務手数料（クレジットカード 5% など購入者の決済手段による）＋プラットフォーム利用料（有料記事は 10%、定期購読マガジンは 20%）＋振込手数料 270円/回。
  例：1,000円の記事をカードで購入 → 手数料 145円（振込手数料は別）。
- 月50万円の目標から逆算した本数・価格は、ゲートN0 で競合 note の実数値を見てから出す（今は根拠がないので書かない）。

## 調べたこと（出典）
- 手数料：[note ヘルプ「コンテンツを販売する際に引かれる手数料」](https://www.help-note.com/hc/ja/articles/360011358873)
- note 公式の有料記事分析（2025年1〜10月に投稿され売れた約30万件）：実用ノウハウ系は平均単価が読み物系の約1.9倍で、無料部分は約1.5倍長い／文字数と売上の相関はほぼゼロ／急上昇カテゴリはテクノロジー・AI活用（成長率268.6%）、SNS・コンテンツ運用（258.7%）
  [note株式会社の発表](https://note.jp/n/n8522197d1ced)・[PR TIMES](https://prtimes.jp/main/html/rd/p/000000360.000017890.html)
- スキ数と有料記事の売上の関係を示す統計は見つからなかった。個人の体験談では「スキ数と売上は関係ない」「フォロワーが少なくても売れた」という報告がある（統計ではない）：
  [ナカヤマ](https://note.com/nakayama6212/n/n078273b0819c)・[瀬戸アオイ](https://note.com/dtfood_setoaoi/n/n562d0fcb2b11)
- ※ 2026-10-25 時点、この作業環境からは note.com・help-note.com・prtimes.jp に直接接続できず、検索結果の要約で確認した。ゲートN0 の前に原文を確認し直す。
