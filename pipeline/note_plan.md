## 基本の考え方
- **無料 note は「スキ集め」ではなく「有料の入口」**：評価は スキ数 ではなく、無料 → 有料の購入率で見る（根拠は下の「調べたこと」）。
- **実用ノウハウ系を主力にする**：note 公式の分析では、実用ノウハウ系は読み物系より平均単価が約1.9倍。
- **事実は出典付きのみ**：動画と同じルール。有料部分でも確認できない数字は書かない。

## 何を売るか（ゲートN0 で社長が決める）
ジャンルは不倫。その中の切り口を、競合の有料 note の実数値（価格・スキ・購入数が見えるもの）で比べてゲートN0 に出す。候補の例（比べる対象であって、決定ではない）：
- 不倫された側の対処（証拠・慰謝料・離婚／再構築の判断）の実用ノウハウ
- 創作と明記した体験談の読み物
※ note 公式の分析では実用ノウハウ系の単価が高い（下の「調べたこと」）。不倫ジャンルで守ること（実在人物・創作の明記・法律情報の出典・違法な調査方法）は `pipeline/README.md`「note」。

## 費用
- 追加費用0（note の登録・投稿は無料）。売上からは note の手数料が引かれる：
  事務手数料（クレジットカード 5% など購入者の決済手段による）＋プラットフォーム利用料（有料記事は 10%、定期購読マガジンは 20%）＋振込手数料 270円/回。
  例：1,000円の記事をカードで購入 → 手数料 145円（振込手数料は別）。
- 週2投稿の目標に対する無料・有料の内訳、価格、月50万円への寄与見込みはゲートN0で競合の実数値を見てから出す。根拠のない売上予測や達成保証はしない。
