# 制作キュー

チャンネルごとに上から順に処理する。複数のチャンネルが進められるときは、表の上のチャンネルを先に進める（利用上限で途中終了しても最優先が進むように）。Routine は1回の起動で **各チャンネルの未完了の最初の工程を1つずつ** 進める（利用上限に達したらそこで終了）。
作業前に必ずそのチャンネルの `channels/<name>/CHANNEL.md` を読む。エピソード ID は `<チャンネル>-<連番>-<英語スラッグ>`（例：`habi-002-proto-elamite`）。note は `notes/note-<連番>-<英語スラッグ>/`。

| ID | チャンネル | テーマ | 状態 |
|---|---|---|---|
| new-channels | ②③ 新規2チャンネル（`channels/new-channels/`） | ジャンル選定（市場が大きく穴場のジャンルを2つ）。**最優先**（社長の目標の対象） | 工程0 チャンネル設計から（YouTube API 必須） |
| habi-001-sumer | ① ハビ判事（`channels/habi-judge/`） | 日本人とシュメール判決（社長作の台本あり） | 公開済みかどうか社長の回答待ち。未公開なら台本の出典検証→動画化 |

| note | note（有料 note・ジャンル：不倫・`pipeline/README.md`「note」） | 不倫ジャンルの切り口・価格帯の方針（ゲートN0）。YouTube とは独立して進める | 工程N0 方針から |
