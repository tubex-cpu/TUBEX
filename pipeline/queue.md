# 制作キュー

チャンネルごとに上から順に処理する。複数のチャンネルが進められるときは、表の上のチャンネルを先に進める（利用上限で途中終了しても最優先が進むように）。Routine は1回の起動で各チャンネルとnoteについて、着手可能な案件の最初の未完了工程を1つずつ進める（利用上限で終了）。承認・監査待ちの案件を飛ばし、独立した他案件へ進む。ゲート0／N0前の後続制作には進まない。
作業前に必ずそのチャンネルの `channels/<name>/CHANNEL.md` を読む。エピソード ID は `<チャンネル>-<連番>-<英語スラッグ>`（例：`habi-002-proto-elamite`）。note は `notes/note-<連番>-<英語スラッグ>/`。
