# 制作キュー

チャンネルごとに上から順に処理する。複数のチャンネルが進められるときは、表の上のチャンネルを先に進める（利用上限で途中終了しても最優先が進むように）。Routine は1回の起動で **各チャンネルの未完了の最初の工程を1つずつ** 進める（利用上限に達したらそこで終了）。
作業前に必ずそのチャンネルの `channels/<name>/CHANNEL.md` を読む。エピソード ID は `<チャンネル>-<連番>-<英語スラッグ>`（例：`habi-002-proto-elamite`）。
