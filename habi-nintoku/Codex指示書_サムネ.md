# Codex向け指示書：仁徳天皇陵判決のサムネイル（競合のブラッシュアップ）

リポジトリ `tubex-cpu/TUBEX`、ブランチ `claude/nice-wright-du0dch`、フォルダ `habi-nintoku/` で作業する。

## ゴール
YouTubeで伸びている競合動画のサムネを分析し、その「勝ちパターン」を取り入れつつ、**コピー・デザイン・使用する画像**の3点を改良したサムネイルを3枚作る。

## 1. 競合の調査
1. YouTubeで「仁徳天皇陵」「大仙古墳」「古墳 謎」「天皇陵 発掘」などを検索し、**直近2年以内で再生数が多い動画**を5〜10本選ぶ。チャンネル登録者数に対して再生数が大きく伸びている動画を優先する。
2. 各サムネについて、次を表にまとめる。
   - 動画タイトル、URL、再生数、投稿日、チャンネル登録者数
   - コピー（文字の内容・文字数・何段か・どの言葉が一番大きいか）
   - デザイン（文字色・縁取り・背景の暗さ・文字の位置・余白）
   - 画像（何を写しているか：空撮、拝所、遺物、人物など。画面のどこに置いているか）
   - なぜ押したくなるのか（数字、禁止・禁断、最新、矛盾、恐怖などのどれか）
3. 共通する勝ちパターンを3つ以内にまとめる。

## 2. ブラッシュアップの方針
競合の「型」は取り入れてよいが、次の3点で必ず上回る。

- **コピー**：下の「使ってよい事実」だけで作る。競合より具体的な「今」の情報（2025〜2026年の出来事）を入れて、新しさで勝つ。ただし答えは言い切らず、「えっ？」と思わせる疑問・矛盾の形にする。
- **デザイン**：3段フォーマットを基本にする（上＝白の大きな文字で題材／中＝白の小さめの文字でひとこと／下＝赤の特大文字でフック）。スマホの小さな表示でも読めるよう、太い黒の縁取りをつけ、背景は暗めにする。
- **使用する画像**：下の「使ってよい画像」から、競合より目を引くものを選ぶ。空撮や遺物の質感など、ひと目で「本物」とわかるものを優先する。

## 3. 作るもの（3枚）
3つの切り口で1枚ずつ作る。コピーは下の案をたたき台にして、競合分析の結果を踏まえて改良してよい（事実の範囲内で）。

| ファイル | 切り口 | たたき台のコピー（上／中／下） |
|---|---|---|
| `サムネ/thumbnail-1.jpg` | **最優先：タブー×被葬者不明×新発見** | 立入禁止の仁徳天皇陵／2026年 宮内庁の調査で「謎の土壇」／眠るのは誰だ |
| `サムネ/thumbnail-1b.jpg` | 速報・新発見 | 仁徳天皇陵／2026年、宮内庁の調査で浮かんだ／もうひとつの埋葬 |
| `サムネ/thumbnail-2.jpg` | 逆張り | 仁徳天皇陵／眠っているのは／仁徳天皇じゃない？ |
| `サムネ/thumbnail-3.jpg` | 恐怖・禁断 | 仁徳天皇陵／明治に一度だけ開いた／禁断の石棺 |

別の切り口として「仁徳天皇陵／150年ぶりに見つかった／消えた宝」も試してよい。良ければ `サムネ/thumbnail-4.jpg` として追加する。

thumbnail-1 は「タブー（立入禁止・開けてはいけない）」「誰が眠っているのか不明」「2026年の新発見」の3要素を必ず1枚に入れる。ただし「誰も入れない」とは書かない（2025年に研究者が立ち入っている）。土壇は地形の確認なので、埋葬施設が見つかったとは書かない。

## 使ってよい事実（コピーはこの範囲で）
- 2026年5月：宮内庁が「赤色立体図」で、前方部に土を盛った「土壇」とみられる地形を確認。未知の埋葬施設が残っている可能性がある（共同通信）。
- 2025年3月：17の学会の研究者が、ボートで濠を渡り、初めて仁徳天皇陵の墳丘に立ち入った。
- 2025年6月：明治5年に見つかった副葬品（金銅の小刀・甲冑のかけら）の実物が、150年以上たって國學院大學で確認された。
- 明治5年（1872年）：前方部から石室と石棺が現れたが、ふたは開けられず埋め戻された。
- 被葬者は確かめられていない。息子（履中天皇）の墓とされる古墳のほうが先に造られたとみられる。
- 墳丘の長さは約486メートル。長さと面積では世界最大級だが、高さと体積ではピラミッドに及ばない。
- 古代の方法なら工期15年8か月、のべ約680万人という試算（大林組、1985年）。
- ボストン美術館に「伝・仁徳天皇陵出土品」があるが、仁徳天皇陵から出た可能性は低いとされる。
- 百舌鳥古墳群は、もとは100基以上あったが、今残るのは44基。

## 守ること
- **競合サムネの画像・イラスト・切り抜きは一切使わない。** 真似してよいのは型（文字配置・色の使い方・構図）だけ。
- 上のリスト以外の画像（ネットの画像、生成画像、報道写真）は使わない。
- ○・△・× の記号は使わない。
- 人物（像・埴輪・肖像を含む）の顔に文字を重ねない。
- 事実と違うこと、本編で言っていないことは書かない（「発見」「判明」は事実のとおりのときだけ）。
- 1280×720、JPEG、2MB未満。

## 納品
1. 画像を `habi-nintoku/サムネ/` に保存する。
2. 競合分析の表と、それぞれのサムネで「何をどう改良したか」を `habi-nintoku/サムネ/分析.md` に書く。
3. コミットして同じブランチにプッシュする：
   `git add habi-nintoku/サムネ && git commit -m "habi-nintoku：競合分析とサムネイル" && git push origin claude/nice-wright-du0dch`
4. 完了報告に、作ったファイル名・使ったコピーと画像・競合から取り入れた点・改良した点・コミットを書く。
