# Codex向け指示書：マチュピチュ判決のサムネイル（競合のブラッシュアップ）

リポジトリ `tubex-cpu/TUBEX`、ブランチ `claude/nice-wright-du0dch`、フォルダ `habi-machu/` で作業する。

## ゴール
YouTubeで伸びている競合動画のサムネを分析し、その「勝ちパターン」を取り入れつつ、**コピー・デザイン・使用する画像**の3点を改良したサムネイルを3枚作る。たたき台として、Claudeが作った3枚が `habi-machu/サムネ/Thumb1Laser.png`・`Thumb2Bingham.png`・`Thumb3People.png` にある（文言は `habi-machu/サムネ案.md`）。

## 1. 競合の調査
1. YouTubeで「マチュピチュ」「マチュピチュ 謎」「インカ帝国 謎」「マチュピチュ 都市伝説」などを検索し、**直近2年以内で再生数が多い動画**を5〜10本選ぶ。旅行・音楽の動画は除く。チャンネル登録者数に対して再生数が大きく伸びている動画を優先する。
2. 各サムネについて、次を表にまとめる。
   - 動画タイトル、URL、再生数、投稿日、チャンネル登録者数
   - コピー（文字の内容・文字数・何段か・どの言葉が一番大きいか）
   - デザイン（文字色・縁取り・背景の暗さ・文字の位置・余白）
   - 画像（全景、空撮、石組み、人物など。画面のどこに置いているか）
   - なぜ押したくなるのか（数字、禁断、最新、矛盾、恐怖などのどれか）
3. 共通する勝ちパターンを3つ以内にまとめる。

## 2. ブラッシュアップの方針
競合の「型」は取り入れてよいが、次の3点で必ず上回る。

- **コピー**：下の「使ってよい事実」だけで作る。競合より具体的な「今」の情報（2026年の調査）を入れて、新しさで勝つ。答えは言い切らず、「えっ？」と思わせる疑問・矛盾の形にする。
- **デザイン**：3段フォーマットを基本にする（上＝白の大きな文字で題材／中＝白の小さめの文字でひとこと／下＝赤の特大文字でフック）。スマホの小さな表示でも読めるよう、太い黒の縁取りをつけ、背景は暗めにする。
- **使用する画像**：下の「使ってよい画像」から、競合より目を引くものを選ぶ。定番の全景だけで終わらせず、雲・霧・古写真など、ひと目で雰囲気が伝わるものを優先する。

## 使ってよい事実（コピーはこの範囲で）
- 2026年3月30日：JICA・ペルー文化省・福島県の測量会社ふたばが、ドローンに積んだレーザー（UAV-LiDAR）で調査。北東の段々畑「アンデネス・オリエンタレス」の全体像を初めて把握。月の神殿の近くで、高さ約2.7mのL字型の壁のような構造、左右対称の3段の段々畑、長さ約2mの四角い石材（裏に空洞）などの**「遺構の候補」**を確認（発掘による確認はこれから）。
- 2026年8月：ペルー文化省の発表。マチュピチュの東、マンドールの壁の周辺で、インカ以前の道が合計2.5km以上（ワルシャワ大学などの調査）。
- 1911年7月24日にビンガムが到着したとき、遺跡には農家が住んでいた。壁には「リサラガ 1902年」の炭の書き込みがあった。
- インカ時代の都市の名前は「ワイナピチュ」だった可能性が高い（2022年の研究、1588年の記録）。
- 骨の放射性炭素年代：1420年ごろから1530年ごろまで住んでいた（2021年）。
- 2023年の遺伝子研究：住人は帝国の海岸・高地・アマゾンなど各地から来ていた。68人の中で血のつながりが分かったのは母と娘の1組だけ。
- マチュピチュ村の初代村長（1948年）は、福島県大玉村出身の野内与吉。ふたばが調査を始めたのは、大玉村が震災で富岡町の町民を受け入れた恩返しがきっかけ。

## 守ること
- **競合サムネの画像・イラスト・切り抜きは一切使わない。** 真似してよいのは型（文字配置・色の使い方・構図）だけ。
- 上のリスト以外の画像（ネットの画像、生成画像、報道写真）は使わない。
- 「新発見」「解明」「判明」とは書かない（見つかったのは「遺構の候補」）。
- ○・△・× の記号は使わない。
- 人物（肖像を含む）の顔に文字を重ねない。
- 事実と違うこと、本編で言っていないことは書かない。
- 1280×720、JPEG、2MB未満。

   `git add habi-machu/サムネ && git commit -m "habi-machu：競合分析とサムネイル" && git push origin claude/nice-wright-du0dch`
4. 完了報告に、作ったファイル名・使ったコピーと画像・競合から取り入れた点・改良した点・コミットを書く。
