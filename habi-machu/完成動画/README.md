# マチュピチュ判決 完成動画（1080p・27分46秒・約426MB）のダウンロード方法

GitHubは1ファイル100MBまでなので、動画を5個に分けて置いています。**5個を全部ダウンロードして、パソコンで1本につなぎます**（つなぐだけで、画質は変わりません）。

- [part2](https://github.com/tubex-cpu/TUBEX/raw/claude/nice-wright-du0dch/habi-machu/%E5%AE%8C%E6%88%90%E5%8B%95%E7%94%BB/habi-machu-1080p.mp4.part2)
- [part3](https://github.com/tubex-cpu/TUBEX/raw/claude/nice-wright-du0dch/habi-machu/%E5%AE%8C%E6%88%90%E5%8B%95%E7%94%BB/habi-machu-1080p.mp4.part3)
- [part4](https://github.com/tubex-cpu/TUBEX/raw/claude/nice-wright-du0dch/habi-machu/%E5%AE%8C%E6%88%90%E5%8B%95%E7%94%BB/habi-machu-1080p.mp4.part4)

## 2. 1本につなぐ
### Windows（ダウンロードしたフォルダのアドレス欄に cmd と入力してEnter）
```
copy /b habi-machu-1080p.mp4.part1+habi-machu-1080p.mp4.part2+habi-machu-1080p.mp4.part3+habi-machu-1080p.mp4.part4+habi-machu-1080p.mp4.part5 habi-machu-1080p.mp4
```
### Mac（ターミナル）
```
cd ~/Downloads
cat habi-machu-1080p.mp4.part1 habi-machu-1080p.mp4.part2 habi-machu-1080p.mp4.part3 habi-machu-1080p.mp4.part4 habi-machu-1080p.mp4.part5 > habi-machu-1080p.mp4
```
