# 企画書：なぜ、大人になると友達がいなくなるのか

※この下の「ChatGPTに渡すプロンプト」をそのままコピーして使ってください。

## 企画の根拠（データ）
- 需要：同じテーマの通常動画が、個人の発信者で大きく伸びている
  - 大愚和尚「友達がいない人の2つの問題点」290万再生
  - ひろゆき切り抜き「これが友達という偶像の正体です」141万再生
- 空き：非属人の動画は「心理の断片」の32万（5分）が最大。**20分以上の非属人の動画は見つからなかった**
- リスク：非属人の「社会のモヤほどき」が同じテーマで112再生（登録25人・12分）。**テーマだけでは伸びない**ので、サムネとタイトルで差をつける必要がある
- 差別化：競合は「心理（あなたの心）」で説明する → こちらは「社会の仕組み（場所・時間・人生の段階・日本社会）」で説明し、**「あなたのせいじゃない」**と言い切る

## ChatGPTに渡すプロンプト
```
あなたはYouTubeのサムネイルとタイトルのプロです。以下の企画で、タイトル案とサムネイル案を作ってください。

# チャンネル
- 名前：人間関係のしくみ帳｜おとなの社会学（顔出しなし・ナレーション＋図解の雑学チャンネル）
- 視聴者：30〜50代。人間関係に疲れている人
- ブランドの色：紺(#1F2A44)・生成り(#F3EDE2)・アクセントのオレンジ(#E8833A)
- 方針：心理学（個人の心）ではなく、社会学（環境・時間・人生の段階・日本社会の仕組み）で説明するチャンネル

# 動画
- テーマ：なぜ、大人になると友達がいなくなるのか
- 尺：約25分
- 中身：①友情が生まれる3つの条件（近くにいる・何度も偶然会う・気を張らずにいられる）が大人になると消える、②友達になるには長い時間が必要（研究による目安）、③就職・結婚・子育てで人生の段階がずれ、話も合わなくなる、④日本は会社以外の人づきあいが国際的に見ても少ない（定年後に人間関係が消える例）、⑤人間関係は数年で入れ替わるのが普通。さらに「SNSでつながっていれば大丈夫？」への答え（知っていると頼れるは違う）。最後に明日からできる対処法
- 視聴後の感情：「自分が悪いんじゃなかった」と安心し、誰かに連絡したくなる

# 参考にしてよいタイトルの型（非属人チャンネルで伸びたものを、学問名を外して示す）
- 「一見普通なのに..実は『奥深い人』の特徴 8選」型（元は31万再生）
- 「なぜ、尽くすほど嫌われるのか」型（元は32万再生）
- 「優しい人にしかできないさりげない行動9選【雑学】」27万再生

# 避けたい型（伸びていても使わない）
- 「※大人になると分かる酷い現実※これが『友達』という偶像の正体です」のような、不安をあおる・断定的に突き放す型
- 「大人になると、どうして友達が減るの？」（他チャンネルの既存タイトル）と語順・言葉がほぼ同じもの

# 出してほしいもの
1. タイトル案を10個。条件：
   - 【】も含めて28〜40文字
   - 必ず「友達」という言葉を入れる
   - 【社会学】を付けた案を5個、学問名を付けない案を5個（どちらが伸びるか比べるため。「心理学」「社会心理学」は使わない）
   - 「あなたのせいじゃない」という安心感か、「意外な理由」という好奇心のどちらかを入れる
   - 研究の数値（例：200時間）を使う場合は「研究では」「目安」などを添え、言い切らない
   - 釣りタイトル・嘘・不安をあおりすぎる表現は禁止
2. 上の10個から、おすすめのベスト3とその理由
3. サムネイル案を3パターン。それぞれ：
   - サムネに載せる文字（最大13文字。タイトルと同じ文言にしない）
   - 構図（人物は顔なしのシルエットかイラスト。実在の人物の写真は使わない）
   - 配色（ブランドの色を基本に）
   - そのサムネが目を止める理由
4. ベスト1のサムネの背景画像を、1280x720pxで、文字を入れずに生成してください（文字は後から自分で載せます）。文字を置く余白を左か右に空けてください
```

## 生成後のチェックリスト
- [ ] タイトルとサムネの文字が同じになっていないか（同じだと情報が増えない）
- [ ] 「社会のモヤほどき」の既存タイトルと見分けがつくか
- [ ] 数値を使ったタイトルが言い切りになっていないか
- [ ] 実在の人物やほかのチャンネルの画像を使っていないか
- [ ] スマホの小さい画面でも文字が読めるか
