# チャンネル設計

## コンセプト
**大人の人間関係のモヤモヤを、「あなたのせい」ではなく「社会の仕組み」で解く、20〜30分の雑学チャンネル。**

- 対象：30〜50代。職場・家族・地元の人間関係に疲れている人
- 運営：非属人（顔出しなし、ゆっくり・ずんだもんなし）。テキスト＋図解＋落ち着いたナレーション
- 競合との違い：競合（深淵回廊、大神さんの謎解き部屋、ちょっと心がラクになる雑学）は「心理学＝個人の心」で説明する。こちらは「社会学＝環境・時間・役割・集団」で説明する
- 視聴後の感情：「自分が悪いんじゃなかった」という安心と、「じゃあこうすればいい」という行動

## チャンネル名

| 順位 | 名前 | 理由 | 被りの調査 |
|---|---|---|---|
| ◎ | **人間関係のしくみ帳｜おとなの社会学** | 30〜50代が検索するのは「社会学」ではなく「人間関係」。前半を悩みの言葉、後半を差別化の言葉にした（反対派レビューで変更） | 「人間関係のしくみ帳」で検索：同名なし。似た名前は「人間関係改善のヒント帳」（登録4,210人）と「人生のしくみ帳」（登録0人）。前者は「〜帳」が共通するので、サムネの色・ロゴで見分けがつくようにする |
| ○ | おとなの社会学ノート | やわらかく、講義っぽさがない | **「大人の社会学」（登録9人）とほぼ同じ文字列で検索で混同される**ため2番手に下げた |
| △ | なぜかの社会学 | 「なぜ、〇〇なのか」というタイトルの型とそろう | 「理不尽な社会学」（登録1人）など、似た名前が多い |

- ハンドル案：`@ningenkankei-shikumi`
- **注意**：ハンドルが空いているかは、YouTubeの作成画面で必ず確認してください（APIでは確認できません）

## チャンネルプロフィール画像（アイコン）
- サイズ：800×800px（表示は円形に切り抜かれる）
- デザイン：開いたノートの上に、人と人をつなぐ線（ネットワーク図）を描いたシンプルなアイコン
- 色：背景はくすんだ紺（#1F2A44）、線は生成り（#F3EDE2）。**寄り添う2つの点を温かいオレンジ（#E8833A）**にして、オレンジが全体の約30%になるようにする（1点だけだと縮小表示で消えるため。反対派レビューで変更）
- 文字は入れない（小さく表示されると読めないため）

**ChatGPT（画像生成）用のプロンプト**
```
YouTubeチャンネルのプロフィールアイコンを作ってください。800x800px、正方形、中央に収まる構図（円形に切り抜かれます）。
モチーフ：開いたノートの上に、5〜6個の点を線でつないだシンプルなネットワーク図。中央で寄り添う2つの点を大きめの温かいオレンジ(#E8833A)にし、オレンジが画面の約30%を占めるように。ビジネス・IT風ではなく、やさしく安心感のある雰囲気で。
背景はくすんだ紺(#1F2A44)、線とノートは生成り色(#F3EDE2)。フラットデザイン、線は太め、余白多め。
文字・人物の顔・ロゴは入れないでください。小さく表示しても形がわかるようにしてください。
```

## チャンネルバナー
- サイズ：2560×1440px。どの端末でも表示される安全領域は、中央の1546×423px
- 文字（安全領域の中に置く）：
  - メイン：**人間関係のしくみ帳**（下に小さく「おとなの社会学」）
  - サブ：人間関係のモヤモヤは、あなたのせいじゃない。
  - 小さく：毎週更新｜20〜30分の"聞ける"社会学
- 絵：左側に、ノートから伸びる人と人のつながりの線。右側は余白（文字のため）
- 色：アイコンと同じ（紺・生成り・オレンジ）

**ChatGPT（画像生成）用のプロンプト**
```
YouTubeチャンネルバナーを作ってください。サイズ2560x1440px。重要な要素はすべて中央1546x423pxの範囲に収めてください。
背景：くすんだ紺(#1F2A44)、ごく薄い紙の質感。
中央左寄り：開いたノートから、点と線のネットワーク図が右へ広がっていくイラスト（フラット、生成り色#F3EDE2、寄り添う2つの点をオレンジ#E8833A）。
中央右寄りに日本語テキスト（太めの明朝体またはやわらかいゴシック、生成り色）：
1行目（大）「人間関係のしくみ帳」
1行目の下（小）「おとなの社会学」
2行目（中）「人間関係のモヤモヤは、あなたのせいじゃない。」
3行目（小）「毎週更新｜20〜30分の"聞ける"社会学」
人物の顔、写真、ロゴは入れないでください。落ち着いた知的な雰囲気で。
```
※画像生成AIは日本語の文字を崩しやすいです。文字が崩れたら、文字なしの画像を作ってもらい、Canvaなどで文字を後から乗せてください。

## チャンネル概要文（「チャンネルについて」欄）
```
人間関係のモヤモヤは、あなたの性格のせいとは限りません。
「大人になると友達が減る」「職場の空気に逆らえない」「地元の友達と話が合わない」──
その多くは、社会の“仕組み”で説明できます。

人間関係のしくみ帳では、社会学の研究や理論をやさしく読み解き、
「自分が悪いんじゃなかった」と思える知識と、明日からできる小さな行動をお届けします。

▶ 毎週更新（20〜30分）
▶ 作業用・寝る前の“聞き流し”にもどうぞ
```

※「土・日の週2本」は25分の台本を週2本作る前提になり、守れないと信用を失うため「毎週更新」に変更（反対派レビューより）。慣れたら週2本に増やす。
