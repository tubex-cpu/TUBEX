# 社長の前提（全チャンネル共通）

Claude と Codex が**毎回必ず読む**、社長の変わらない考え・前提。ここに書いたことは、個別の指示がなくても判断の基準にする。
- チャンネル固有の前提は `channels/<name>/CHANNEL.md`、日付付きの個別の判断は `docs/チャンネル方針.md` に書く。
- 前提が変わったら、ここは最新版に書き換え、経緯は `docs/チャンネル方針.md` に1行残す。
- 箇条書きで短く（1〜2画面まで）。できれば「理由：」を1行添える（書いていない場面でも意図に沿って判断できるように）。

## 1. なぜやるのか（目的）
- 本業以外の収入の柱をつくる

## 2. 目標（数字と期限）
- 対象は**これから新規で立ち上げる2チャンネル（未設計）**。① ハビ判事は目標に含めない
- 2026-11 までに、新規2チャンネルの**両方**で、それぞれ登録者1,000人・総再生4,000時間を達成し、収益化する
- 2026-12 までに、新規2チャンネル合計で月の収益30万円
- 2027-01 までに、**note 販売も含めた合計で月50万円**（上の YouTube 月30万円の目標とは別に持つ）
- note は**ほぼ自動化**で進め、**有料 note** を販売する。ジャンルは**不倫**（名前「不倫の答え合わせ」・ID `furin_atode`）。YouTube 新規チャンネルを待たずに開設する
- そのため、**チャンネル設計・コンセプト・市場が大きく穴場のジャンル選びが一番大事**（`channels/new-channels/CHANNEL.md`）
- ① ハビ判事の制作は続ける（上記の収益化・収益目標には含めない）
- 投稿本数の目標：ハビ判事＋新規2チャンネルは各週3本（合計週9本）、note は週2投稿。無料・有料の内訳はゲートN0で決める。達成実績・制作能力は未検証

## 3. 使える資源
- お金：**追加費用ゼロ**（サブスク枠内のみ。詳細は `pipeline/README.md`）
- 社長の時間：1日2時間以内
- 社長がやること：ゲート0/A/B/N0/Cの承認・サムネ方向選択・3回差し戻し時の判断。それ以外は AI が進める（note の入稿・公開も Claude か Codex が社長の PC を操作して行う。社長はゲートC で承認するだけ。`pipeline/README.md`「note」）
- 顔出し・自分の声：しない（理由：効率性を高めるため）

## 4. 大事にしている価値観（判断に迷ったときの優先順位）
- 事実は出典付きでしか言わない（確定済み）
- 視聴者に新しい驚きや発見、気づきを与える

## 5. 絶対にやらないこと
- 有料の API・素材・サービスを使う（確定済み）
- 他者のサムネ・キャラ・画像の流用（確定済み）
- 差別化できていないのに工程を進めること

## 6. 社長の好み・苦手
- 市場が大きいジャンルが好み

## 7. その他、AI に知っておいてほしいこと
- 企画・台本・動画は Claude Code、サムネ・note 見出し画像は ChatGPT、分析は双方。Codex は制作本文を代筆しない
- 確認の負担は週次の企画候補・公開候補の一括提出で減らす。既存ゲートとサムネ方向選択は残す（`pipeline/README.md`）
- 就寝宣言後は承認不要かつ許可済みの作業を進め、承認待ちの案件だけを止める。宣言がないのに夜間運用扱いにしない
- 未完了タスクの毎時通知は既存の ChatGPT スケジュールを使う。重複作成・就寝中の通知停止への変更はしない
