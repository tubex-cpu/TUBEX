## 3. 販売者の表示
**推論**
- 週1本の有料記事を続けて売る計画なので、**反復・継続の販売にあたり、「販売業者」に該当し得る**と考えて運用する（F1・F9）。**1本 ¥500 の少額だから不要、とはしない**。

## 4. 返金と、公開設定のほかの項目
**事実**：返金の申請の受付はオン（F6）。返金は購入から24時間以内の申請で、note の審査があり、必ず返金されるわけではなく、ゲスト購入は対象外（F7）。販売者の表示（F2）と本文には、返金の記載はない。

**提案（未承認）**
- **初週は、返金の申請の受付をオンのままにする**（Codex の提案）。理由：初めての販売で、読者が「合わなかったら申請できる」と分かるほうが、購入の不安を減らせる（効果は未検証）。
- **販売の条件と返金の案内を、有料記事の無料部分に短く入れる**（草案。**今の本文はまだ変えない**）。
  - 位置：`03_paid.md` の「この記入セットについて」の表の「価格」の行の直後。**今の有料ラインの位置（「読み終えたときに…目指しています。」の直後）は変えない**ので、追記は有料ラインより前の無料部分に入る。
  - 文（草案）：

    | | |
    |---|---|
    | **購入と返金** | 購入すると、この記事の有料部分をすぐに読めます。購入から24時間以内であれば、note の返金申請ができます（note の審査があり、返金されない場合もあります。ゲスト購入は対象外です）。 |

  - 本文の変更になるので、社長の判断の後、Codex の監査を通してから反映する。06 版・note の下書きも合わせて直す。

**自動翻訳・AI 学習の対価還元への参加**
- 現状：どちらも**オン**（F6）。**変更していない**。
- 提案（Codex、未承認）：**初週は両方オフ**にする。理由：日本語での表現と、販売の結果の確認に集中するため。
- 社長の判断待ち。
