## 書き方で守ったこと（レビューの観点）
- 記入例・記入見本は架空と明記。日付・日数は例で、推奨する待機日数ではないと明記
- 彼の本心の断定、男性心理・本能の一般化、科学的・医療の効果、法律の判断、復縁の保証、相手を調べる方法は書かない
- 拒否されているときの追いの連絡を勧めない。「連絡しない」「返事を急がない」も選択肢として書く
- コメント欄に私的な事情を書くよう求めない（書かないよう案内）
- 無料記事は一般の恋愛でも完結。有料への案内は「既婚男性との恋愛に悩む方へ」と対象を明示
- 有料記事は4ステップ（導入 → 問題提起 → 原因解明を無料、解決策を有料）
- 無料と有料で同じ文章を繰り返して水増ししない
- 保険をかける言い回しを使わない
