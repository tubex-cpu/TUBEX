# 既婚の彼の曖昧な約束を待つ前に｜自分の条件・次の行動・見直す日を決める記入セット

「落ち着いたら会おう」
「年末が過ぎたら、ゆっくり時間をとるから」
「家のことが片づいたら、ちゃんと考える」

既婚の彼からの約束は、いつも少しだけ先にあって、日付がありません。

平日の夜、家にいる時間に連絡が止まる。週末は返事が来ないのが当たり前になっている。会う日は、彼の家の予定が空いたときに、彼のほうから決まる。そして、そのことを誰にも相談できない。

友だちに話したら、何と言われるか分からない。だから一人で、あの一言を何度も読み返して、意味を考える。

この記事は、あなたの恋を正しいか間違っているかで裁くためのものではありません。曖昧な約束を前にして、**自分がどこまで待つか、次に何をするか、いつ見直すかを、自分の手で決める**ための記入セットです。

## よくある待ち方

曖昧な約束を待つ間、こんな動き方になっていませんか。

- **予定を空け続ける。** 彼に急に時間ができたときにすぐ会えるよう、自分の週末や夜を決めずにおく
- **確認の連絡を重ねる。** 「いつ頃になりそう？」と聞いて、返事が短いと、もう一度送る
- **気持ちを長文で送る。** 待っている寂しさや不安を、まとめて伝えようとする
- **彼の家の事情を推し量る。** 「いまは家のことが大変なはず」と、見えないところを想像で埋めて納得しようとする

どれも、関係を大事にしたいからこその動きです。あなたが悪いわけではありません。

ただ、どの動き方も、**待つ期限を彼の側に預けたまま**、自分の時間と気持ちを使い続ける形になっています。

## なぜ、待つほど判断が揺れるのか

曖昧な約束には、日付がありません。日付がない約束は、「いつまで待つか」を決める材料を、相手の側に置いたままにします。

もう1つ、既婚の彼との関係ならではのことがあります。

彼の説明の多くは、**あなたが確かめようのない情報**です。

- 「仕事が繁忙期で」
- 「家のことでバタバタしていて」
- 「妻とは話をしている」

これらは、彼から聞いたことです。あなたが自分の目で見た出来事ではありません。

ところが、待つ時間が長くなるほど、彼から聞いた説明と、自分が見た出来事と、自分の想像が、頭の中で1つに混ざっていきます。「家のことが落ち着けば会える」が、いつの間にか「もうすぐ会える」に変わる。そして連絡が来ないたびに、気持ちが大きく揺れる。

判断が揺れるのは、あなたの意志が弱いからではありません。**判断の材料が、確かめられるものと確かめられないものに分かれていない**からです。

この記入セットでは、それを8つの欄で分けます。

## 1. 8つの欄

| 欄 | 書くこと | 書かないこと |
|---|---|---|
| ① 彼の発言 | 彼が言ったことを、言い換えずにそのまま | 自分の解釈（「会いたいと言ってくれた」など） |
| ② 日時 | それを言われた日時 | — |
| ③ 自分が直接確認した出来事 | あなたが自分の目で見たこと、あなたとのやりとりで実際に起きたこと | 彼から聞いた説明、人づての話 |
| ④ 本人から聞いただけの情報 | 彼の説明で、あなたが確かめていないこと（仕事・家庭の事情など） | — |
| ⑤ まだ分からない点 | 確かめようのないこと。彼の気持ちもここ | — |
| ⑥ 自分の条件 | どこまで待つか。自分の生活のどこを守るか | 彼に守らせるルール |
| ⑦ 次の行動 | 次にすること・しないこと | ⑤を確かめるための行動 |
| ⑧ 見直す日 | この表を見返す日 | — |

大事なのは、**③と④を分けること**です。

彼の説明が本当かどうかを、あなたが確かめる方法はありません。だから④に置いておきます。疑うためではなく、**判断の土台を、自分が見たこと（③）に置くため**です。

⑤の「まだ分からない点」は、空欄にしないで「不明」と書いて構いません。分からないことを分からないまま置いておけるのが、この表のいちばんの役目です。

## 2. 1行から始める手順

8つの欄を、最初から全部埋める必要はありません。過去のやりとりを全部さかのぼる必要もありません。**いちばん気になっている出来事を1つだけ**選んで、次の順に書きます。

1. **①②③⑤の4つを書く**（無料記事の4つの欄と同じです。無料記事の「④ まだ分からない点」は、ここでは⑤です）
2. **④を分ける。** ③に書いたもののうち、彼から聞いただけのことがあれば、④に移す
3. **⑥を書く。** 自分の生活に照らして、どこまで待つかを決める（決め方は5章）
4. **⑦を書く。** ⑥に沿って、次の1週間ほどでやること・やらないことを1つか2つ
5. **⑧を書く。** この表を見返す日を、カレンダーに入れる

途中で止まっても大丈夫です。分からない欄は「不明」のまま、⑥⑦⑧に進んでください。⑥⑦⑧は、③に書けることがあれば決められます。

## 3. 空欄テンプレート（コピーして使えます）

```
【記録 No.1】
① 彼の発言：
② 日時：
③ 自分が直接確認した出来事：
④ 本人から聞いただけの情報：
⑤ まだ分からない点：
⑥ 自分の条件：
⑦ 次の行動：
⑧ 見直す日：
```

スマホのメモに貼り付けて、ロックのかかる場所に保存してください。誰かに見せるためのものではなく、あなたが自分で見返すためのものです。

## 4. 完成した記入見本3件

※ 以下の3件は、説明のために作った**架空の記入見本**です。実在の人物や出来事ではありません。
※ 日付・日数は例です。**推奨する待機日数ではありません。** 何日待つかは、あなた自身の生活から選んでください。

### 見本A：日時の候補が出た

```
【記録 No.1】
① 彼の発言：「落ち着いたら会おう」→ その後「21日か22日の夜なら行けそう」
② 日時：11月2日（土）夜／11月10日（日）昼、どちらも LINE
③ 自分が直接確認した出来事：11月10日の LINE で、21日と22日の2つの候補が出た。時間と場所はまだ決まっていない
④ 本人から聞いただけの情報：「月末までは家のことでバタバタしている」
⑤ まだ分からない点：21日・22日に本当に会えるか。家の事情がどうなっているか。彼の気持ち
⑥ 自分の条件：候補日が変わっても、日程の調整は自分からは1回まで。22日を過ぎたら、自分の週末の予定を先に入れる
⑦ 次の行動：今日中に「21日なら空けられる」と1回だけ返す。それ以外の日は、自分の予定で埋める
⑧ 見直す日：11月22日（金）の夜
```

ポイント：候補日が出たことは③に書けます。でも「月末まで忙しい」は④です。21日に会えるかどうかは⑤。会えるかどうかを⑤に置いたまま、⑥で「変更されたときに自分がどうするか」を先に決めています。

### 見本B：曖昧なまま

```
【記録 No.1】
① 彼の発言：「落ち着いたら会おう」
② 日時：10月20日（月）夜、LINE
③ 自分が直接確認した出来事：10月20日から11月10日まで、LINE は週に2〜3回あった。日程の話は一度も出ていない
④ 本人から聞いただけの情報：「仕事が繁忙期」「家のことがある」
⑤ まだ分からない点：いつ落ち着くのか。彼の予定。彼の気持ち
⑥ 自分の条件：12月1日（月）までに彼から具体的な日付が出なければ、自分から日程を1回だけ聞く。その返事が曖昧なら、それ以上は聞かない
⑦ 次の行動：11月の週末は、彼の連絡を待たずに自分の予定を入れる。確認の連絡はしない
⑧ 見直す日：12月1日（月）
```

ポイント：3週間の間にあった出来事（③）は、「やりとりはある」「日程の話は出ていない」の2つだけです。④の説明は確かめられないので、⑥の判断には使っていません。「聞くのは1回だけ」と決めておくと、返事が曖昧だったときに、もう一度送るかどうかで悩まずにすみます。

### 見本C：一度会えたが、次が未定

```
【記録 No.1】
① 彼の発言：別れ際に「また落ち着いたら連絡する」
② 日時：11月1日（土）夜、会った帰り
③ 自分が直接確認した出来事：11月1日に会えた。次に会う日付は、その場でも、その後の LINE でも出ていない
④ 本人から聞いただけの情報：「年末は家の行事が多い」
⑤ まだ分からない点：年末の彼の予定。次がいつになるか。彼の気持ち
⑥ 自分の条件：12月20日までに次の日付が出なければ、年明けの見直しの日まで、自分からは誘わない
⑦ 次の行動：年末年始の自分の予定（実家・友だち・一人で過ごす日）を、先に決めて手帳に書く
⑧ 見直す日：12月20日（日）
```

ポイント：会えたことは③に書ける、確かな出来事です。ただ、「次」はまだ③に1つもありません。会えた喜びと、次が決まっていない事実を、分けて書いています。

## 5. 自分の条件・次の行動・見直す日の決め方

### ⑥ 自分の条件

⑥は、彼に守らせるルールではありません。**あなたが自分の生活を守るための線**です。次の問いに答えると、書きやすくなります。

- 彼のために空けておける週末や夜は、どれくらいまでなら苦しくないか
- 待つ間、どの予定は自分のために必ず残したいか（仕事、友だち、家族、一人の時間）
- 「ここを過ぎたら、待ち方を変える」と思える日はいつか

日付や回数は、あなたの生活から選んでください。見本の日数は例です。短くても長くても構いません。大事なのは、**彼の都合ではなく、あなたの側に期限があること**です。

### ⑦ 次の行動

⑦には、⑥に沿って、次の見直しの日までにやること・やらないことを1つか2つ書きます。

- やることの例：日程を1回だけ聞く／自分の予定を先に入れる／返事を急がない
- やらないことの例：確認の連絡を重ねない／長文を送らない／彼の家庭の事情を確かめようとしない

**連絡をしない、返事を急がない、という選択も⑦に書けます。** 何かをすることだけが「行動」ではありません。

### ⑧ 見直す日

⑧は、表を見返して、⑥⑦をそのまま続けるか、変えるかを決める日です。カレンダーやスマホのリマインダーに入れておくと、毎日あの一言を読み返さなくてすみます。

**見直す日までは、表を見返さなくて大丈夫です。** 待つ時間を、自分の生活に戻すための日付です。

## 6. 返事の分かれ道

日程を聞いたり、見直す日が来たりしたときの、彼の返事ごとの書き方です。

### 返事がある（日付や候補が出た）

- 出た日付を③に書く。「21日の夜」のように、具体的に
- その日付を、次の⑧（見直す日）にする
- 当日に変更や取り消しがあったら、それも③に書き足す。⑥で決めた「変更されたときの自分の動き方」に沿って⑦を書く

### 返事が曖昧（「また連絡する」「もう少し待って」など）

- 曖昧な返事は、①に言葉のまま書き、理由の説明があれば④に入れる
- **⑥の期限は動かさない。** 曖昧な返事は、日付のある約束ではないからです
- もう一度聞くかどうかは、⑥で決めた回数どおりにする。決めた回数を超えて聞き直さない

### 返事がない

- 「返事がない」ことを、日付とともに③に書く
- **追いの連絡を重ねない。** 見直す日まで、表に記録するだけにする
- 見直す日に、⑥の条件どおり次を決める。待ち方を変える、こちらから連絡しない、離れる。どれも、あなたが選んでよい選択です
- 彼から「距離を置きたい」「連絡しないでほしい」と言われたときは、連絡を重ねないでください。⑦には「こちらから連絡しない」と書きます

## 7. 見直しの記録（履歴）のつけ方

見直す日が来たら、前の記録を**書き換えずに**、新しい記録を下に足していきます。

```
【記録 No.2】（見直し：12月1日）
① 彼の発言：
② 日時：
③ 自分が直接確認した出来事：
④ 本人から聞いただけの情報：
⑤ まだ分からない点：
⑥ 自分の条件：（変えた場合は「No.1 の条件 → 変えた理由 → 新しい条件」の順に書く）
⑦ 次の行動：
⑧ 見直す日：
```

前の記録を消さないのは、**何が変わって、何が変わっていないか**を、あとで自分の目で確かめられるようにするためです。No.1 から No.3 まで並べたときに、③に新しい日付が増えているのか、①の言葉だけが増えているのか。それが、あなたの次の判断の材料になります。

⑥を変えるのは、悪いことではありません。変えたときは、変えた理由も一緒に書いておいてください。

## 8. この表で、しないこと

- **相手を調べない。** 彼のスマホを見る、位置を調べる、家族や職場に連絡する、といったことはしません。この表は、あなたが自分で見聞きできる範囲だけで使います
- **彼の説明を「確かめた事実」に混ぜない。** 彼から聞いたことは、どれだけ具体的でも④に置きます
- **表を誰かに見せたり、SNS やコメント欄に書いたりしない。** あなたと相手を守るためです

## 最後に：手元に残す1枚

最後に、今日の記録から3つだけ抜き出して、1枚にしておきましょう。

```
自分の条件：
次の行動：
見直す日：
```

彼の本心は、この表では分かりません。でも、**自分がどこまで待ち、次に何をして、いつ見直すか**は、今日、自分で決められます。

決めた日までは、あの一言を何度も読み返さなくて大丈夫です。その時間は、あなたの生活のために使ってください。
