## 3. 上位3案

### 案1 即身仏
- 問い：即身仏は、本当に生きたまま土に入ったのか？
- サムネ（短文）：上「生きたまま、仏に？」／中「土の中で3年」／下「本当に生きていた？」
  - 「生きたまま仏に」は言い伝えの説明で、事実として断定はしない。
- タイトル：即身仏は本当に生きたまま土に入ったのか？ 山形の即身仏と科学調査をハビ判事が検証
- 冒頭30秒：
  1. 「1961年、新潟の寺の裏で、58年前に葬られた一人の僧の墓が掘り起こされた」（仏海上人。要一次資料）
  2. 「伝承では、僧は生きたまま土に入り、鈴の音が止まるまで経を唱えたという」
  3. 「だが、掘り出された遺体と墓の造りは、別の話を語っていた」
  4. 「そして2015年、オランダの病院でCTにかけられた仏像の中から、僧の遺体が見つかる」
  5. 「即身仏は、本当に生きたまま仏になったのか」
- 証拠を出す順序：
  1. 伝承（木食行・土中入定。寺の縁起と安藤更生の記述）
  2. 1960年代の学術調査（日本ミイラ研究グループ）
  3. 仏海上人の墓と発掘
  4. 遺体の処置の跡（石灰・燻製・柿渋）
  5. 明治の法律（旧刑法。条文確認後）
  6. 2019年の宥貞法印のCT（論文は「投稿中」と明示し、新発見とは言わない）
  7. 中国の章公祖師像（CT・裁判・行方不明）
  8. いまの信仰（御衣替え・お守り）
- 判決の限界：
  - 一体ごとに経緯が違うので、「すべて生きたまま」「すべて死後」とは決められない。
  - 当時の一次史料は少ない。CTの論文は未刊行。御衣替えの年は寺の発表で確認するまで断定しない。
- 確認すべき一次資料：
  - 『日本ミイラの研究』（1969）
  - 科研費 19K06869 の報告
  - 旧刑法（明治13年）の条文
  - 大日坊・注連寺・西生寺の公式発表
  - 中国の判決（2022年7月19日、福建省高級人民法院）

### 案2 金印は本物か
- 問い：江戸時代に田んぼから出てきた金印は、本当に2000年前の皇帝の印なのか？
- サムネ（短文）：上「国宝 金印」／中「田んぼから出てきた」／下「本物か？」
- タイトル：志賀島の金印は本物か？ 二つの王印と発見記録をハビ判事が検証
- 冒頭30秒：
  1. 「1784年、福岡・志賀島。田んぼの溝を直していた農民が、石の下から金の印を見つけた」（発見の経緯は記録で食い違いがあり、要一次資料）
  2. 「刻まれていたのは、漢委奴国王」
  3. 「教科書にも載る国宝。だが、発見の記録には不自然な点があり、偽物ではないかという説が、いまも消えない」
  4. 「その答えの手がかりは、中国で見つかった二つの王の印にあった」
- 証拠を出す順序：
  1. 『後漢書』東夷伝（西暦57年、光武帝が印綬を授けた記事）
  2. 発見の記録（甚兵衛の口上書）と、記録の食い違い
  3. 偽物説の論点（発見の状況、彫りの技法など。著者と出典を明示）
  4. 中国の王印2つ（滇王之印＝1956年、広陵王璽＝1981年）との比較
  5. 寸法（漢の一寸）と金の成分
  6. いまの位置づけ（国宝、福岡市博物館）
- 判決の限界：
  - 本物・偽物のどちらかを先に断定しない。
  - 「本物とする材料が多い」「発見の経緯は確かめきれない」と分けて判決する。
- 確認すべき一次資料：
  - 『後漢書』東夷伝
  - 甚兵衛の口上書（福岡市博物館）
  - 偽物説の原典（三浦佑之ほか。著者と書名を要確認）
  - 2つの王印の出土報告
  - 福岡市博物館の解説
- 参考URL：
  - https://www.youtube.com/watch?v=p7fqN-hHBpw
  - https://www.youtube.com/watch?v=na4nK8Cjkrg
- 注意：
  - 競合が2週間で3本出している（行間の古代史の「最新AIで分析した結果 金印は本物なのか」を含む）。いまは後追いになる。
  - 出すなら「判決」の形式と、2つの王印の実物比較で差をつける。

### 案3 奈良は本当に湖だったのか（試験枠）
- 問い：奈良盆地は、本当に大きな湖だったのか？ 都はなぜ、そこに造られたのか？
- サムネ（短文）：上「奈良盆地」／中「大きな湖だった？」／下「都の下に眠る水」
- タイトル：奈良は本当に湖だったのか？ 地形データでたどる古都の昔をハビ判事が検証
- 冒頭30秒：
  1. 「奈良盆地の標高データに水を張ると、平城京も飛鳥も沈む湖が現れる」（地形データからの仮定図だと明示する）
  2. 「この『奈良湖』は、本当に人が住む時代まであったのか」
  3. 「地層、遺跡の位置、そして古事記の言葉から確かめる」
- 証拠を出す順序：
  1. 地形データ（標高の段彩図。自作）
  2. 地質学の知見（盆地の成り立ち、湖があった時代）
  3. 遺跡の分布（縄文・弥生の集落の標高）
  4. 古い地名と文献
  5. 大和川・亀の瀬の地形
  6. いまの溜池と水害
- 判決の限界：
  - 地質の時代（数十万年単位）と人の歴史を混ぜない。
  - 地形データに水を張った図は「仮定」であり、昔の姿の復元ではないと明示する。
- 確認すべき一次資料：奈良盆地の地質の論文、奈良県の地質図、遺跡の分布データ（全国遺跡報告総覧）。
